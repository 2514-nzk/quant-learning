# 第三卷 · 02｜市场状态识别与择时

> **状态：教学正文 v1；基于教材独立合成数据的冻结状态规则与策略对照可复算。** 全部特征和未来收益均是人工构造，未证明真实 A 股阶段差异、择时收益或可交易性。

## 本章核心问题：定义市场状态，怎样避免事后解释冒充事前信号？

假设某个行业 Top1 策略在市场上涨时表现更好。如果先看到整段收益，再把赚钱日期叫“强势期”，亏钱日期叫“风险期”，最后宣称在强势期持仓、风险期空仓，这就不是交易时可执行的状态识别。

因此本章只回答一条方法论问题：**市场状态是否在决策之前由可得特征决定，而且在与无状态策略的同日配对中显示明确的人工增量？** 这和“市场真的可被预测”是两个不同命题。

## 1. 状态定义来自当时已知的市场特征

本卷固定数据中的市场特征包括：

| 字段 | 定义 | 数据边界 |
|---|---|---|
| trend20 | 人工近 20 日市场趋势代理，小数收益口径 | 数值为正仅表示生成者设计的正趋势 |
| breadth | 人工宽度比例，范围 0–1 | 真实研究需历史动态证券母体作分母 |
| vol20 | 人工波动率代理 | 不等于未来波动，也未经市场校准 |
| known_at | 特征入库并可用于信号的人工时刻 | 必须不晚于 feature_cutoff_at |

明确的**预注册分类器**是：

\[
G_t=
\begin{cases}
\text{RISK\_ON},& trend20_t>0,\ breadth_t\ge0.55,\ vol20_t<0.035,\\
\text{RISK\_OFF},& \text{其余情况}.
\end{cases}
\]

这是一个人为选择的**教学阈值**，不是市场公认的最优规则；算法只能看到当期特征，不能看到 following_week_return。

例如，trend20 为 0.01、breadth 为 0.60、vol20 为 0.02，按冻结规则得到 RISK_ON；若仅把 breadth 改为 0.53，状态就是 RISK_OFF。不能因为未来行业收益上涨而回头修改分类。

## 2. 事前标签与事后阶段分析必须区分

阶段研究常把牛市、震荡、恐慌、复苏作为描述性名词。但当一个阶段依赖未来最高价、事后收益或全样本的峰谷转折才能确定时，它**不能**直接进入过去某天的模型输入。

真正用于决策的标签必须记录：

1. 形成状态的特征版本与时间戳；
2. 分类阈值和模型版本；
3. 可解释的 UNKNOWN 或数据拒绝路径；
4. 不修改历史的冻结决策日志；
5. 阈值选择发生在哪个开发样本，最终检验有无被用来调参。

本书没有引入未经证实的“五类 A 股市场阶段真实差异”，只使用明确的 RISK_ON / RISK_OFF 人工二状态机制，展示怎样写出可被审计的条件策略。

## 3. 有条件与无条件策略怎样公平比较？

第 01 章固定行业评分为上一段观察到的 past_4w_return。令 \(\hat g_t\) 是当期历史行业强弱排名第一的行业：

\[
\hat g_t=\arg\max_{g\in U_t}s_{g,t}.
\]

不择时分支：

\[
w^{\mathrm{always}}_{g,t}=\mathbf{1}(g=\hat g_t).
\]

条件择时分支：

\[
w^{\mathrm{gated}}_{g,t}
=\mathbf{1}(G_t=\text{RISK\_ON})\mathbf{1}(g=\hat g_t).
\]

在风险关闭状态，目标行业仓位为零，现金 100%。**现金并非免费防御**：真实市场可能失去上涨机会，也可能为反复进出支付额外成本。本书现金不计利息，仅作人工基准。

评价时，要在**同一周、同一合成证券母体与同一费用代理**上做配对：

\[
d_t=R^{\mathrm{proxy,gated}}_t
-R^{\mathrm{proxy,always}}_t.
\]

输出每期 \(d_t\)、状态、仓位、L1 变动、退出与重新进入次数，然后才讨论均值。这一差值只是**两个合成目标组合收益代理的差**；绝不自动等于真实净超额或有统计显著性。

## 4. 较低波动不等于预测更准

条件策略如果缩短持仓时间，观察净值可能更平稳；但改善可能仅来自现金比例变高，而不是行业预测能力改变。报告至少分四层：

- **排序层**：行业分数对未来相对收益排名有没有持续信息；
- **仓位层**：处于各状态时的平均目标仓位、现金与集中度；
- **组合层**：绝对毛观察收益、成本代理后的相对现金和等权基线差；
- **执行层**：未来真实卖出是否成功、停牌/涨跌停与资金如何改变实际持仓。

第 02 章的人工策略只能计算前三层的有限模拟量，不能证明第四层。目标行业 100% 不等于当天存在可买卖的证券。尤其不要把后验降低回撤说成统计预测增量。

## 5. 从二状态扩展到可证伪的条件交互

真实研究若事先提出“反转因子在风险期表现不同”，可以定义：

\[
y_{i,t}=\alpha+\beta f_{i,t}
+\gamma G_t+\delta f_{i,t}G_t+\epsilon_{i,t}.
\]

此处 \(G_t\) 是决策前已知的状态编码，\(\delta\) 描述在给定样本与回归规格中**预测斜率的条件差异**。它既不能证明因果关系，也不是多头的已实现收益。实际推断还要控制市场与行业共同冲击、重叠标签、多重候选、观察期有效样本数、训练/验证选择偏差。

当不同状态下 RankIC 差异的区间跨零，或条件显著却没有成本后长仓超额时，合理的结论是“证据不足”，不是继续更换阶段标签直到显著。更多方法参照 [第二卷第 08 章统计推断](../volume-2/08_factor_validation.md) 和 [第 11 章漂移](../volume-2/11_oos_drift.md)。

### 5.1 宏观和跨境特征还需要怎样的门禁？

真实 A 股研究若使用美国指数、汇率、宏观数据，必须比较带时区的**绝对公布与实际入库时刻**。美国周五收盘往往在中国周五决策以后发生；不能因日历都叫“周五”就使用它。历史市场宽度还需要真实上市/退市、停牌、行业分类和交易资格信息。本教材的市场变量是人工生成，不能代替真实的跨境披露记录。

## 6. 动手实验与反例

~~~bash
python examples/volume3_strategy_lab.py --json
python -m unittest discover -s tests -p "test_volume3_strategy_lab.py" -v
~~~

输出中的 market_regime_counts 给出两个**人工**状态的期数。对照 strategies 下 always_top、regime_gated_top、equal_four、cash 四个条目，同一时期都报告：

- 人工目标行业和现金；
- 人工未来收益对应的毛观察值；
- L1 目标仓位换手；
- 人工费率造成的成本代理；
- development（前八期）和 later_artificial（后八期）摘要。

改变任何一周的**未来收益标签**，市场状态和那一周的目标权重仍必须完全不变；如果把市场特征的 known_at 改成决策以后，代码必须拒绝。这是本章程序正确性的反事实测试。

## 7. 习题及答案

**练习 A：** trend20=0.01、breadth=0.60、vol20=0.02，状态是什么？

答：RISK_ON，三条阈值条件均满足，前提是输入在截止前已知。

**练习 B：** 同样趋势与波动，但 breadth=0.53 呢？

答：RISK_OFF，宽度未达 0.55；不允许为符合未来收益改标签。

**练习 C：** 状态门禁的组合回撤更小，就证明行业预测更准吗？

答：不能。空仓会降低暴露，需单独比较排序、仓位、费用和实际执行。

**练习 D：** 用 2025 年全年高低点定义五类阶段，再用它解释年初策略，是否等于实时阶段模型？

答：不是。年初无法知道后面的高低点。这是后验描述，不能作为当时的策略输入。
