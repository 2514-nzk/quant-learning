## 1. 价值因子：盈利价格比 EP

第一期的四家公司财务数都已在信号前可用；下表金额统一为亿元。它们是与本故事配套的教学输入。

| 股票 | 最近十二个月归母利润 | 总市值 | 平均归母权益 |
|---|---:|---:|---:|
| A | 8 | 100 | 40 |
| B | 6 | 100 | 60 |
| C | 4 | 100 | 25 |
| D | -2 | 100 | 20 |

先只比较利润与市场给整家公司的报价。A 的 `8/100=8%`，B 为 6%，C 为 4%，D 为 -2%。这个盈利价格比叫 **EP**。

同样的报价，能对应更多利润，是值得研究的“便宜”线索。但 D 的负数也提醒你：便宜与持续恶化可能一起出现，公式本身没有回答企业以后会怎样。

## 2. 质量因子：净资产收益率 ROE

A 的利润除以平均权益为 `8/40=20%`；B 是 10%；C 是 16%；D 是 -10%。这个指标叫 **ROE**，试着描述盈利相对股东权益的比例。

股东权益是会计意义上的净资产，并不等于银行账户里的现金。“归母”指归属于母公司股东；“最近十二个月”常写成 TTM。

先猜一句：EP 和 ROE 会把 B、C 排成同一个顺序吗？

<details>
<summary>展开对照两张名次表</summary>

不会。EP 把 B 放在 C 前面，ROE 则把 C 放在 B 前面。它们并不完全在回答同一个问题。

</details>

## 3. 异常值与无效分母

小林把 A 的权益暂时改成 0.4，让你再除一次：`8/0.4=20`，也就是 2,000%。

A 突然优秀了一百倍吗？先查数据单位、分母口径和权益是否真的很小。可能是记录错误，也可能是需要解释的业务事实，不能只凭比值大就给最高评价。

如果分母为零或负数，本故事先标为无效。例如：

```python
profit = -2.0  # 这次练习的利润。
equity = 0.0  # 故意设为零，观察无效分母怎样处理。
if equity <= 0:  # 本教学规则要求权益为正。
    roe = None  # None 表示这次不提供有效值，不是 ROE 为零。
else:
    roe = profit / equity  # 只有分母符合约定，才执行除法。
print(roe)
```

这里只修改了一个演练条件，没有把固定数据文件中的 A 或 D 改掉。你留下错误原因，再回到原表。

## 4. 横截面排名与标准化

现在第一期的候选输入齐了：

| 股票 | EP | ROE | 过去五日涨幅 MOM_5 |
|---|---:|---:|---:|
| A | 8% | 20% | 8% |
| B | 6% | 10% | -1% |
| C | 4% | 16% | 4% |
| D | -2% | -10% | 2% |

你若直接把原数相加，取值范围较大的一列可能影响更多。先给每列按同方向排名，或按事先约定做标准化，才能说清怎样汇总。

排名压缩了极端值的距离；标准化保留更多距离，也更需要检查异常值。它们各改变了什么，应通过同口径实验观察，不能看过最终成绩后才挑一个最好看的版本。

## 7. 进阶训练｜把 EP、ROE 从公式变成可用因子

**入门关**：EP 常写成盈利与价格的比率，ROE 常写成净利润与股东权益之比。但“盈利”究竟用归母、扣非还是滚动十二个月？股东权益用期末还是平均？这些是不同定义，不能在报告中只留两个字母。

**进阶关：数值有效性不是经济意义。** PE 为负、净资产为负、净利润一次性跳变、分母接近零，都可能让比率极端。不能简单将全部负数改成零；应该先标记原始情况、定义可解释的异常规则、记录每次排除原因。

将处理流程写成：

~~~text
原始财务版本 → 经济主体与日期匹配 → 计算比率
→ 标记无效值 → 预定去极值/中性化/标准化
→ 检查横截面覆盖 → 再计算排序与未来标签关联
~~~

**研究关**：比较至少两套预先定义的处理口径：不去极值与基于当时已知横截面的稳健截尾。按相同日期和股票集合评价，记录 RankIC、缺失率和排名变化。若改用跨期估计的处理参数，只能在历史训练段拟合，不能拿完整测试期倒推边界。

**本章交付**：因子口径卡、异常值样例、两种处理方案的相同样本比较，不要只留最好的一版。
