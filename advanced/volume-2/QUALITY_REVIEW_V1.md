## 质量目标与不做什么

本次只关闭**教学版内容一致性和可复算性**问题：一章一条知识主线、公开假设与数据性质、公式可显示、数字能手算、题目有答案、Python 实验存在且有负例测试、跨章名词不冲突。数据只用 [教材专用三套数据](../../data/teaching/README.md)，不依赖私人策略数据库。

本次**没有**声称完成真实历史股票池、独立市场 OOS、产业级执行仿真、法律意见或外部专家审稿。真实证券价格的描述性结果仍不应被推广为全 A 股可交易 Alpha。

## 全卷统一术语、时间和统计口径

| 符号/字段 | 本卷定义 | 常见误解 |
|---|---|---|
| signal_at | 信号横截面归属的观察时刻 | 不必等于真实决策提交时刻 |
| feature_available_at | 最晚一个特征实际可用时刻 | 不等于价格所对应的交易日期 |
| decision_at / cutoff | 本次决策已完成、可以使用信息的截止 | 不能用此时之后的收入/订单结果 |
| source_published_at / ingested_at / available_at | 源公开、研究端接收、系统可用的三个时间 | 报告期不等于首次披露日 |
| label_end_at | 形成标签所需的最后价格/事件时刻 | 不等于标签已被研究系统收到 |
| label_available_at | 标签可用于训练的可信时刻 | 第 06/11 章前向门禁严格要求早于验证/本期信号 |
| member/eligible/unknown | 历史参考母体内的状态与可判定资格 | 未来名单不能回填；UNKNOWN 不等于 INELIGIBLE |
| N_t / T | 单期横截面证券数 / 有定义的时间期数 | 不能用 N×T 充当独立时间样本 |
| RankIC_t | 当期因子与未来收益的 Spearman 秩相关 | 不是当期百分比投资收益 |
| ICIR | 平均逐期 IC / IC 跨期样本标准差 | 未年化；标准差为零时未定义 |
| HAC / block bootstrap | 估计序列均值不确定性的两种近似方法 | 不能补救非法 PIT、结构断裂或盲目多次试验 |
| w / mu / Sigma | 目标权重、收益代理、协方差 | 排名分数不等于可直接交易的收益预测 |
| NAV | 实际模拟现金加持仓按价估值 | 不等于目标权重所对应的纸面价值 |
| OOS | 选型和研究规则冻结后独立的评价证据 | 本书合成后段仅用于算法教学 |

**统一时间顺序**：对于已接收事实，源公开不晚于接收、接收不晚于系统可用；特征可用时刻不晚于信息截止，决策须早于计划入场；标签形成后才可能被允许训练。本卷的**保守前向标签门禁**为：历史信号早于验证首信号，且 label_available_at **严格早于**验证首信号；相等也剔除。双向交叉验证的 Embargo 不是同一算法。

**统一证据等级**：合成数据 = 代码/算术教学；真实四股 = 特定历史报价的回顾性描述；真正全市场 PIT + 独立 OOS + 成本/成交验证 = 尚未具备。读者不得将三类证据混写。

## 余项分级（不阻止教材版 v1 内部收口）

- **需外部专业评阅**：数学推导完整性、经济学假设、交易规则逐条适用和参考资料权威性；
- **需要另立研究项目**：真实动态全市场 PIT、行业/财报历史、真实成本容量与独立市场 OOS；
- **属于第三卷**：具体策略全流程信号→组合→可执行订单和市场状态/行业强弱的深度实战。

**结论**：14/14 章可作为自洽的内部校审教学版 v1 使用；并不将其包装成完整的、经外部审稿的研究级或可实盘教材。
