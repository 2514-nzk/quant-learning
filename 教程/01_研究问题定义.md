# 第 1 章｜把研究想法写成可检验的问题

起步课中，我们按过去五日涨幅选了 A、C，算出一次组合收益。现在要解决的问题是：别人能否照着同样的规则做一遍？换一个日期以后，我们还能否诚实地判断它有没有帮助？

本章只交付一份短研究说明。先把问题和动作写清楚，后面的数据、评价和模型都会接在它上面。

## 1. 一句“买强势股”为什么还不够

假设三个人都说自己买强势股：

- 甲看过去五天，买涨得最多的两只。
- 乙看过去一年，买涨得最多的十只。
- 丙在今天收盘以前买，甲、乙在明天开盘买。

他们可能得到完全不同的结果。如果没有写清规则，就无法判断差别来自想法、时间，还是执行方式。

因此，研究的第一步是把“我觉得可能有用”写成“具体怎样检查”。这份事先写下的说明，书中叫**研究规格**。

## 2. 先把一个小问题写完整

沿用起步课的想法：

> 在固定的候选股票中，过去五日涨幅较高的股票，接下来从次日开盘到第五个交易日收盘，是否通常表现更好？

逐项拆开：

| 要说清的事 | 本次课堂实验的约定 |
|---|---|
| 从谁里面挑 | 四只虚构股票 A、B、C、D |
| 用什么挑 | 决策时已经知道的过去五日涨幅，分数越高越优先 |
| 什么时候决定 | T 日收盘后 |
| 什么时候买、什么时候卖 | T+1 开盘买，T+5 收盘计划卖出 |
| 买多少 | 选前两只，每只分一半资金 |
| 和谁比较 | 四只候选股票的等权平均收益 |
| 费用和限制怎样处理 | 起步手算暂不扣费用，并假设都能成交；形成真实结论前必须加入这些条件 |
| 怎样记录结果 | 每次都记录所选股票、收益和与基准的差额，包括亏损的区间 |

现在别人已经能重做这次手算。将来改成真实股票时，还要补历史股票名单、数据来源和可成交状态；这些会在第 3、9 章逐项加入。

**停下来想一想：** 把“过去五日”改成“过去二十日”，是不是同一条规则？

答案是规则已经改变。改动可以有理由，但必须记录，并重新评价。

## 3. 分清已知条件和未来答案

起步课中的两列很容易被混在一起：

| 股票 | T 日已知：过去五日涨幅 | 事后才知：未来指定区间收益 |
|---|---:|---:|
| A | 8% | 5% |
| B | -1% | 1% |
| C | 4% | 3% |
| D | 2% | -2% |

左列帮助我们做选择，右列帮助我们检查选择。

- **特征**：做决定时已经知道的数量。本例是过去五日涨幅。
- **标签**：后来才知道、用来核对预测的答案。本例可以是未来收益，也可以是未来收益的排名。
- **信号**：从已知信息得到的选择依据。本例把过去涨幅当分数，按高低排序。
- **策略**：把信号变成完整买卖动作的规则，包括买多少、何时买卖、费用和受限时怎么办。

因子研究会先检查某个已知数量是否适合打分。机器学习则会尝试从历史例子中学出打分关系；第四编再进入这一步。

本章的手工规则已经能研究。先有清楚的问题和对照，之后才有判断模型是否帮助了我们的依据。

## 4. 为什么赚了钱也可能没有选股帮助

这次 A、C 的平均收益是 4%，四只股票的平均收益是 1.75%，相差 2.25 个百分点。

再想一个情形：某次所选组合赚了 2%，同一候选股票的平均收益却是 3%。这次虽然盈利，选股结果仍比对照低 1 个百分点。

所以报告至少回答两件事：组合自己的收益是多少，相对事先规定的基准表现如何。以后还会问中途亏过多少、费用吃掉多少、哪些股票没能买卖。

这些问题会在相应章节逐步加入。第一章先把比较对象写进研究说明。

## 5. 先写下哪些结果会让自己改变看法

“过去涨得多，接下来可能继续较强”叫**研究假设**。假设是待检查的解释，研究需要允许结果反过来改变我们的看法。

一次亏损不能直接证明规则永远无效；一次盈利也不能证明它长期有效。我们需要事先安排多个日期、不同年份和没参与挑选规则的数据来评价。

现在先写三个可以触发复查的情况：

1. 发现选股时使用了未来信息：先修正数据和时间顺序。
2. 换一段预留历史后，结果和最初相差很大：检查是否只记住了某段行情。
3. 组合的优势在扣费用或恢复成交限制后消失：说明当前方法的交易价值仍需验证。

到评价章节，再把“相差很大”“优势消失”落实到事前登记的指标、区间和容忍范围。这里先形成一种习惯：把不利结果也纳入研究说明。

## 6. 轮到你写六句话

拿一张纸，先不打开模型代码，写下：

1. 我想检查什么关系？
2. 哪个数字在做决定时已经知道？
3. 从哪些股票中选、选几只？
4. 什么时候决定，什么时候买卖？
5. 用什么结果评价，和谁比较？
6. 哪些条件还没实现，哪些结果会让我复查？

一个合格的课堂答案可以是：

> 我想检查过去五日涨幅与随后收益的关系。在 T 日收盘后，给四只候选股票按已知涨幅排序，T+1 开盘各用一半资金买入前两只，T+5 收盘计划卖出。记录收益和候选股票等权平均的差额。这次手算暂不含费用和成交限制，因此只核对计算；下一步用更多日期并逐步加入这些条件。

## 7. 三道小练习

**题一：** “预测股票会不会涨”和“给同一天的股票排出相对强弱”，有什么区别？

**答案：** 前者问一只股票是否上涨；后者问股票之间谁相对更强。全部下跌时，也可以排出相对次序。

**题二：** 看完未来结果以后，把“买两只”改成“只买这一期最好的 A”，再用这一期评价新规则，问题在哪里？

**答案：** 未来结果参与了规则选择。这段数据已经帮助我们修改方法，需要另留一段数据评价新规则。

**题三：** 两份报告收益不同，首先比较什么？

**答案：** 先比较候选股票、数据、信号、买卖时间、费用和基准等约定。规格不同，不能马上把差别归给模型好坏。

完成这六句话后，进入[研究假设与研报复现](01a_研究假设与研报复现.md)，进一步区分想法、解释与证据。完整的公式、字段和正式模板保存在[研究规格参考](参考_研究规格与字段.md)，实现项目时再按需查阅。
