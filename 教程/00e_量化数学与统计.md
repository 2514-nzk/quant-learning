## 第一次读这里：只要会三种计算就能继续读正文

不需要先补完整套数学。先掌握下面这三件事：

| 会做什么 | 例子 | 答案 |
|---|---|---|
| 算百分比 | 10 元涨到 11 元 | (11−10)÷10 = **10%** |
| 算平均 | 两只股票分别赚 5%、3%，等金额买入 | (5%+3%)÷2 = **4%** |
| 算连续两期 | 100 元先涨 10%，再跌 10% | 100×1.1×0.9 = **99 元** |

后面如果出现“方差、标准差、相关、回归”，先回到具体例子：

- **波动/标准差**：过程是否大起大落？
- **相关/RankIC**：你排的名次，和真实名次是否接近？
- **回归**：根据过去样本学习每一列应该给多大权重？

每个公式都应能回答一个普通问题。若公式暂时看不懂，先用本页的中文解释和数值表，再决定是否继续看推导。


## 1. 先统一符号、单位和维度

| 符号 | 意思 | 实际对象 |
|---|---|---|
| i | 第 i 只股票 | 一行记录中的 code |
| t 或 T | 一个时间点 | 信号日、执行日或某个统计期 |
| r(i,t) | 股票 i 在指定区间的收益 | 必须说明起止价格，数值 0.02 表示 2% |
| x(i,t) | 当时可用的因子值 | 例如过去 20 日动量 |
| w(i,t) | 在本期收益开始前确定的持仓权重 | 不能用本期结束后的权重倒算收益 |
| n | 样本数 | 横截面的股票数或时间序列的期数，需区分 |

求和符号 `Σ` 可以读成循环累加：`Σ_i w_i*r_i` 就是对股票逐只求和。均值、相关、回归都要问“沿股票轴，还是沿时间轴”。

例子：当日 100 只股票的平均收益是横截面统计；某策略 100 天的平均收益是时间统计。两者都是均值，但不能互相替代。100 只股票 × 100 天的 10,000 行，也不能未经检查就当作 10,000 个独立实验。

## 2. 复利、对数收益和净值路径

简单收益描述一段持有期内资金比例的变化：

```text
r_t = P_end / P_start - 1
V_0 = 1
V_t = V_(t-1) * (1 + r_t)
累计收益 = product(1 + r_t) - 1
```

先涨 10%，再跌 10%，净值为 `1 → 1.1 → 0.99`，累计亏损 1%。算术平均收益为零，不能据此说资金没变化。

等长周期的几何平均为 `product(1+r)^(1/n)-1`，这两期约为 -0.5013%。对数收益 `g_t=log(1+r_t)` 可以沿时间相加，再用 `exp(sum(g))-1` 还原累计简单收益。

要区分两种运算：

- 同一时期的组合简单收益可以按期初权重加权；
- 不同时期的简单收益需要复乘，不能直接累加。

组合对数收益通常也不能简单按股票权重加权，因为 `log` 是非线性的。若收益为 -100%，资金归零，对数收益为负无穷；低于 -100% 涉及杠杆或额外负债，本章简单净值例子不覆盖。

**练习：** 先跌 20%，需要涨多少才能回到起点？

**答案：** `1/0.8-1=25%`。百分比变化的分母改变了。

## 3. 分布：均值之外还要看什么

均值容易被极端值改变，中位数描述中间位置，分位数描述尾部。对 `[1,2,3,4,100]`，均值为 22，中位数为 3。先看分布再决定清洗规则，不能仅因为数字大就删掉真实损失。

样本方差和标准差：

```text
mean = sum(x_i) / n
sample_variance = sum((x_i - mean)^2) / (n - 1)
sample_std = sqrt(sample_variance)
```

分母 `n-1` 对应 `ddof=1`；总体描述性方差用 `n`，对应 `ddof=0`。NumPy 默认 `ddof=0`，pandas 的 `.std()` 默认 `ddof=1`，不能忽略默认差异。

收益 `[1%,-1%,2%,0%]` 均值为 0.5%，偏差平方和为 0.0005，样本标准差 `sqrt(0.0005/3)≈1.2910%`。方差单位是收益率平方，标准差才回到收益率单位。

本教材约定：估计时间序列波动通常用 `ddof=1`；当日截面 Z-score 的教学例子用 `ddof=0`。其他文献可以有不同约定，但要写清楚。

标准差描述上下波动，不等于“最大可能亏损”，也不能单独刻画尾部风险。股票收益常有厚尾、偏斜和波动聚集，不能看到均值和标准差就默认收益服从正态分布。

## 4. 概率、期望和样本量

交易胜率是盈利次数占比，期望收益还取决于盈亏幅度和费用。一个仅用于算术说明的模型：

```text
期望收益 = 胜率 * 平均盈利 + 败率 * 平均亏损 - 平均费用
```

若胜率 55%，盈利时 +1%，亏损时 -2%，则未扣费的期望是 `0.55×1%+0.45×(-2%)=-0.35%`。高胜率并不直接回答收益问题。真实研究还应看尾部、持有时长和资金占用。

统计中要区分：

- **总体/过程**：希望了解的收益产生机制，通常无法全部观察。
- **样本**：手上这段历史。
- **估计量**：从样本算出来的均值、波动、IC 等，本身也会随样本变化。
- **不确定性**：换一段同类数据，估计值可能偏离多少。

常见标准误公式：

```text
SE(样本均值) ≈ sample_std / sqrt(n)
```

它依赖近似独立、同分布或足够弱的依赖等条件。它测量的是**均值估计的不确定性**，不是单期收益波动。

假设 100 期近似独立收益，均值 0.10%、样本标准差 2%，则 SE=0.20%。大样本正态近似区间为 `0.10% ± 1.96×0.20%`，即约 `[-0.292%,0.492%]`。观察到正均值仍不足以排除均值接近零。

这里 1.96 是满足相应近似条件的教学数值。小样本、厚尾或自相关数据需要相应方法；不能把它当作任何回测都通用的精确区间。频率学派的 95% 置信区间描述重复抽样方法的覆盖性质，不表示某条已算区间让固定真值随机落入的概率为 95%。

## 5. 相关、排名与 IC

协方差衡量两列是否一起偏离各自均值，相关系数再除以两者标准差：

```text
sample_cov(x,y) = sum((x-mean_x)*(y-mean_y)) / (n-1)
PearsonCorr(x,y) = cov(x,y) / (std(x)*std(y))
```

相关系数在 -1 到 1 之间，没有原字段单位。它度量线性关系；零相关不等于所有关系都不存在。例如对称的 x 与 x² 可以线性相关为零，却有确定的非线性关系。正相关也不能证明因果。

Spearman 相关先把两个变量变成名次，再算 Pearson 相关。它保留次序，对原数值距离不敏感；并列取平均名次。只有无并列时，才可直接使用简式：

```text
RankIC = 1 - 6*sum(d_i^2)/(n*(n^2-1))
```

四只股票的因子名次为 `[1,2,3,4]`，未来收益为 `[1%,3%,2%,4%]`，收益名次为 `[1,3,2,4]`，名次差平方和为 2，所以 RankIC=0.8。

**量化应用：** 对每个信号日，用当时因子与后来指定窗口的收益计算横截面相关，得到一条按日期排列的 IC 序列。不能把所有日期直接拼成一个相关系数。

| 指标 | 衡量什么 | 不能直接说明什么 |
|---|---|---|
| Pearson IC | 因子数值与未来收益的线性关系 | 可实现交易收益 |
| RankIC | 因子次序与未来收益次序的关系 | 收益幅度或因果关系 |
| ICIR | 逐期 IC 均值 / 标准差，本教材常用 RankIC 序列且不额外年化 | 显著性检验的 p 值 |
| 正 IC 比例 | 有效日期中 IC>0 的占比 | 是否扣费后赚钱 |

常数因子没有排名区分力，相关无定义；零标准差的 IC 序列使 ICIR 无定义；两个配对观测的非退化相关只能是 ±1。必须同时报告有效股票数、有效日期数、并列和缺失情况。

## 6. 标准化：统一尺度，保留什么信息

```text
Z-score = (x - mean(x)) / std(x)
RankPct = 平均名次 / 有效股票数
Robust Z = (x - median(x)) / (1.4826 * MAD_raw)
MAD_raw = median(abs(x - median(x)))
```

Z-score 保留相对距离；RankPct 只保留顺序。`[1,2,100]` 与 `[1,2,3]` 排名相同，但最后一项距离不同。选哪一种是在定义研究信号，而不是单纯格式转换。

对 `[1,2,3,4,100]`，中位数=3、MAD_raw=1，按 `中位数±3×1.4826×MAD_raw` 缩尾，上界=7.4478。1.4826 是在正态分布参照下将 MAD 调到标准差尺度的系数，不会让真实收益因此变成正态。

零标准差和零 MAD 必须记录退化情况，不能直接相除，也不能看收益后才决定备用规则。详细处理见[传统因子与预处理](03b_传统因子与预处理.md)。

当日横截面标准化只用当时可见的股票截面；机器学习跨期 scaler 只在训练样本拟合。理解两者的数学操作相似、信息范围不同，才能正确判断是否泄漏。

## 7. 组合收益、协方差与回撤

在同一持有区间、期初权重给定、没有中途额外现金流的简化条件下：

```text
组合收益 r_p = sum(w_i * r_i)
预期收益 E[r_p] = w^T * mean_vector
组合方差 Var(r_p) = w^T * covariance_matrix * w
```

对程序员，`w^T * Σ * w` 就是 `weights @ covariance @ weights`。`Σ` 的对角线是各股票方差，非对角线是股票之间协方差。

两只股票日波动分别为 2%、3%，各持有 50%，相关系数 0.2：

```text
组合方差 = 0.5²*0.02² + 0.5²*0.03² + 2*0.5*0.5*0.2*0.02*0.03
         = 0.000385
组合波动 = sqrt(0.000385) ≈ 1.9621%
```

若相关为 1，组合波动是 2.5%；低于完全正相关时可能获得分散化效果。但估计误差和压力时期相关上升都会改变结果，相关矩阵也不是永远稳定的常数。

计算组合前，权重和收益必须按相同证券顺序对齐，见 [量化 Python 第 2 节](00d_量化Python实战.md)。收益缺失的持仓不能通过 `sum(skipna=True)` 自动抹去。

回撤依赖整条净值路径：

```text
running_peak(t) = max(V_0, ..., V_t)
drawdown(t) = V_t / running_peak(t) - 1
最大回撤（带负号口径）= min(drawdown)
```

对净值 `[1,1.1,0.99]`，最大回撤为 -10%，累计收益为 -1%。报告若写正的“回撤幅度”，则为 10%，需说明符号。

**初始净值 V_0=1 必须计入历史峰值。** 若第一期亏 10%，只对亏损后的 `[0.9,...]` 调 `cummax()`，会遗漏从初始资金开始的跌幅。配套脚本的 `wealth_and_drawdown()` 显式补入初始净值，并拒绝把缺失收益自动填零。

## 8. 年化、Sharpe 和主动收益

只在周期定义一致后讨论年化。等长、非重叠周期，每年约 K 期时：

```text
几何年化收益 = product(1+r_t)^(K/n) - 1
年化波动（近似）= std(r_t) * sqrt(K)
Sharpe（近似）= mean(r_t - rf_t) / std(r_t - rf_t) * sqrt(K)
```

无风险收益 `rf_t` 必须与同一期收益对齐，不能直接把一个年利率从每日收益中减掉。配套例子假设 rf=0，便于手算。

日频常用 K≈252，月频常用 K=12，等长非重叠 5 日期用 K≈252/5。若 5 日收益均值为 0.3%、标准差为 1%，近似 Sharpe 为 `sqrt(252/5)×0.003/0.01≈2.1298`。

平方根缩放依赖收益依赖性和稳定性等假设。有自相关、重叠窗口或不等长持有期时，不能机械套用；尤其退出延迟后的周期变长，应使用真实时间轴和合适方法。很短的样本即使能算年化，估计也可能非常不稳定。

组合与基准的单期主动收益为 `r_p-r_b`。例如组合 +8%、基准 +10%，主动收益为 -2 个百分点。IR 使用主动收益的均值/标准差并按声明的周期年化；它与 ICIR 不同。

多期相对财富为 `product(1+r_p)/product(1+r_b)-1`，不能直接把主动收益逐期相加当作相对净值。比较两个策略时，数据区间、现金占用、费用和基准要统一。

## 9. 最小二乘与中性化的数学直觉

用一条直线解释某个结果：

```text
y_i = a + b*x_i + residual_i
选择 a、b，使 sum(residual_i²) 最小
```

在程序中，截距对应一列 1，多个解释变量组成矩阵 X：

```python
import numpy as np

x = np.array([-2., -1., 0., 1., 2.])  # 准备五个输入值。
noise = np.array([0.001, -0.002, 0.002, -0.002, 0.001])  # 人为加一点误差，让数据不完全落在直线上。
y = 0.01 + 0.02*x + noise  # 按 截距 + 斜率×输入 + 误差 生成答案。
X = np.column_stack([np.ones(len(x)), x])  # 补一列全为 1 的数，用来估计截距；column_stack 把两列并排放好。
beta, _, rank, _ = np.linalg.lstsq(X, y, rcond=None)  # 最小二乘返回系数等四项；下划线表示这次不使用的返回值。
residual = y - X @ beta  # @ 按列加权求预测值；答案减去预测值就是残差。
print(beta)  # [0.01 0.02]
assert rank == 2  # 核对两列输入没有重复表达同一方向。
assert np.allclose(X.T @ residual, 0, atol=1e-12)  # 每列输入与残差逐项相乘再加总，应接近零。
```

最小二乘残差与用于拟合的列在该样本的内积为零；包含截距时残差之和也约为零。这不保证残差独立、正态，也不保证样本外关系成立。

同一个工具有不同研究用途：

| 用途 | y | X | 时间约束 |
|---|---|---|---|
| 因子中性化 | 当日原始因子值 | 当时已知的行业、市值等 | 不使用未来收益 |
| 因子收益评价 | 后来实现的收益 | 当时的因子与控制暴露 | 事后评价，不回流到信号 |
| 预测模型 | 训练样本的已实现标签 | 训练特征 | 参数仅由允许的历史训练/验证决定 |

若解释变量高度相似，系数可能很不稳定。含截距又加入全部行业哑变量会产生冗余；有效样本数也应明显多于待估参数。代码优先用稳定的最小二乘求解器，避免直接求 `(X.T@X)` 的逆。

Ridge 在误差之外加入 `alpha*sum(beta_j²)`，倾向于限制过大的系数；因为惩罚受尺度影响，需要理解标准化。梯度、特征值和复杂优化可以在进入机器学习时再系统展开。

## 10. 为什么漂亮的回测可能只是偶然

### 10.1 重叠收益与自相关

T 日的未来 5 日收益与 T+1 日的未来 5 日收益共享大部分价格区间。100 个逐日观测不代表 100 个独立的 5 日实验。同一天不同股票也可能一起受市场影响，不能仅按数据行数计算置信程度。

先做非重叠日期和分年度对照。更进一步可以采用 HAC 标准误或连续时间块重采样，而不是逐行随机重采样。时间块方法仍有块长、平稳性和样本规模限制。

脚本生成 120 个有正自相关的合成数值，按长度 10 的连续块重采样 2,000 次，保存每次均值，再取 2.5% 和 97.5% 分位数。固定种子的一次输出约为：均值 0.0045，均值区间 `[-0.0050,0.0137]`。这个例子展示“估计值为正，而不确定范围跨零”，不代表任何真实因子的结果。

不要通过反复调整块长来获得喜欢的区间。块重采样也不能修复数据泄漏、历史股票池偏差或结构突变。

### 10.2 多重尝试

假设每次检验在无效假设下都有 5% 假阳性率，做 20 个相互独立检验，至少碰到一次假阳性的概率为：

```text
1 - (1-0.05)^20 ≈ 64.15%
```

现实参数试验常常彼此相关，所以不能把这个数直接当作你策略的“造假概率”。它说明：试得越多再只挑最高值，越容易把偶然当成证据。

登记所有尝试，区分探索与验证；冻结公式、股票池、处理规则和成本后，用没有参与选择的连续时间区间验证。传统因子窗口、分组数和缩尾阈值也属于参数选择。

### 10.3 统计显著与经济价值

即使某种关系统计上较稳定，幅度也可能小到被成本吃掉。例如单期毛优势 0.10%，实际费用 0.15%，成本后为 -0.05%。反过来，短期高收益也可能来自市场暴露或偶然集中。

最终需要同时回答：关系是否存在、能否跨期重复、是否有新增信息、能否在交易约束与成本下保留。p 值也不是“原假设为真的概率”，更不是“策略未来赚钱的概率”。

## 11. 综合练习与答案

| 练习 | 答案或核对要点 |
|---|---|
| +10%、-10% 的累计收益和最大回撤 | -1%、-10%；净值从 1 开始 |
| `[1%,-1%,2%,0%]` 的均值和样本标准差 | 0.5%、约 1.2910%，样本标准差用 ddof=1 |
| 两只等权股票波动 2%、3%，相关从 0.2 升至 1 | 组合波动从约 1.9621% 升至 2.5% |
| 四股票例子的因子排名整体取反 | RankIC 从 0.8 变 -0.8；方向不能看测试结果后决定 |
| 因子全为常数 | 相关无定义，应记录 NaN 与原因 |
| 5 日收益换算 Sharpe | 使用对应周期，不能直接用 sqrt(252)；重叠与延迟还需额外处理 |
| 100 日 × 300 股是否等于 30,000 个独立样本 | 不等于，需要考虑时间重叠和股票之间共同波动 |
| 20 个窗口中只有一个表现突出 | 探索结果；登记全部尝试，检查邻域并做时间留出 |
| 第一笔亏 10%，怎样保证回撤不会漏算 | 将初始净值 1 纳入历史峰值 |

完成本章的标准：能解释收益、波动和均值不确定性的区别；能手算 RankIC、组合收益与回撤；能说明一个正的历史指标为什么尚不足以支持策略结论。
