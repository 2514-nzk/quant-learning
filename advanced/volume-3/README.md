## 第 01–04 章首批正式正文与独立教材数据

第一批已建立完整的**策略立项 → 市场状态 → 周频行业轮动 → 反转/动量条件排序**教学路线：

- [第 01 章策略合同](01_strategy_contract.md)：周五信号、18:00 决策、人工下一交易日入场、标签可得与成本代理的完整合同；
- [第 02 章市场状态](02_market_regime.md)：冻结 RISK_ON/RISK_OFF 定义，同一数据上的条件和无条件基线；
- [第 03 章行业轮动](03_industry_rotation.md)：TEACH_OLD/TEACH_NEW 的人工行业分类与 PIT 成员身份；
- [第 04 章反转/动量](04_reversal_momentum.md)：REV20/MOM5、Spearman、强弱行业条件与统计解释边界。

数据集 [volume3-weekly-synthetic-v1](../../data/teaching/volume3_weekly_v1.json) 完全属于教材自身：16 周 × 四行业 × 八只虚构股票，含未来标签晚到、行业分类变化、成员未知的失败反例。此数据**绝不代表实际申万分类或 A 股收益**，后八期只是人工时序演示，不是独立市场 OOS。
