# 深度专题 A｜从一个因子到可信的研究报告

这一篇接在[第 8 章：单因子研究与评价](08a_单因子研究与评价.md)之后。如果你第一次学习量化，先读原第 8 章的四股票手算，再回来完成本篇。

**学习目标：** 自己从原始评分得到每一期 RankIC、分组差异、换股名单、成本后资金；区分“有排序信息”“多头能赚钱”和“能在真实市场成交”；最后给出一份明确写出不利证据的因子报告。

> 全文只使用本仓库人工构造的 A/B/C/D、60 个非真实交易期。后 56 期数据由设定的生成机制产生，不能用于证明 A 股存在动量、EP 或 ROE 异象。

## 1. 先定义研究问题，别急着算 IC

小林提出：过去五日涨幅越高，未来五日收益是否越高？

这句话里至少包含六个必须固定的设定：

| 项目 | 本书教学选择 | 换到真实 A 股时要问 |
|---|---|---|
| 股票池 | A、B、C、D 四只 | 是否含已退市股票？历史时点成员是否正确？ |
| 信号 | 过去五日涨幅 | 价格使用哪个复权版本？停牌如何对齐？ |
| 观察时刻 | D006、D012 等信号日收盘后 | 实际决策截止时刻、时区是什么？ |
| 标签 | 次一交易日开盘买，指定第五日收盘卖 | 交易端点、分红、不可卖出如何处理？ |
| 指标 | 每期 RankIC 与 Top-2 / Bottom-2 | 主指标是否事先指定？ |
| 实现假设 | 全成交、虚拟份额、固定双边费率 | 现实交易单位、费用、滑点与容量？ |

现在的研究是**固定解释教学结果**。你可以同时计算动量、EP 和 ROE，但不要事后比较三者的测试成绩，再把最好的一个写成“唯一提前提出的假设”。

**判断题**：假如另一个研究者只写了“动量回测很好”，没有保存股票池和信号时刻，能复现吗？不能。哪怕公式相同，输入和标签也可能完全不同。

## 2. 手算 RankIC：相关的是名次，不是收益金额

R01 的四只股票：

| 股票 | 动量 | 动量升序名次 | 未来收益 | 未来升序名次 | 差的平方 |
|---|---:|---:|---:|---:|---:|
| A | 8% | 4 | 5% | 4 | 0 |
| B | -1% | 1 | 1% | 2 | 1 |
| C | 4% | 3 | 3% | 3 | 0 |
| D | 2% | 2 | -2% | 1 | 1 |

没有并列时，Spearman 可以用短公式：

\[
\rho_s = 1-\frac{6\sum_i d_i^2}{n(n^2-1)}
\]

本期 n=4、平方差合计为 2，所以：

\[
1-\frac{6\times 2}{4(4^2-1)}=0.8
\]

如果有并列：先给并列项**平均名次**，再算两组名次的 Pearson 相关；不能继续硬套上面的无并列公式。所有分数相同或所有标签相同时，相关性没有定义，不能把它改写成 0。

**重点：** IC=0.8 不是“赚了 80%”、不是胜率 80%，也不意味着未来哪个个股会赚钱。

## 3. 从四只股票的高低组，到更大截面的分层

每一期把动量从高到低排序，取前两只和后两只。R01 前两只 A/C 平均未来收益 (5%+3%)/2=4%；后两只 D/B 平均 (-2%+1%)/2=-0.5%；差为 **4.5 个百分点**。

R02 同样选 A/C 为前两只，后续收益为 4%；但后两只收益达到 7%，因此高低差反而是 **-3 个百分点**。

你应该同时报告：

- **排序层：** 每期 RankIC 与其时间序列；
- **分组层：** 每期高组、低组、组间差以及是否单调；
- **资金层：** 只买高分股的现金结果、费用和执行差异。

高减低常是研究里的多空诊断，但对未允许做空或未模拟融券的 A 股故事而言，**不能把这个差值直接称为能赚到的多空收益**。四只股票只够分成透明的两组，不足以做稳健的五分位研究；真实五分位需要足够多的横截面股票与预设的缺失处理。

<details>
<summary>自测：高减低始终为正，是否一定有正的多头收益？</summary>

不是。假如高组平均 -1%、低组 -4%，高减低为 +3 个百分点，但只买高组依旧亏损；如果还有手续费和冲击，多头会更差。

</details>

## 4. 为什么逐期 IC 不等于把全部股票行混在一起算一次？

本书每期四只股票，60 期共 240 行。正确的横截面因子评价先在**每个信号日**做排名相关，再对时间求统计量：

\[
IC_t=\operatorname{Spearman}_i(f_{i,t},r_{i,t+1:t+h})
\]

\[
\overline{IC}=\frac{1}{T}\sum_{t=1}^{T} IC_t
\]

如果把所有日期和股票混在一起求 Spearman，可能混入截面之间的整体水平与不同期的市场背景，那回答的是另一个问题。特别是市场同涨同跌时，一次全样本相关会掩盖每一期内部排序的失败。

固定数据每期只有四股，练习里每个有效期按一票计。现实评价可采用按样本数加权等不同汇总方式，但需要事先定义，不能依据结果挑加权方法。对没有足够有效股票的日期应记录为无效，而不是悄悄删除。

## 5. ICIR 与正 IC 比例：它们各回答什么？

一个常见描述量是：

\[
ICIR=\frac{\operatorname{mean}(IC_t)}
{\operatorname{std}(IC_t)}
\]

这里的 std 是**每期 IC 的样本标准差**。它衡量“平均 IC 相对于跨期波动有多大”；正 IC 比例则只数有多少期为正。一个因子少数几期极高、其它时期为负，可能均值为正但正 IC 比例很低。

不要在没有报告频率、重叠区间及自相关的情况下随手乘以一年交易期数的平方根。样本期数非常少、标准差为零或相邻标签重叠严重时，ICIR 的解释也会受限。

重要的是**不要给人工数据上的 ICIR 贴上实盘可交易标签**。它还没有回答换手率、资金容量、买不到和卖不掉的问题。

## 6. 在本仓库亲手运行 60 期因子诊断

无需安装 NumPy 或 LightGBM。进入仓库根目录后执行：

~~~powershell
python examples/factor_diagnostics_lab.py
python examples/factor_diagnostics_lab.py --factor ep
python examples/factor_diagnostics_lab.py --factor roe
python examples/factor_diagnostics_lab.py --factor equal_rank
python examples/factor_diagnostics_lab.py --json
~~~

可选因子固定为 **mom_5、ep、roe、equal_rank**。输出按三段分别统计：

| 区间 | 用途 | 期数 |
|---|---|---:|
| R01–R36 | 训练历史（描述） | 36 |
| R37–R46 | 验证候选（描述） | 10 |
| R47–R60 | 冻结测试段（描述，不再选参） | 14 |

代码每期先生成分数，再读取事后答案计算 RankIC；同时计算高低差、名单更替比例、Top-2 和四股等权基准的成本后期末金额。单边默认 0.1%，两侧按成交额扣除，资金从 8,000 元开始、每个区间**分别重新起算**。

**注意三个边界：**

1. 把 ep、roe 等所有因子都列出来，允许比较教学结果，但绝不允许据此重选“正式研究在测试前已经选中的指标”。测试值不是新的调参区。
2. 本实验显示的**名单更替比例**是相邻两期 Top-2 成员替换的数量比例，不是实际组合按成交金额定义的换手率；由于故事每期完全清仓，二者尤其不能混为一谈。
3. 期末资金是同口径“全成交 + 固定费率”纸面账，没有 A 股真实订单、税费历史、价格冲击与停牌。每个区间从 8,000 元起算，其终值不能直接相加。

练习：把费率由默认 0.001 改成 0.005 再运行。检查高低组统计是否不变、净资金是否因费率变大而下降。若你的程序发现换费率后 RankIC 也变化，说明把预测层和执行层错误地混在了一起。

## 7. 为什么好看的样本均值还不够？

### 7.1 覆盖率和生存者偏差

现实项目每期不仅报告有效股票数，还报告信号时点的候选数、每个字段的缺失原因及退市历史范围。某只后来退市的股票不能因为今天找不到行情就从所有历史样本中消失。否则“有完整未来收益的样本”往往比真实可研究股票池更漂亮。

### 7.2 行业、规模与风格混杂

假如高分组集中在单一行业，上涨可能主要来自行业共同表现。可以按事先定义的行业组内排序、行业哑变量回归或构造行业匹配对照，比较因子信息是否仍存在。对于只有 A/B/C/D、没有真实行业字段的教学数据，**不应该硬造一张“行业中性化有效”的表**。

### 7.3 参数和周期敏感性

一个五日动量因子，还可以试 10 日、20 日；但新窗口需要真实的对应历史价格和新的时间边界，不是把原有 mom_5 数字乘 2。要预先指定候选范围和评价指标，保存全部尝试，最终在没有参与挑选的未来时期确认。

### 7.4 统计推断与多重比较

一项检验的 p 值，只在给定原假设与统计假设下解释。如果同时检验几十个因子、持有期和子市场，最好的那个常带有选择偏差。相邻时期因子 IC 也可能自相关，不能总用按期独立重抽的 bootstrap 当成现实证据。

研究报告应清晰分开：效应方向、效应大小、不确定性、经济可执行性。不同问题不能只靠一个“显著”二字代替。

## 8. 交一份可复查的单因子报告

至少保存下面几项，能复算才算完成：

| 交付 | 最低验收 |
|---|---|
| 因子定义卡 | 公式、方向、单位、历史字段、可用时刻、缺失规则 |
| 样本与时间审计 | 股票池与退市覆盖、标签结束时刻、训练/验证/测试边界 |
| 截面诊断 | 每期有效股票、RankIC、ICIR、正 IC 比、Top-2/Bottom-2 |
| 执行对照 | 纸面毛收益、双边费率、成交限制、资金和现金账 |
| 不利证据 | 负 IC 时段、失效时期、参数与成本敏感性 |
| 复现记录 | 输入指纹、代码版本、候选尝试和未来独立评价计划 |

自查三问：**是不是只有“未来才知道”的数据才能算出我的分数？报告中的收益有没有被当成实际成交？我是不是看了测试再修改研究规则？** 任何一个答案为“是”，都不能把结果写成独立验证的选股 Alpha。
