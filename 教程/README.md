# A 股量化研究入门：从问题到样本外证据

你拿出 8,000 元虚拟资金，从四只股票中选两只，第一次赚了 320 元。规则有效了吗？接下来，你和虚构的研究搭档小林会遇到跑输、亏损、未来信息、买不到，以及训练漂亮却不能兑现的模型。

本书沿这一次纸面研究展开。先用两节起步课算懂第一笔，再按五编、十六章向前读。每章解决一个上章留下的问题，保留尝试、错误和修改的理由。所有股票与数据均为教学构造，配套演算和模型结果可以重做。文件名中的旧编号仅用于仓库内部管理。
