# 第二卷 · 07｜因子工程、表达式与中性化

> **状态：教学正文初稿；合成因子流水线可复算。** 本章尚未接入真实大截面 A 股数据、财务公告或完整行业历史版本。代码运行成功只能证明部分算法口径，不代表真实 Alpha。

## 研究问题：因子到底在表达什么？

“过去涨得多”“规模较小”“盈利质量较好”是不同经济假设。它们必须先被转换为**具有明确时间与单位的数学表达式**，再进入因子工程。因为一个看似稳定的因子可能只是在重复行业和市值暴露，中性化必须回答：**剔除这些暴露后，它还剩下什么？**

第 05 章的 PIT 规则是本章前提；第 06 章的切分约束决定了哪些数据可以拟合预处理器。

## 1. 从直觉到因子定义卡

每个因子至少记录以下属性：

| 字段 | 举例 | 审计点 |
|---|---|---|
| `factor_id` | `REV20_v1` | 固定语义与版本 |
| `universe` | 当时属于某动态股票池的证券 | 上市/退市/行业历史证据 |
| `expression` | `-(P_t/P_(t-20)-1)` | 端点与价格复权口径 |
| `lookback` | 20 个交易日 | 不是自然日；明确缺失规则 |
| `signal_at` | 预先规定的交易信号时刻 | 交易所日历 |
| `known_at` | 所有输入最晚可得时刻 | 不晚于特征截止 |
| `unit` | 原始值为小数收益 | 例如 0.05 是 5% 而非 5 |
| `direction` | 值越高代表越强反转预期 | 事前确定 |
| `missing_policy` | 上市过短时缺失 | 不能用未来补齐 |

表达式中的 `P_t` 必须对应约定的市场价格版本。如果信号在 t 日开盘前形成，就不能读取 t 日收盘；若 18:00 决策，可使用已知的 t 日收盘，但也必须记录行情何时完成入库。

### 1.1 算子语义会改变结论

对滑动收益、标准差、秩、相关性等算子，应逐一约定：含不含当前 bar、最小观测数、缺失传染、复权端点、停牌日是否计入窗口、相同数值如何处理，以及横截面对象是谁。

例如“过去 20 日涨幅”可能被实现成 20 个**交易日期的端点之差**，也可能错误地对每只股票表格直接使用 `shift(20)`，这在停牌和缺失日期时会产生不同的实际时间跨度。正式研究不能靠函数名替代口径说明。

## 2. 数据清洗、缩尾和标准化是研究决策

一套常见横截面流水线为：

~~~text
PIT raw inputs
 -> factor expression and historical eligibility
 -> missingness audit and known-at cutoff
 -> predeclared clipping / winsorization
 -> cross-sectional standardization
 -> industry and size exposure residualization
 -> coverage / exposure / rank / turnover diagnostics
~~~

本章合成实验选定每期横截面 10% 和 90% 的**线性插值分位数**作为上下裁剪点：

\[
x^{clip}_{i,t}=\min(\max(x_{i,t},q_{0.10,t}),q_{0.90,t}).
\]

随后按当期样本均值和总体标准差进行：

\[
z_{i,t}=\frac{x^{clip}_{i,t}-\bar{x}^{clip}_t}{\sqrt{\frac1{N_t}\sum_i(x^{clip}_{i,t}-\bar{x}^{clip}_t)^2}}.
\]

这里只是公开选择了一个教学处理方案，**并不表示 10%/90% 是市场公认的最优阈值**。如果全截面因子恒定或有效样本过少，不能输出一个看似有效的零向量；本章程序直接报错。

### 2.1 “当期横截面”与“未来拟合参数”的区别

如果某日全市场的因子值在做决策前已知，那么仅用当日已知横截面求均值、分位数和标准差，不自动构成未来泄漏。

但用未来年份的样本拟合缺失值填充器、PCA 主成分、整体标准差或机器学习预处理参数，再回测较早时期，则会污染历史预测。应由研究合同决定哪些变换是**当日可计算的截面变换**，哪些参数必须只在训练集 `fit`。

此外，极端值可能具有真实经济含义；缩尾会改变因子本身，必须报告处理前后相关性、分布及结果敏感性。

## 3. 行业和规模中性化到底在做什么？

在信号日 t，把已标准化因子 z 用当时行业哑变量和对数市值解释：

\[
z_{i,t}=\alpha_{g(i),t}+\beta_t\log(M_{i,t})+\epsilon_{i,t}.
\]

这里 g(i) 是该时点 PIT 行业归属；M 必须是定义明确且当时可得的市值。将残差 `epsilon` 作为“行业与规模中性化后的因子”，只表示在指定的回归模型和暴露定义下**样本内线性正交**，不等同于消除一切风险或获得市场中性收益。

### 3.1 用组内去均值理解 Frisch–Waugh–Lovell

先对每个行业分别去均值：

\[
z_i^*=z_i-\bar z_{g(i)},\quad
s_i^*=\log M_i-\overline{\log M}_{g(i)}.
\]

然后拟合共用规模斜率：

\[
\hat\beta=\frac{\sum_i z_i^*s_i^*}{\sum_i(s_i^*)^2},
\quad
\hat\epsilon_i=z_i^*-\hat\beta s_i^*.
\]

若分母为零，意味着规模与行业在该截面中完全共线，无法识别规模系数；程序应明确报错，而不是悄悄加一个未经记录的随机扰动。本章的脚本使用等权回归，残差再标准化供比较；行业为三组人工类别，仅是数学演示。

这里每个交易日重新估计的中性化回归，是**当日已知截面上的变换**。如果行业成员来自今天的分类、规模来自未来版本，残差再漂亮也不能纠正前视。

### 3.2 为什么要报告中性化前后？

应至少展示原因子与残差的 Spearman 相关、行业均值、规模相关、覆盖率、尾部截断比例和排名变动。若中性化后几乎没有剩余变化，说明原信号可能主要来自行业/规模，不能强行加标准差输出信号。

中性化不等于组合约束：即使因子残差行业均值为零，选 Top-N 后的**持仓**依然可能行业集中、拥挤、不可成交。需要在组合层再审计暴露。

## 4. 在仓库运行完整合成因子流水线

[实验源码](../../examples/advanced_factor_research_lab.py) 通过 `make_synthetic_panel()` 生成 12 个周度时期、每期 12 只人工证券，三个人工行业，和预先构造的规模与因子值。执行：

~~~bash
python examples/advanced_factor_research_lab.py --json
python -m unittest discover -s tests -p "test_advanced_factor_research_lab.py" -v
~~~

关键函数 `transform_factor_day()` 对每个时点分别：分位缩尾、z-score、行业组内去均值、规模系数回归、残差标准化。它**没有读取 `future_return`**；单元测试把所有未来收益替换成完全不同的数字，因子变换结果必须保持不变。

其他边界测试验证：单日信号日期一致、缺失/非法因子数值、规模与行业完全共线、行业残差均值约为零、与规模的样本协方差约为零。

### 4.1 实验结果如何解读？

这些近似零的残差暴露是代数性质，**不是发现 Alpha 的证据**。由于因子、规模、行业和收益均由合成公式制造，任何相关或四分位收益都不能推广到真实 A 股。

真实研究至少还需要：有历史版本的行业成分与市值、完整交易所日历、因子覆盖与复权审计、分期稳定性、交易成本和换手影响，以及预注册条件检验。

### 4.2 真价格因子，不等于真 PIT 因子

新增 [四股证据审计](REAL_DATA_EVIDENCE_REVIEW.md) 用真实历史收盘价验证 `MOM5 = close(signal)/close(signal-5)-1`，并用未来价格变动检验信号隔离。但四股样本是事后选择，缺少完整历史母体、行情消息入库时刻及真实行业/规模成员，因此**不能**把该案例扩展为全市场中性化的证据。原行业/规模残差化仍是合成截面演示。

## 5. 可复核练习

**题 1。** 用 2026 年的最新行业分类回填 2020 年的证券，计算 `factor_neutral` 合法吗？

答：不能直接称为严格 PIT。必须获得当时行业体系/历史成员、并说明分类切换口径。

**题 2。** 将训练、验证和测试三段所有日期的特征合在一起拟合一个全局 StandardScaler，再研究 2023 年预测，是否存在数据泄漏风险？

答：存在。整体分布统计量已见过验证/测试时期，应只在训练期拟合，随后应用到未来样本。

**题 3。** 行业固定效应加规模回归后，残差对行业和规模样本线性正交，是否意味着 Top-N 组合行业完全均衡？

答：不意味着。截面残差的线性约束与极端分数选股后的组合权重约束不同。

**题 4。** 发现某日行业内规模没有变化，无法识别规模系数，应该怎么办？

答：明确标记不可识别，按事前制定的退化处理规则选择跳过或改变规格，不能为了通过测试事后添加任意处理。
