# 第三卷 · 03｜周频行业轮动

> **状态：教学正文 v1；冻结历史分类版本的周度行业排序、成员门禁和成本代理已实现。** 本章使用自编 TEACH_OLD/TEACH_NEW 行业分类与人工未来收益；未接入真实申万历史成分或任何真实 A 股轮动收益。

## 本章核心问题：选“最强行业”，到底在比较谁？

周频行业轮动常见想法是：每周五观察行业强弱、选择得分最高的行业，下一交易日建仓，之后按新信号调仓。问题不是排序函数多复杂，而是行业体系会调整、成分股会进出、停牌和退市会影响可交易母体。**如果历史行业成员用今天的代码反推，连研究对象都可能错。**

本章教你写出可以检查的行业历史版本、权重和评价协议。它不声称“四周强势必然继续领涨”，也没有通过真实市场的 OOS。

## 1. 研究对象是历史时点的行业定义

真实 A 股行业研究必须明确：

1. 行业分类供应商及版本，比如历史申万体系，而不是只写“申万一级”；
2. 分类版本的**生效日**、证券成员的进出有效区间；
3. 变动公布/可使用的时点；
4. 历史证券身份键与股票代码的有效区间；
5. 轮动收益由行业指数还是成员股票组合构成，价格、公司行为与费用口径；
6. 当历史成员不完整时的 UNKNOWN，以及如何计算分母和覆盖率。

本教材不是现实申万复现。它为教学设计了两个虚构分类版本：

| 时段 | 分类版本 | 行业代码 | 教学目的 |
|---|---|---|---|
| 人工第 1–8 周 | TEACH_OLD | O_A / O_B / O_C / O_D | 固定旧分类的含义 |
| 人工第 9–16 周 | TEACH_NEW | N_A / N_B / N_C / N_D | 展示版本切换对成员与持仓的影响 |

例如 S02 从旧版本 O_A 归入新版本 N_B，S04 从 O_B 归到 N_A。**这只是人工构造的分类变化，绝不能写作真实的申万行业迁移事实。** 教材实验不自动把 O_A 等同于 N_A，也不使用未来行业成员回填历史。

### 1.1 两个不同问题：历史属于哪个行业，与现在能否交易

每条人工股票成员记录有 security_id、industry_code、membership_known_at。定义可用成员集合：

\[
U_t^{\mathrm{known}}=
\{i:\mathrm{membership\_known\_at}_i
\le \mathrm{feature\_cutoff}_t\}.
\]

某项身份晚于当前截止时，该证券应该记为 **UNKNOWN**，不是“不在行业里”，也不是“可以正常交易”。第 7 周 S03 的成员信息故意迟到，在时点实验中被排除出已知成员；参考母体仍为八只，已知成员只有七只。

正式研究需要上市、退市、历史分级、公司行为和可交易资格数据支持。已知行业成员也可能停牌、涨跌停无法成交；历史分类并不替代订单执行审计。

## 2. 行业强弱因子与未来标签必须分列

本教材行业评分是事先观察到的人工过去四周收益：

\[
s_{g,t}=R^{\mathrm{past\ 4w}}_{g,t}.
\]

从当期同一分类版本的四个行业中确定：

\[
\hat g_t=\arg\max_{g\in U_t^{industry}}s_{g,t},
\]

并按 **过去收益降序、行业代码字典序** 处理完全相等的评分。这个并列规则是预先确定的教学实现，不暗示字典序较小的行业更有经济价值。

行业未来一周收益记作 \(y_{g,t}\)，只能在计划退出价形成且标签到达以后用于评价。**先看 next_return 再决定排名属于前视泄漏**。本书的 industry.future_return 是手工写入的人工数值，**不是根据八只股票真实成交价重建的指数**；不能将它与股票自身的人工收益混为一种可直接交易的行业基金价格。

### 2.1 从行业排名到单只证券还差几步？

真正的行业多头至少需要：

- 行业成分与股票权重（等权、市值权重或指数权重）在历史当时已知；
- 同一入场/退出时刻可用的证券报价、复权/分红与退市现金流；
- 成员内无法买入、卖出和价格缺失的处理；
- 真实成本、交易额参与比、持仓上限、行业风险；
- 行业体系切换后的旧持仓与新目标之间的**证券级**映射。

**行业评分排序不等于能买到行业收益本身。** 本章是行业目标权重算术实验，非已完成的可执行成分股组合。

## 3. 周度信号与交易标签的时间合同

本书一律采用第 01 章固定的人工时间：

~~~text
周五 14:50 人工行业历史强弱可得
周五 15:00 信号/特征截止
周五 18:00 目标行业与权重确定
下一周一 09:30 假定入场观察
再下一周一 09:30 假定退出观察
退出后 09:45 模拟标签可供训练
~~~

注意标签可用时刻晚于前一周信号，**不能用上周信号的整段未来收益直接训练下一周模型**。这与第 01 章的前向 Purge 相同。

在真实 A 股里，周五若休市、周一若非交易日，入场要按真实市场日历寻找可行交易日，并根据预设价格和可成交资格处理；不能用自然日固定加三天。对行业分类切换，所有结果必须保留所属版本，不能把不同分类体系的逐行业 RankIC 当作同一对象直接纵向拼接。

## 4. 对照策略、收益与成本代理

保留四条先验分支：

| 分支 | 规则 | 基本意义 |
|---|---|---|
| cash | 全现金 | 无持仓的零观察收益对照 |
| equal_four | 每期四行业各 25% | 同版本行业等权 |
| always_top | 当前历史最强行业目标 100% | 行业排序单独贡献 |
| regime_gated_top | 仅在第 02 章 RISK_ON 时持有 Top1 | 市场条件的额外约束 |

对每期人工目标 \(w\)：

\[
R_t^{\mathrm{proxy}} =
\sum_gw_{g,t}y_{g,t}
-c\sum_g|w_{g,t}-w_{g,t-1}|.
\]

人工费用系数 \(c=0.001\)。为了避免混淆，教材把这个数字命名为 synthetic_net_observation；它**不是**扣除了实际税费、冲击和未成交的真实净利润。

跨 TEACH_OLD 和 TEACH_NEW 时，由于没有证券级连续权重映射，当前教学程序将旧行业代码和新行业代码视为不同目标；其 L1 变动可能偏大。若把这一指标直接当作真实行业轮动换手或成本，就是**错误的经济解释**。

## 5. 最小模型验证协议：为什么前八周与后八周仍非真实 OOS？

本书 16 个人工周期中，第 1–8 周称开发部分，第 9–16 周称 later_artificial。程序没有用后段的未来标签拟合行业排名，故可测试算法有无直接未来读取。

但数据是教材作者预先人为生成的；该后段从来不是外界后来才发生的不可提前知道的真实市场收益，**不能因为代码沿时间顺序运行就宣布有独立 OOS**。

真正的周频行业研究还需要 PIT 行业与股票母体、冻结信号时间、逐日或逐期实际收益、训练折叠与标签延迟、未触碰确认期、基线配对差分区间及成本容量。即使行业分类的两个历史版本在数据里都齐全，也不能跳过缺失值/退市/停牌审计。

## 6. 可运行的行业轮动教学实验

~~~bash
python examples/volume3_strategy_lab.py --json
python -m unittest discover -s tests -p "test_volume3_strategy_lab.py" -v
~~~

结果中 taxonomies 必须有 TEACH_OLD 与 TEACH_NEW；unknown_members 为 **1**；strategies 中每一分支都保存 16 期目标行业、人工毛观察收益、换手与费用代理。

实验还执行：改写任意未来行业收益时，**历史行业排名必须不变**；第 7 周的迟到股票成员不可进入已知证券集合；错误混用两种分类代码、重复股票身份、未来已知特征应直接报错，而不是悄悄填补。

### 6.1 不能做的统计推断

四行业的平均排序、前后 8 周观察收益和现金代理在这里只能被描述为**人工数值**。若某一分支的人工平均收益大于另一分支，不能据此产生显著性结论或“实盘月收益”；16 周且有类别切换、价格生成机制变化，远远不足以证明市场优势。

## 7. 习题与参考答案

**题 A：** S02 在第 8 周属于 O_A、第 9 周属于 N_B，可否直接把 O_A 与 N_A 视作同一真实行业？

答：不能。二者属于不同人工分类版本，需要明示映射和历史成员证据；真实分类更应使用正式发布的历史表。

**题 B：** 八只参考股票中有一只成员信息到下周才可得，能否删掉该证券后宣称“全市场覆盖 100%”？

答：不能。可判定率为 **7/8**，未知一只不能自动被认定为退市或不可交易，母体分母仍为八只。

**题 C：** 周五晚得到行业第一名，但下一周一因涨停无法买入，可以直接使用行业后续观察收益作为账户盈利吗？

答：不能。目标信号不等于成交，必须另有可交易的股票清单、成交数量、报价与现金账本。

**题 D：** 16 期合成行业排名的后 8 期效果比前 8 期好，能称真实 A 股未来 OOS 吗？

答：不能。后期收益由教材人工生成，仅用于程序时序逻辑验证；现实市场研究需要重新冻结并独立验收。
