# 第 12 章｜决策树、随机森林与过拟合

你已经会：线性模型、验证集和过拟合。这一章只问：切分和随机森林带来的是信息，还是容量？

Ridge 把输入乘权重再相加。你盯着这条式子，觉得它漏掉了一种情况：

“也许只有盈利质量较好时，动量才有用。”

小林说：“那就让模型自己找条件。”


**先把决策树想成一个会问问题的分岔路口。** 比如先问“过去涨幅有没有达到 4%”，回答“是”走左边，回答“否”走右边，最后两个方向给出不同分数。


## 1. 树的切分、叶子与误差

第一期的真实排名标签为 A 1.00、B 0.50、C 0.75、D 0.25。如果暂时所有股票都给一样的预测，平均标签是 0.625。

现在按“过去涨幅是否至少 4%”切开：

| 条件分支 | 股票 | 分支内标签均值 |
|---|---|---:|
| 至少 4% | A、C | 0.875 |
| 低于 4% | B、D | 0.375 |

先猜：切开以后，训练误差会降多少？

<details>
<summary>展开核对</summary>

给组里每个样本相同预测，误差平方和从 0.3125 降到 0.0625。只看这一小段训练题，切开确实更贴合答案。

</details>

最末端的小组叫**叶子**。树会继续找特征和阈值，把训练误差降下来。


### 用两句“如果……那么……”就能做预测

根据本章 R01 的四只股票，先提出一条很简单的规则：

```text
如果过去涨幅 ≥ 4%：给预测分数 0.875（A、C 那一组）
否则：给预测分数 0.375（B、D 那一组）
```

这个 0.875 不是上涨概率，而是**这一组训练样本的平均名次标签**。你看，它本质上仍是一句“如果……那么……”的程序。

但如果继续加条件：“如果是 A 就给 1.0，如果是 C 就给 0.75……”就可能把四只股票的旧答案背下来。下次换一批日期，背答案未必有用，这就是**过拟合**。

<details>
<summary>试一下：一棵树把 R01 的四只股票全背对了，能保证 R02 也全对吗？</summary>

不能。R02 的未来强弱可以变。训练集得分很高只说明做过的题答得好，验证和测试才帮助我们观察遇到新日期是否也答得好。

</details>


## 2. 模型容量与过拟合

你很快想到：继续分到四只各自一个叶子，这期训练答案就能被记得几乎一模一样。

但 R02 的真实强弱顺序变了。R01 的细碎分法并没有保证下一期也成立。这是模型容量过大、把偶然细节也学进去的一个直觉。

你们不靠这张四股票小图选参数，而是在第 4 章划定的训练和验证区间里比较。

## 3. 随机森林的深度比较

随机森林给多棵带随机差异的树做汇总。你们固定 100 棵树和随机种子，只改变最大深度：

先猜：如果不限制深度，验证成绩会最好吗？

| 最大深度 | 候选训练平均 RankIC | 候选验证平均 RankIC |
|---|---:|---:|
| 2 | 0.5278 | 0.3800 |
| 4 | 0.7611 | 0.4200 |
| 不限制 | 0.9833 | 0.2600 |

<details>
<summary>展开看这次为什么没有保留最深的森林</summary>

不会。不限制深度的训练成绩接近满分，验证反而最低。按事先的验证选择规则，保留深度 4。训练更贴合，不等于后来样本也更好。

</details>

这些是固定教学数据上实际运行的结果，不表示真实市场也应选深度 4。我们学习的是比较动作和选择职责。

## 4. 深度与叶子样本数

`max_depth` 限制最多往下分多少层；`min_samples_leaf` 限制一个叶子至少留下多少训练样本。

它们都会影响能否把训练表切得很碎。不是参数越小或越大总是更好，而是增加容量以后，验证证据是否跟着改善。

```python
from sklearn.ensemble import RandomForestRegressor

# 下面是本次选定的设置，尚未开始拟合；其余切分由故事脚本负责。
model = RandomForestRegressor(
    n_estimators=100,  # 一百棵树汇总预测。
    max_depth=4,  # 验证集选定的深度。
    min_samples_leaf=1,
    random_state=42,  # 固定随机种子，便于重做。
    n_jobs=1,
)
```

OOB、重要性与更完整的参数取舍见[模型参考](参考_模型比较与解释.md)。内部抽样得到的诊断，仍不能替代向未来的时间评价。

## 5. 验证比较与最终评价

深度 4 的 0.42 略高于 Ridge 的 0.40。你暂时把森林保留为候选，没有因此换掉最后那段测试卷。

下一章还会出现一种树：它不只把各棵树平均，而是一次次尝试修正前面的错误。听起来应该越修越好，结果却未必如此。


## 选读｜进阶训练：模型容量、集成和时间外推

**入门关**：一棵回归树在每个叶子输出训练样本标签的代表值；分得越细，通常越容易贴合训练题。但贴合不是泛化。

**进阶关：解释随机森林如何降低不稳定性。** 不同树在训练样本的随机抽样与候选特征选择上产生差异，最终平均多棵树的预测。多棵树可以降低单棵树的方差，但不能自动解决错误标签、未来数据混入或时间变化。

建议分别比较这几项，而不是一次调整所有参数：

| 参数 | 主要影响 | 应记录的失败信号 |
|---|---|---|
| max_depth | 树能切多深 | 训练 IC 大涨、验证 IC 下降 |
| min_samples_leaf | 一个叶子最少样本 | 叶子过小导致训练记忆 |
| max_features | 每次分裂候选特征数量 | 与高度相关输入一起影响分裂 |
| n_estimators | 汇总多少棵树 | 耗时增加但验证证据没有改善 |

**研究关**：把最大深度 2、4、不限制三版的训练和验证指标画在同一张表，并保留所有结果。树的特征重要性不能当成因果效应；相关特征可能相互分摊重要性，删除后重训的消融与打乱列的置换也回答不同问题。若试图用 OOB 分数替代未来时间评价，需要指出它没有模拟真实向前的时间关系。
