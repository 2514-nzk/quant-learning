# 贯穿案例：数据与运行说明

正文从同一笔 8,000 元虚拟资金出发，用四只虚构股票 A、B、C、D 演示研究过程。这里的数值均为编写教学题目而构造，不是下载的市场行情，也不是实际投资成绩。

## 三份材料各做什么

- `rounds.csv`：60 期、每期四只股票的固定横截面，共 240 行。前四期专门设置为“首次获利、跑输对照、发生亏损、进一步回撤”；后 56 期是固定随机种子生成的练习样本。
- `price_history.csv`：第一期之前六个教学交易日的归一化价格指数，用来重算第一期的过去五日涨幅。每只股票起点设为 100；它不是实际成交价。
- `model_results.json`：用配套脚本实际运行得到的参考输出，包括输入与脚本指纹、库版本、候选参数、验证成绩和测试成绩。

重做基础演算：

```powershell
python examples/story_research.py
```

重做模型练习并保存自己的报告：

```powershell
python examples/story_research.py --models --output outputs/story/report.json
```

复算第 14 章的置换检验、bootstrap 区间与 oracle 对照：

```powershell
python examples/story_evidence.py
```

基础演算只用 Python 自带功能；模型练习需要项目 `requirements.txt` 中的 NumPy、pandas、scikit-learn 和 LightGBM。报告中的文本指纹统一换行后计算，便于跨系统核对。库版本不同可能产生小的模型差异，应保留自己的实际输出。

## 日历、输入与答案

第 r 期的信号日是第 `6*r` 个教学交易日，下一交易日入场，第五个交易日计划退出。这里的日期是编号 D001、D002……，没有声称这些编号对应某段真实交易所日历。

每期已知输入为 `mom_5`、`ep`、`roe`，未来答案为 `fwd_return`。`feature_available_day` 表示这组输入最晚何日形成，等于信号日：动量要等当天收盘才能算出；财务使用此前已公开的版本。第 3 章另用明确的日内时间演示新财务版本为何不可提前使用，CSV 本身没有模拟真实财务公告流水。模型学习同一期未来收益的百分位排名。第一期输入与起步课一致：A/B/C/D 的过去涨幅为 8%、-1%、4%、2%，未来收益为 5%、1%、3%、-2%。

模型按第 1–36 期训练、第 37–46 期验证、第 47–60 期测试。前一集合的末条标签，在下一集合首个信号前已经结束。候选 Ridge 和随机森林参数只按验证 RankIC 选择；LightGBM 早停只观察验证损失。测试结果不参与这些选择。

这是人为练习册中的时间隔离演示，不能把测试段当作现实世界独立证据。这些横截面也没有模拟四家公司的连续财务与全部日内行情。

## 资金怎样记

前四期的主线曲线以 8,000 元开始，逐期复乘各期未扣费收益。基准是同期四只候选股票的等权平均，同样复乘。它们先假设所有股票都能成交。

“重放第一期”会明确重新回到原始 8,000 元，用同一组 A/C 价格比较理想成交、C 买不到、扣费，以及买不到加扣费四个版本。各版本是独立对照，不能顺次相加。C 买不到时保留其 4,000 元现金，不临时加仓 A。

重放的名单同样从 `rounds.csv` 的第一期已知分数产生。给定 A/B/C/D 的入场价为 10/20/8/15 元，退出价由这份 CSV 的未来收益推回，避免在两处另存互相不一致的答案。

故事费率固定为每侧成交金额的 0.1%。每只股票的 4,000 元预算包含买入费用，因此买入金额为 `4000/1.001`；卖出费用按实际卖出金额再扣。允许虚拟份额，未实现整手、最低佣金、税费历史版本、盘口与部分成交。

模型表中的统计组合也逐期全部买入并全部卖出，假设都能成交，买卖各收上述费率；每个模型和等权基准从相同的 8,000 元分别计算。它没有把第九章的限制情形接成完整订单账本。

## 数据构造记录

后续练习样本使用 Python `random.Random(20261103)`。每期生成一个共同扰动，每只股票生成过去涨幅、EP、与 EP 相关的 ROE，以及额外扰动；未来收益由这些量的一个教学加权式与噪声组合。前四期再使用正文的固定题目覆盖输入和答案。该设置用于练习方法，无法支持市场规律结论。

生成式为：共同扰动服从均值 0.001、标准差 0.008 的高斯分布；`mom_5` 在 -0.10 到 0.12 均匀取值，`ep` 在 -0.02 到 0.12 均匀取值；`roe = 0.02 + 1.3×ep + 高斯扰动(0,0.05)`；`fwd_return = 共同扰动 + 0.12×mom_5 + 0.12×ep + 0.08×roe + 高斯扰动(0,0.025)`。按期数、A/B/C/D 顺序抽样，前四期也消耗同样随机抽取后再覆盖。数据因此刻意含有可学习关系，尤其不能把模型分数解释成市场证据；重做本书时以已提交的固定 CSV 为输入。

故事脚本与原有 `src.run_demo` 是不同的数据入口。后者用较大的合成日频面板和七个量价/规模特征；来源课程的月度 Top-50 又有另一套数据与执行要求。正文只沿故事练习推进，这两种工程扩展放在参考材料中。
