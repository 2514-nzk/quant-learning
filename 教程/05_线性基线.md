# 第 11 章｜线性模型与 Ridge 基线

你已经会：特征、标签、时间切分和 RankIC。这一章只问：让历史决定权重，最少需要哪几步？

你把三个权重来回改了几次：动量多一点，EP 少一点，名单就换。改到第五版，小林把越来越长的表推回来：

“如果每次都由你定权重，那这套东西到底是谁在学？”

于是你们请出第一个模型：线性模型。它仍然做乘法和加法，只是权重由训练样本估计。

## 1. 线性评分与学习目标

本故事每一期有四只股票。未来收益从低到高的百分位标签是 0.25、0.50、0.75、1.00；R01 对应 D、B、C、A。

模型想根据过去涨幅、EP、ROE，给出接近这些标签的分数。一个最简单的形式是：

```text
分数 = 截距 + w1×处理后的动量 + w2×处理后的 EP + w3×处理后的 ROE
```

这里的分数用于同一期排序，不是预测能赚百分之几，更不是盈利概率。

你提供的是训练期历史输入和历史答案。模型在最终测试时，只能读输入。

## 2. 标准化、Ridge 与处理流程

如果一列数值范围很大，它在加权时与其他列的尺度就不同。你们只用训练数据估计每列均值和标准差，再将同一套转换用于验证和测试。

Ridge 在拟合误差之外，还给过大的权重加罚分。可以把它想成：

```text
损失 = 拟合误差 + alpha × 权重平方和
```

拟合误差让预测贴近答案；罚分让权重不要为了贴合训练样本而变得很大。`alpha` 越大，罚分越重。

```python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge

# 先处理数值尺度，再训练 Ridge；fit 时两步只接收训练数据。
model = make_pipeline(StandardScaler(), Ridge(alpha=0.1))
model.fit(train[features], train["label_rank"])  # 输入和答案按同一行对应。
validation_scores = model.predict(validation[features])  # 新样本只交输入，不交答案。
```

这是接口片段；完整数据切分和运行命令在后面。`alpha` 不是越大越好，仍要由验证集选。

先猜：`alpha` 从 0.1 加到 10，训练和验证会一起变好吗？

## 4. 系数解释与相关输入

选好 alpha 后，用前 46 期重训的标准化系数约为：动量 0.0511，EP -0.0023，ROE 0.1022，截距 0.625。

你原本以为“便宜更好”，看到负号很不踏实。先不要把它翻回正数：模型是在其他输入同时存在、并已标准化的条件下估计关系。EP 与 ROE 相关时，权重分配也会变化。

这里不能把负系数直接解释为“便宜导致亏损”，也不能把原始的 8% 直接乘这个标准化权重。输入转换本身是模型的一部分。

删除一列再比较，会比猜一个系数的经济故事更有帮助。我们在第 14 章回来看这件事。

## 6. 进阶训练｜从 Ridge 公式到严格的训练流水线

**入门关**：线性模型在固定特征下的预测是截距加上各列与权重的乘积。本章训练目标是同一期的未来收益名次标签，不是直接预测未来百分比收益。

**进阶关：明确正则化到底惩罚什么。** Ridge 通常通过最小化下面的目标估计权重：

~~~text
L(w,b) = Σ_i [ y_i - (b + x_i·w) ]² + alpha × Σ_j w_j²
~~~

常见实现默认不对截距 b 施加同样的 L2 惩罚，损失的缩放约定与不同库的 alpha 含义可能不完全相同。要比较 alpha，应在同一个实现、同一标准化和同一训练窗口内进行。

用 scikit-learn 的 Pipeline 将 StandardScaler 和 Ridge 绑在一起；一次 fit 只喂训练段，验证和测试使用 transform/predict。先把“所有历史统一标准化后再切分”的坏做法当成反例，明确它为什么泄漏。

**研究关**：做三种对照：单因子动量、等权排名、标准化后的 Ridge。每个候选需要相同样本、标签和时间切分。再检查 EP 与 ROE 相关导致的系数不稳定；系数反号不等于经济效应反号，也不意味着该特征没有独立预测贡献。
