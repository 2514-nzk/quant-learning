# 第 6 章｜因子表达式与常用算子

你已经会：特征和窗口。这一章只问：同一个算子，应该沿时间算，还是沿横截面算？

A 的五日涨幅应该是 `108/100-1=8%`，你却得到约 6.93%。先别重装 Python，看看分母。

这份表按日期排列，每天依次写 A、B、C、D。当前行往前数五行，落到了 D 的另一个日期：它的指数是 101。于是电脑认真算出了 `108/101-1≈6.93%`。


**这一章其实在教电脑别串行。** A 的昨天要跟 A 的今天比较，不能拿 A 的今天去除以 B 的昨天；同一天比较 A 和 B 的分数，则是另外一种方向。


## 1. 算子的计算方向与对象

你原来的写法表达的是：

```python
# 错误对照：整列向前找五行，会在四只股票之间串行。
history["wrong_mom"] = history["close_index"].pct_change(5, fill_method=None)
```

`pct_change(5)` 并不知道你心里想的是“五个交易日前同一只股票”。它只按接到的数据方向取值。

<details>
<summary>先想一步：要让 6.93% 变成 8%，应该改哪一边？</summary>

先让每只股票各自成列，再沿日期向前找五行。也就是说，计算方向要从“整张表往下”改成“同一只股票沿时间”。

</details>

我们把取前值、变化率、平均、排名这类小操作叫**算子**。名字写对以后，还得说明沿谁的时间、在哪个日期、对哪些股票算。


### 先用两只股票、两天把方向弄清楚

| 股票 | 星期一收盘价 | 星期二收盘价 | 自己的涨跌幅 |
|---|---:|---:|---:|
| A | 100 元 | 110 元 | +10% |
| B | 200 元 | 198 元 | -1% |

正确算法是：

```text
A：110 ÷ 100 − 1 = +10%
B：198 ÷ 200 − 1 = -1%
```

如果把 A 的 110 除以 B 的 200，会得到 -45%，但这**不是任何一只股票自己的涨跌幅**。表格行挨在一起，不代表它们能拿来互除。

**两个方向：** 沿着 A 的日期往下看，是时间序列计算；站在星期二把 A、B 放一起比哪只更强，是横截面排名。

<details>
<summary>练一下：星期二按涨跌幅从高到低排，谁第一？</summary>

A 是 +10%，B 是 -1%，所以 **A 第一、B 第二**。排名时可以比较不同股票，但计算各自涨幅时必须先在同一只股票内部找前一天价格。

</details>

## 3. 滞后、变化率与横截面排名

在项目根目录运行下面的例子，需要 pandas。代码里的 `#` 注释先说清每步做什么：

```python
import pandas as pd  # 引入处理表格的工具。

history = pd.read_csv("data/story/price_history.csv")  # 读入同一份固定历史。
# pivot 把日期变成行、股票名字变成列，每个格子放对应价格指数。
wide = history.pivot(index="day", columns="code", values="close_index").sort_index()
previous = wide.shift(5)  # 每列向下移五行，使五日前的值与今天对齐。
changes = wide / previous - 1  # 当前值除以对应前值，再减 1。
last = changes.iloc[-1]  # iloc[-1] 取最后一个日期的结果。
print(last.round(4))  # A 0.08，B -0.01，C 0.04，D 0.02。
print(last.rank(pct=True))  # 同一天排名：A 1，B 0.25，C 0.75，D 0.50。
```

你拿起步课的已知表逐个对照，四个数终于接上了。后面所有演算继续使用这四个涨幅。

### 你在 K 线图上用过的均线，原来就是一个算子

**另一个小例子：** A 最近三个**完整收盘价**为 10、11、12 元，那么三日均线是 (10+11+12)÷3=**11 元**。均线不需要猜未来，只是拿已经发生的三个数求平均。

| 炒股软件的叫法 | 告诉电脑做什么 |
|---|---|
| 3 日均线 MA3 | 同一股票最近 3 个收盘价取平均 |
| 过去 5 日涨幅 MOM5 | 同一股票今天收盘价 / 五个交易日前收盘价 − 1 |
| 过去 5 日最高价 | 同一股票最近 5 个交易日的 high 取最大 |
| 今日涨幅排名 | 同一天不同股票的涨幅从高到低排序 |

一个容易忽略的区别：**MA5 用五个收盘价；MOM5 要今天和五个交易日前两个价格端点，共涉及六个市场日期。** 如果中间停牌缺行，先沿市场日历补齐日期位置，不能把“往前五行”直接当“五个市场交易日”。

**换成真实行情验算：** 平安银行（000001）在 2024-06-24 至 06-28 的收盘价依次是 **9.98、10.08、10.08、10.13、10.15 元**。所以那天 MA5 为 **10.084 元**。如果算 MOM5，则还需要 06-21 的 10.00 元，得到 **+1.50%**。这是真实历史行情，与前面的四股手算例子分开。三张 K 线图和练习见[真实 A 股 K 线](真实A股K线_入门实例.md)。

## 4. 滚动均值与时间序列排名

你顺手问：“A 最近三天的平均呢？”这一次不用改变数据形状，只取 A 那一列：

```python
prices_a = wide["A"]  # 按列名取出 A 的价格指数。
mean_3 = prices_a.rolling(3, min_periods=3).mean()  # 最近三个值齐全才求均值。
print(mean_3.iloc[-1])  # (104 + 106 + 108) / 3 = 106。
```

窗口前两天没有三个值，所以结果缺失。它表示历史不足，不表示均价是零。

排名又是另一个方向：刚才的 `last.rank` 在同一天比较四只股票；A 自己与历史三天相比的位置，则是时间序列排名。两者都叫排名，比较对象不同。

## 选读｜进阶训练：算子的“轴”决定计算的含义

先区分三种经常混淆的方向：

| 算子 | 沿哪个方向 | 具体问题 |
|---|---|---|
| 滞后/滚动 | 同一只股票沿时间 | A 的 T 日相对 A 的 T-5 日怎样变？ |
| 排名 | 同一决策日沿股票 | T 日 A 的分数相对 B/C/D 排第几？ |
| 连接 | 股票主体 + 可用时点 | T 日能拿到的最近一版财务数是什么？ |

**入门关**：六条价格观测从 D001 到 D006，有五段收益，不要把“观测数”错当“区间数”。

**进阶关**：pandas 的 groupby 滚动或 pct_change 首先要在每只股票内部按市场日历排序：

~~~python
# 这是接口示意：先以交易所日历对齐，再执行下面的组内计算。
panel = panel.sort_values(["code", "market_day"])
panel["mom_5"] = panel.groupby("code")["close"].pct_change(5)
# 若某股票缺少市场交易日，请先对齐并标记停牌/缺失；
# 否则“向前五行”并不等于“向前五个市场交易日”。
~~~

**研究关**：故意把 A 和 B 两只股票交错排在同一张长表里，在没有 groupby 的情况下运行 pct_change，观察错误；再修复。另加“同分”“全缺”“只上市三天”三个边界测试。
