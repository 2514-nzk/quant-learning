# 初级教材目录：从 A 股因子研究到机器学习选股

本教材已融合《A股量化研究基础课程目录.pdf》的十个传统多因子模块。你的学习起点按“有编程能力、有股票交易经验、初学量化研究”安排：先补量化 Python 和数学统计，再研究简单因子，最后进入机器学习。原有文件编号保留；**以下阅读顺序优先于文件名排序**。

## 先修与总路线

- [00 学习路线](00_学习路线.md)：两阶段安排、案例口径和验收要求。
- [00d 量化 Python 实战](00d_量化Python实战.md)：程序员的实践入口；标签对齐、行情面板、市场日历、窗口、PIT 连接、评价覆盖与断言。
- [00e 量化数学与统计](00e_量化数学与统计.md)：收益与风险、概率与估计误差、IC、协方差、回归、年化、重叠和多重检验。
- [00a Python 数据分析基础](00a_Python数据分析基础.md)：pandas/NumPy 语法参考，按需要查阅。
- [00c 金融市场基本概念](00c_金融市场基本概念.md)：基础行情内容可跳读，重点核对复权、PIT、成交与成本的研究口径。
- [00b 机器学习基础](00b_机器学习基础.md)：进入第二阶段前学习，第一阶段不要求机器学习背景。

两份练习均内置虚构数据，可从项目根目录直接运行，不需要接入真实数据库：

```powershell
python examples/quant_python_workshop.py
python examples/quant_math_workshop.py
```

建议把 Python 的每项操作与数学含义一起学：先面板与窗口，再截面排名与相关，接着收益与组合，最后检查时点和不确定性。两章合计约 8–14 小时阅读与练习，按完成检查点的情况调整，不计入 PDF 原 17 学时。

## 第二阶段：机器学习选股扩展

先完成 00b，再按下面顺序学习，已有传统等权因子可作为比较标尺。

1. 回读 [04 时间切分与泄漏](04_时间切分与泄漏.md)，落实到训练/验证/测试
2. [05 线性基线](05_线性基线.md)
3. [06 决策树与随机森林](06_决策树与随机森林.md)
4. [07 GBDT 与 LightGBM](07_GBDT与LightGBM.md)
5. [08 模型评价与解释](08_模型评价与解释.md)
6. 回读 [09 预测到组合](09_预测到组合.md)
7. [10 研究框架与结课项目](10_研究框架与结课项目.md)
8. [11 完整手算案例与实验操作](11_完整手算案例与实验操作.md)

本阶段现有代码使用 T 收盘后信号、T+1 开盘至 T+5 收盘标签、5 日非重叠教学回测。它与第一阶段的月度三因子项目是不同实验规格，不能直接混用结果。
