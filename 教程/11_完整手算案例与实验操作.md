书读到最后，我们没有换另一组股票或给你一个突然大赚的收尾。桌上仍然是第一期的 A、B、C、D，起始资金还是 8,000 元。

这次先合上前面的答案，按自己的顺序重做。

## 1. 已知输入与选股规则

A 过去涨了 8%，B 为 -1%，C 为 4%，D 为 2%。规则仍是取前两只，各分一半。

你应该先写出 A、C。T 日还不知道未来买卖价，也不知道 C 到买入时是否受限。

把这个动作做完，才打开 A `10→10.50`、C `8→8.24` 的未来表。理想未扣费收益为 4%，期末 8,320 元。

## 2. 未来信息隔离检查

假设只把 A 的未来收益从 5% 改成 -10%，过去分数完全不动。你会在原决定里删掉 A 吗？

<details>
<summary>展开核对这次压力题</summary>

仍然选 A、C。改变的是事后成绩：`(-10%+3%)/2=-3.50%`。如果看到亏损才把 A 删掉，就让未来答案参加了原来的选择。

这是对一份副本的假设题，不覆盖固定 CSV，也不把它混入正式四期记录。

</details>

你可以只在内存里试这件事：

```python
from examples.story_research import load_rows, factor_scores, select_two

# dict(row) 复制记录；只在这份小副本里改变未来答案。
first = [dict(row) for row in load_rows() if row["round_id"] == 1]
for row in first:  # 每次检查一只股票。
    if row["code"] == "A":
        row["fwd_return"] = -0.10  # 不改过去涨幅。
scores = factor_scores(first, ["mom_5"])  # 打分仍只读已知输入。
selected = select_two(first, scores)
print([row["code"] for row in selected])  # 仍为 ['A', 'C']。
```

## 5. 模型运行与比较复现


先核对输入指纹、库版本和切分，再核对候选设置。训练与验证结束以后，才用它们确定的设置产生测试结果。

编书时的参考运行中，最深森林的训练成绩最好，却没有通过验证选择；LightGBM 多加树也没有持续改善验证；最终测试里复杂模型没有超过动量基线。无需把练习“调到某个复杂模型获胜”才算完成。

这些仍是人工题目的成绩。真正接入历史市场，还要处理可靠数据、历史股票范围、财务时点和完整执行，并预留没有参与研究的数据；相关工程资料在参考区。

## 6. 完整研究结论

> 第一笔理想未扣费演算盈利 320 元，但它不能代表全部研究。固定规则在后续题目中出现了跑输和亏损；第一期恢复买入限制与双边费用后，盈利约 191.61 元。模型练习没有显示复杂度带来超过既定动量基线的增量。已保存输入、设置和不利结果，未把教学数据当作市场有效性的证明。

这段话把你亲手走过的尝试、失误和判断留在了记录里。
