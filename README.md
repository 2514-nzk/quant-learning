# A 股量化研究入门｜从真实 K 线到完整研究

本书面向有炒股经验、希望系统学习量化研究的读者。我们使用 **贵州茅台（600519）、寒武纪（688256）、宁德时代（300750）、比亚迪（002594）** 的真实历史日 K 线，带着一个 **100 万元课堂模拟账户**，从选股和收益计算开始，逐步学习因子、回测、组合、机器学习与结果审计。

**[在线阅读本书](https://2514-nzk.github.io/quant-learning/)** · [章节目录](教程/README.md) · [起步第一课](教程/真实_起步一课.md)

- **第二卷｜专业量化研究方法**：[14 章研究级框架](advanced/volume-2/README.md)，将系统讲授 PIT 数据、统计推断、严格样本外、模型增量、组合与执行；**目前 01、05–11 章为教学正文初稿，其余为章节骨架**。

[查看三卷总览和建设规范](advanced/README.md)。目录框架不等于实证内容完成，更不构成交易策略有效性的证据。

## 贯穿全书的案例

2024 年 6 月 21 日收盘后，我们只用当时已经知道的价格，计算四只股票过去五个交易日的涨跌幅；按事先确定的规则选出前两名，假设在 6 月 24 日开盘买入，观察至 6 月 28 日收盘。

| 学习设定 | 内容 |
|---|---|
| 股票 | 贵州茅台、寒武纪、宁德时代、比亚迪 |
| 课堂模拟资金 | **1,000,000 元** |
| 决策时点 | 2024-06-21 收盘后 |
| 观察买入价 | 2024-06-24 开盘 |
| 观察退出价 | 2024-06-28 收盘 |
| 历史价格 | 真实不复权日线 |
| 学习目的 | 理解计算、时间约束、交易限制与研究评价 |

书中还会在 2024 年上半年的 **18 个非重叠观察期**重复这一规则，练习复利、基准和因子评价。这是四只知名股票组成的教学样本，并非完整历史股票池；理论收益也不等于实际订单成交或包含分红的总收益。

## 阅读顺序

- **起步两课**：读懂真实 K 线，手算一次选股，让 Python 做相同计算。
- **第 1–2 章**：收益率、等权基准、多期观察与复利。
- **第 3–8 章**：历史数据、因子、信息时点、时间切分和 RankIC。第 6 章后有[补充阅读：归母权益、少数股东权益与财务质量](教程/真实_06a_合并报表与财务质量.md)，使用宁德时代的真实历史年报核对利润、现金流和资产变化。
- **第 9–10 章**：交易单位、费用、现金与多因子组合。
- **第 11–14 章**：线性模型、树模型、LightGBM 与风险评价。
- **第 15–16 章**：留下可复核的研究记录并完成综合练习。
- **选读进阶专题 A**：[用宁德时代与比亚迪的真实价格理解协整和配对交易](教程/真实_专题A_协整与配对交易.md)，先比较两只股票的走势，再学习价差、统计检验与 A 股交易限制。

不需要先学完一本 Python 手册。每章先给看得懂的例子和实际数字，公式与代码逐步引入。

## 动手复算

在项目根目录运行：

~~~powershell
python examples/real_stock_learner.py
~~~

程序读取 [固定的历史数据与计算结果](data/real_a_share/)，展示四只股票的当时涨幅、随后观察到的收益、组合对照与分段统计。阅读器里的相应章节也提供直接运行的练习。

项目中的其他代码、数据和研究模板可以用于扩展练习。将方法推广到正式 A 股研究前，需要补齐历史动态股票池、公司行为、财务数据可用时点、实际成交约束和独立样本外验证。

**本书用于量化研究方法教育，不构成投资建议或收益承诺。**
