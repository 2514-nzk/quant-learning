## 课程定位

- **第一卷**保持已发布的四只真实股票、100 万元课堂模拟账户与原有 16 章顺序。
- **第二卷**先讲研究可信度，再讲模型复杂度；可以得到不显著或无效结论。
- **第三卷**专注 A 股可交易性，不把理想报价收益当作实盘收益。

## 填充顺序

1. 第二卷 01、04–08：研究协议、A 股制度、PIT、标签与因子研究。
2. 第二卷 09–14：增量检验、机器学习、严格 OOS、组合、成本与研究复现。
3. 第三卷各策略专题：从时点、基线和可交易性开始，再做回测。
4. 每章按 [写作与实验规范](AUTHORING_GUIDE.md) 验收，并更新 [素材覆盖地图](COVERAGE_MAP.md)。

## 合作约定

课程框架章节各自独立成 Markdown；原有正文和历史数据不覆盖。改动走 PR 审核，禁止编造论文、市场规则或交易成绩。在线阅读器将新卷框架单列，第一卷的阅读进度保持独立。
