## 4. 一页结论

- **问题与机制：**
- **事实：** 哪些数据和实验已完成，有什么结果？
- **推断：** 这些事实支持到哪一步？
- **假设：** 哪些信息可用性或成交条件仍是假设？
- **局限：** 哪些数据、功能或独立验证尚缺？
- **决定：** 采用 / 保留 / 否定当前规格，以及理由。
- **下一项反证实验：** 什么结果会改变本次决定？
