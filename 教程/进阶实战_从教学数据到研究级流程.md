# 进阶实战｜从四只股票到研究级量化流程

这是一条与十六章正文并行的进阶路线。**第一次阅读只需做正文的手算；第二次做真实代码；第三次做能被独立审计的研究项目。** 不能把教学数据里得到的分数当作真实市场收益。

> 本书 A、B、C、D 四只股票、60 期练习和 8,000 元资金均是人工构造。这里的“研究级”指可验证的方法和工程过程，不表示策略已经有效，更不保证收益。真实交易规则应按证券类型和历史日期核对。

## 一、四级学习目标

| 层级 | 你应该能回答 | 过关作品 |
|---|---|---|
| 入门 · 会算 | 选股收益从哪笔钱来？ | 两只股票手算，与 Python 一致 |
| 基础 · 会研究 | 特征是否当时可知，因子是否真的能排序？ | 数据审计 + 每期 IC 和分组表 |
| 进阶 · 会回测 | 预测怎样变成真实的现金和持仓？ | 成交约束 + 费用 + 现金账 |
| 研究级 · 会反证 | 结果能否跨时期、参数、成本重复？ | 冻结协议 + 滚动 OOS + 失败日志 |

读完书不等于精通。真正的能力体现在遇到失败时能定位原因、重做证据、诚实收口。

## 二、数据工程：每一列都要能回到历史

真实数据最少要分清四个时间：记录所对应的期间、官方披露时刻、供应商可用时刻、策略决策截止时刻。报告期不等于可用日。

| 字段 | 含义 | 必须查什么 |
|---|---|---|
| symbol / entity_id | 股票代码 / 经济主体 | 改名、重组、退市后是否错误拼接 |
| period_end | 财务指标归属期 | 不能据此当作披露日期 |
| published_at | 信息首次公开时间 | 盘前盘后和时间区 |
| ingested_at | 数据源实际上线该版本的时间 | 公告后入库延迟 |
| available_at | 本研究认可的使用起点 | 不能晚于信号截止 |
| revision_id | 历史版本号 | 修订不能悄悄覆盖旧版本 |

例如：一项数据周五 16:20 才发布，若策略在当日 15:00 决策，就算它属于上一季度，也不能用于这次决策。把决策改到 18:00 后仍要确认数据源届时确实提供了该版本。

时点连接可以从 pandas 的后向连接入手：

~~~python
import pandas as pd

# signals: symbol, signal_at
# versions: symbol, available_at, value
signals["signal_at"] = pd.to_datetime(signals["signal_at"], utc=True)
versions["available_at"] = pd.to_datetime(versions["available_at"], utc=True)

left = signals.sort_values("signal_at")
right = versions.sort_values("available_at")
joined = pd.merge_asof(
    left, right,
    left_on="signal_at", right_on="available_at",
    by="symbol", direction="backward",
)
# 对有效匹配逐行审计，而不是只相信 join 成功。
matched = joined.dropna(subset=["available_at"])
assert (matched["available_at"] <= matched["signal_at"]).all()
~~~

这段代码**只演示连接方向**。如同一时刻有多个修订，还需预先规定版本选择；若原始可用时间不可信，连接正确也不能证明历史可复现。可参阅 [pandas.merge_asof 官方文档](https://pandas.pydata.org/docs/reference/api/pandas.merge_asof.html)。

**验收**：随便抽一个历史信号日，能解释它所用的每项财务值来自哪个版本、何时可用；今天已经退市的股票仍按当时的状态进入历史股票池。

## 三、标签和 Purge：按真实区间清除，而非固定删五行

一行股票样本至少携带三个时间：信号时刻、计划入场时刻、标签结束时刻。前向切分要求训练标签不越过后面评价期的第一笔决策。

~~~python
# 示例字段 signal_at、label_end_at 均已转成同一时间类型。
valid_start = valid["signal_at"].min()
clean_train = train.loc[train["label_end_at"] < valid_start]
assert (clean_train["label_end_at"] < valid_start).all()
~~~

这里的严格小于是一条保守边界约定。具体使用不等号还是允许等时，取决于标签计算完成时间是否早于决策截止；必须明确到时刻。

- **时间切分**：预测过去训练、未来评价；
- **Purge**：剔除信息区间与评价期冲突的训练样本；
- **Embargo**：特定验证设计下追加的缓冲，并非所有前向切分必须使用。

scikit-learn 的 TimeSeriesSplit 支持按样本数留 gap，但不能自动根据每个标签结束时间执行事件级 Purge，参见 [官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)。

**验收**：每折输出训练最大标签结束时刻和验证最早信号时刻；只要越界，就明确失败而非继续训练。标签期限一改，切分也必须重新审计。

## 四、因子研究：从 RankIC 走到稳健性

某期因子排序和后续收益排序的 Spearman 相关叫 RankIC。跨期汇总常用每期 IC 均值与标准差之比，即 ICIR（必须注明原始评价频率与标准差定义）。

~~~text
IC_t = corr(rank(score_i,t), rank(fwd_return_i,t))
mean_IC = mean(IC_t)
ICIR = mean(IC_t) / std(IC_t)
~~~

若所有分数相同，相关性无定义，不能擅自写成 0。每期有效股票数、缺失原因和股票池变化要一起记录。只有四只股票时可以做高低两组，**不能假装有足够样本做稳定的五分位评价**。

一份真正能用的因子报告至少包括：定义与方向、PIT 覆盖、每期 IC、ICIR、分组收益和单调性、Top-N 换手、行业和规模偏差、参数及持有期敏感性、成本后多头收益。排序能力不是资金收益，也不保证多头赚钱。

**验收**：不只贴平均 IC；保留逐期结果、失败阶段和缺失样本的去向。若试了很多因子，只汇报最好的一个属于多重比较问题。

## 五、模型研究：先解释简单基线为什么不够

保持相同信号日、标签、样本、费用和评价方式，依次对照单因子、横截面排名等权、Ridge、随机森林与 LightGBM。

- 预处理器只能在每折训练期拟合；验证和测试沿用参数。
- 模型的目标若是未来名次，就不能把分数解释为未来收益率。
- 随机森林训练分数更高，未必代表未来分数更高。
- LightGBM 早停监控的损失可能与最终 RankIC 不一致，应同时记录两者。
- 特征消融需按同一协议重训；在看完测试后设计的新消融，只能作为新探索。

LightGBM 官方对早停回调的要求见 [early_stopping 文档](https://lightgbm.readthedocs.io/en/stable/pythonapi/lightgbm.early_stopping.html)。

## 六、交易执行：四种成绩不能互相顶替

| 级别 | 统计含义 | 不能省略的东西 |
|---|---|---|
| 理想毛收益 | 预定价格全成交、不扣费 | 只是上限式对照 |
| 成本后纸面收益 | 理想全成交但扣费用 | 费率适用日期及买卖双方 |
| 交易约束回放 | 有买不到、卖不掉和留现金 | 成交状态与资金占用 |
| 更真实的执行模拟 | 订单、部分成交、排队、滑点 | 盘口和可观察信息的时间界限 |

每期至少保持现金守恒：期初现金减买入金额减买费，加卖出收入减卖费，得到期末现金。未成交订单不得产生收益；交易单位、T+1、税费、涨跌幅和停牌规则要按实际历史时点核对。

**验收**：同一信号分别运行无成本、基准成本、压力成本。逐笔检查目标名单和成交名单的差异，不能为了让回测好看而给买不到的股票虚拟收益。

## 七、真正的样本外：让决策顺着时间发生

预先写下：研究对象、基准、标签、费用、候选参数、验证方式、停止条件、最终测试起止范围。不要看到结果后再随意更换“最终测试”。

推荐进一步练习 walk-forward / prequential：

1. 截止当前时刻，只使用已经形成标签的历史样本训练；
2. 用过去的验证过程选参；
3. 在下一期决策截止前提交预测，不改历史记录；
4. 标签形成后追加真实结果；
5. 按冻结的频率更新模型，继续向前。

真实市场存在时间相关、横截面共同冲击与多重测试，因此独立同分布的简单置信区间不应被无条件套用。试了上百组参数才挑出的赢家，不能按“只做过一次检验”估显著性。可延伸阅读 [Hansen, 2005, A Test for Superior Predictive Ability](https://doi.org/10.1198/073500105000000063)。

**验收**：留下所有实验版本、失败期、原始 OOS 预测和当时可用的数据截止；任何新参数都只能进入下一轮探索。

先运行本仓库已有、不会自动外推到真实市场的教学脚本，并运行新增的独立审计实验（只依赖 Python 标准库）：

研究审计脚本会读取 60 期固定数据，打印第一期 Top-2、毛收益、等权基准及 RankIC，并检查各期数据可用日与训练/验证/测试的标签边界。它是流程练习，不含真实交易撮合。运行完整机器学习实验仍需安装项目依赖。

然后在**具有完整历史股票范围和 PIT 证据**的真实数据上重建一个简单研究项目，至少产出五份文件：

1. **研究规格**：决策和成交时点、候选股票、标签、基准、费用、停止条件；
2. **数据审计**：原始字段来源、可用时间、修订、退市覆盖和缺失原因；
3. **因子/模型报告**：逐期 IC、分组、参数选择、消融与滚动 OOS；
4. **执行报告**：目标持仓、成交差异、资金核对、费用与容量压力；
5. **复现清单**：数据与代码指纹、版本、运行环境、完整试验记录。

> **真正的通过条件不是回测为正**，而是结果能被独立重算、看得到失败、知道测试有没有被使用过、知道执行哪些部分没实现。流程合格之后，才有资格讨论是否存在稳定超额。
