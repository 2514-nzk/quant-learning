# 第三卷 · 07｜题材网络与行业条件基线

> **状态：教学正文 v1；证据等级：SYNTHETIC_ONLY；独立合成题材关系、PIT 网络快照、同行业对照实验与边界测试已建立。** 本章不使用真实题材供应商数据、真实证券关系或个人研究结果。

## 本章核心问题

两只股票共享一个题材标签，是否意味着它们之间存在可利用的信息联系？这种关系能否提供行业分类之外的增量信息？如果题材关系本身会修订、迟到或随时间变化，研究者如何避免把今天的题材标签回填到过去？

本章把题材关系看作一个**随时间变化的二部网络**，并将检验问题收窄为：

> 在同一个决策时点、同一个历史行业内，拥有已知共享题材关系的同业股票，与没有已知共享题材关系的同业股票，后续表现是否存在稳定差异？

共享题材可能代表共同业务、共同催化、产业链联系或市场注意力，也可能只是供应商标签的共现。它不天然代表利好、因果关系或可交易信号。

### 阅读准备｜先把网络当成关系表

本章的集合符号主要用于描述股票与题材的连接。交集（∩）是双方共有的题材，并集（∪）是任一方拥有的题材，竖线包围集合表示元素数量。例如 A 有 AI、芯片，B 有芯片、汽车；交集有 1 个，并集有 3 个，Jaccard 相似度为 1/3。它反映题材集合的重合程度，不是收益相关系数。

## 1. 题材、行业与经济关系不是同一个概念

先区分三类关系：

| 关系 | 主要回答的问题 | 常见时间特征 |
|---|---|---|
| 行业分类 | 公司主要属于哪个产业门类？ | 相对稳定，但会换版、调整成员 |
| 题材标签 | 某时点哪些概念、事件或主题与公司相关？ | 变化较快，来源间口径可能不同 |
| 经济关系网络 | 公司之间是否存在客户、供应商、竞争、投资或其他可验证联系？ | 依赖具体关系来源和生效时间 |

同一家公司可以属于一个主要行业、拥有多个题材标签，并与多个公司存在不同类型的经济联系。不能把“同题材”直接写成“同产业链”，也不能把供应商的标签共现解释成已经核实的客户、供应商或控制关系。

真实研究应为关系来源单独建字典：官方披露、公司公告、供应链数据、新闻事件标签、文本模型输出等分别记录。不同来源的证据强度不同，不应简单拼接为一张没有来源字段的题材表。

## 2. 用二部图表示股票—题材关系

在决策时点 \(t\)，定义股票集合 \(S_t\)、题材集合 \(T_t\)，以及股票与题材之间的边集合 \(E_t\)：

\[
G_t=(S_t,T_t,E_t).
\]

定义邻接矩阵：

\[
A_{i,k,t}=
\begin{cases}
1,& \text{股票 }i\text{ 在时点 }t\text{ 有一条可用的题材 }k\text{ 关系}\\
0,& \text{当前 PIT 快照中没有这条已知关系}
\end{cases}
\]

股票的题材度数与题材覆盖广度分别为：

\[
d_{i,t}=\sum_{k\in T_t}A_{i,k,t},
\qquad
b_{k,t}=\sum_{i\in S_t}A_{i,k,t}.
\]

- \(d_{i,t}\) 表示当前快照中股票 \(i\) 有多少条已知题材边；
- \(b_{k,t}\) 表示题材 \(k\) 关联了多少只股票；
- 边数、平均度数和题材广度描述网络结构，不代表预测能力。

**没有已知边不等于现实中不存在关系。** 只有在数据源覆盖、采集完整性和缺失语义经过核验后，才能把“未记录”解释为“该数据源在该快照中没有记录”。真实数据若覆盖不完整，应将未知与明确无关系分开编码。

## 3. 关系强度：交集、Jaccard 与稀有题材权重

令股票 \(i\) 在时点 \(t\) 的题材集合为 \(\mathcal T_{i,t}\)。两只股票的共享题材数为：

\[
C_{ij,t}=|\mathcal T_{i,t}\cap\mathcal T_{j,t}|.
\]

共享题材数容易被“热门大题材”主导。可进一步计算 Jaccard 相似度：

\[
J_{ij,t}=
\frac{|\mathcal T_{i,t}\cap\mathcal T_{j,t}|}
{|\mathcal T_{i,t}\cup\mathcal T_{j,t}|}.
\]

例如，股票 A 的题材集合是 \(\{T_1,T_2\}\)，股票 B 是 \(\{T_1\}\)，股票 C 是 \(\{T_2,T_3\}\)。A 与 B 的 Jaccard 为 \(1/2\)，A 与 C 的 Jaccard 也为 \(1/3\)。这只是集合重合度，不代表关系强弱的经济真值。

为降低极宽泛题材的权重，可按当期题材广度定义逆频率权重：

\[
w_{k,t}=1+\log\left(\frac{|S_t|+1}{b_{k,t}+1}\right).
\]

再计算加权 Jaccard：

\[
J^{w}_{ij,t}=
\frac{\sum_{k\in \mathcal T_{i,t}\cap\mathcal T_{j,t}}w_{k,t}}
{\sum_{k\in \mathcal T_{i,t}\cup\mathcal T_{j,t}}w_{k,t}}.
\]

权重只使用当期已知网络快照计算。不能先用全样本统计某题材有多热门，再把该权重回填到历史时期。题材广度很小也不代表标签一定准确；还应检查来源覆盖、标签生成规则和人工复核状态。

## 4. 最重要的门禁：题材关系必须 PIT

一条关系记录至少需要以下字段：

| 字段 | 含义 |
|---|---|
| security_id / issuer_id | 证券与稳定主体标识 |
| theme_id | 稳定题材键，不应只依赖展示名称 |
| effective_from / effective_to | 关系在业务上的有效区间，左闭右开 |
| published_at | 来源公开或发布时点 |
| available_at | 研究数据系统实际取得该记录的时点 |
| source / source_version | 来源与版本 |
| confidence / review_status | 关系置信度与核验状态 |
| record_id / supersedes | 记录标识及修订关系 |

对决策时点 \(d_t\) 和信号日期 \(s_t\)，本章仅接受同时满足以下条件的关系：

\[
effective\_from\le s_t<effective\_to,
\]

\[
published\_at<d_t,\qquad available\_at<d_t.
\]

边界相等时保守排除。还应核对题材快照的完成时间、行业映射的有效区间和可得时间。供应商后来补录一条“历史上有效”的题材关系，不代表策略在当时已经知道它。

修订数据不能覆盖历史快照。应保存首次版本、修订版本、修订时间与替代关系；回测在每个历史决策时点重建当时可得版本。题材名称改写、合并、拆分和同义词映射也需要单独版本表。

## 5. 同行业条件基线：不要把行业效应误认为题材效应

如果共享题材的股票本来就集中在同一个强势行业，那么简单比较“共享题材组”和“非共享题材组”会混入行业收益差异。

对锚定股票 \(i\)，在同一决策时点、同一历史行业 \(g\) 内定义同行集合：

\[
P_{i,g,t}=\{j:j\ne i,\ industry_{j,t}=g\}.
\]

将同行拆成两组：

\[
P^+_{i,t}=\{j\in P_{i,g,t}:C_{ij,t}>0\},
\]

\[
P^-_{i,t}=\{j\in P_{i,g,t}:C_{ij,t}=0\}.
\]

这里的 \(P^-\) 严格表示“当前完整快照中没有已知共享题材边”，不是宣称两家公司在现实中没有任何关系。只有当数据覆盖足够完整时，这种分组才有更强的解释力。

若 \(r_{j,t+1}\) 是事后才可得的下一观察窗口收益，可构造描述性差值：

\[
\Delta_{i,t}=
\operatorname{mean}_{j\in P^+_{i,t}}(r_{j,t+1})
-
\operatorname{mean}_{j\in P^-_{i,t}}(r_{j,t+1}).
\]

还可以将共享题材组与全部同行均值比较，作为行业基线的另一种表达。只有当两组都存在、标签窗口完整且数据口径一致时，才计算差值；否则标记为不可比较，不用零填补。

**解释边界：** \(\Delta\) 是同一行业内的条件相关差异，不是题材关系的因果效应。它也不等同于买入共享题材股票的策略收益。

## 6. 从描述性差异到增量预测检验

如果研究目标是判断网络特征是否提供增量信息，至少应比较两个事前冻结的模型：

- **基线模型 \(M_0\)**：行业、市场状态、规模、流动性、历史收益等当时可得变量；
- **扩展模型 \(M_1\)**：在 \(M_0\) 基础上加入共享题材数、Jaccard、加权 Jaccard、股票度数、题材广度等网络特征。

比较时要固定训练/验证/测试时间边界、样本母体、标签、模型容量和调参预算。关注的是严格时间外样本中 \(M_1-M_0\) 的差值，而不是 \(M_1\) 自身的拟合分数。

建议至少报告：

1. 每期 RankIC / IC、方向一致性和有效覆盖率；
2. 加入网络特征前后的增量指标及区间；
3. 按行业、规模、流动性和题材广度分层；
4. 网络特征与行业、动量、新闻强度之间的相关性；
5. 组合层面的换手、成本、容量和无法成交比例；
6. 预先定义的负对照、置换检验与多重检验修正。

若仅有少量人工样本，或每期可比较的锚定股票不足，应停留在方法演示，不计算看似精确的显著性结论。

## 7. 统计推断：配对行数不是独立样本数

同一只股票会出现在多个锚定股票的同行集合中；同一个题材也可能连接很多股票。把所有股票对展开后直接做普通 t 检验，会把共享的股票、题材和日期冲击误当成独立信息。

更稳妥的步骤是：

1. 先在锚定股票—日期层面汇总共享组与非共享组的差异；
2. 再按日期形成区块统计量；
3. 用日期区块自助法或适当的多维聚类方法处理时间与主体依赖；
4. 报告独立日期数、锚定股票数、有效关系数和覆盖率；
5. 当时间区块很少时，不将 bootstrap 区间包装成可靠的显著性证据。

还可以进行**保度数二部图置换**：在行业和日期内通过边交换随机化股票—题材关系，同时尽量保持每只股票的题材度数和每个题材的覆盖广度。若真实网络统计量并不优于这些置换网络，就没有证据说明具体边配置提供了超出度数与题材流行度的信息。

## 8. 稳健性、反证与常见失败

至少完成以下检查：

- **行业替代口径**：更细或更粗的行业分类、历史分类换版、无法映射成员的排除规则；
- **题材替代口径**：来源独立计算、同义词映射、低置信度标签排除、只保留可核验关系；
- **关系强度替代**：共享题材数、Jaccard、加权 Jaccard、保度数置换；
- **时间稳健性**：不同事前窗口、不同标签期限、公告/新闻到达时点门禁；
- **混杂控制**：行业收益、市场状态、规模、流动性、历史动量、新闻强度和题材广度；
- **负对照**：未来才出现的题材标签、公告前窗口或无关题材关系；
- **样本外**：按日期滚动或扩展训练，不随机打散股票对；
- **交易检验**：成本、冲击、换手、容量、停牌、涨跌停与订单可成交性。

常见失败包括：用当前题材标签回填历史；把没有记录的关系当成确定不存在；跨行业比较却没有行业基线；把同一股票重复出现在许多配对中却不做聚类；只报告最有效的题材定义；以及看到结果后再选择收益窗口。

## 9. 可复算实验：动态题材边与同行业差异

数据集 [volume3-theme-network-synthetic-v1](../../data/teaching/volume3_theme_network_synthetic_v1.json) 包含 12 只虚构证券、3 个虚构行业、6 个研究时点和人工题材关系。情景包括：

- 一条关系在业务有效期内，但供应商在第三个时点之后才送达；
- 一只证券在后续时点发生题材关系变更；
- 每期都提供人工生成的事后收益标签；
- 题材关系快照与收益标签严格分离。

所有证券、题材、行业、日期、关系和收益均为合成数据。收益生成过程不使用题材关系，不应把实验输出解释为题材预测能力。

在仓库根目录运行：

~~~bash
python examples/volume3_theme_network_lab.py --json
python -m unittest discover -s tests -p "test_volume3_theme_network_lab.py" -v
~~~

程序输出每期的网络边数、题材广度、股票度数、Jaccard、加权 Jaccard、同行业锚定差值、日期区块汇总与教学用区块 bootstrap 区间。它不会报告真实市场 alpha、因果效应或可执行收益。

## 10. 习题与参考答案

**题 A：** 两只股票共享三个题材，是否一定比只共享一个题材的股票关系更强？

答：不一定。三个标签可能高度宽泛、重复或低置信度。应结合题材覆盖广度、来源质量、有效时间和加权相似度判断。

**题 B：** 某题材关系在周五决策之后才被供应商补录，但其有效日期写的是周一，能否加入周五的历史网络？

答：不能。业务有效时间和数据可得时间必须同时满足 PIT 门禁。补录不能改变当时策略实际知道什么。

**题 C：** 共享题材股票收益更高，能否证明题材网络有增量信息？

答：不能。必须先控制行业、规模、流动性、动量、题材广度等变量，再比较严格时间外样本中的 \(M_1-M_0\)。

**题 D：** 一个锚定股票对应十个共享题材同行，能否当作十个独立观测？

答：不能。同行之间共享股票、题材和日期冲击。应先在锚定股票—日期层面汇总，再按日期区块或适当聚类推断。

**题 E：** 未来题材标签对过去收益的解释力很强，是否是好结果？

答：更可能是未来信息泄漏的警报。未来标签只能作为负对照，不可进入历史决策特征。

## 12. 本章交付边界

**已交付**：题材二部图、股票度数、题材广度、Jaccard 与加权 Jaccard、PIT 关系快照、同行业条件基线、日期区块汇总、保度数置换思路、独立合成数据、可运行实验和自动化边界测试。

**尚未交付**：真实题材供应商的完整历史快照、来源覆盖审计、真实主体映射、正式保度数置换推断、真实市场严格 OOS 和可成交组合验证。合成实验不能替代这些工作。
