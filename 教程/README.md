# A 股量化研究入门：从问题到样本外证据

本书按研究流程讲解 A 股量化入门：定义问题，整理数据，构造和检验因子，形成组合，再比较模型与保存研究证据。章节标题标明知识主题，方便顺序学习和回头查阅。

正文用一笔 8,000 元的模拟研究贯穿讲解，保留尝试、错误与修正。先完成两节起步课，再按五编、十六章向前读。所有股票与数据均为教学构造，配套演算和模型结果可以重做。文件名中的旧编号仅用于仓库内部管理。
