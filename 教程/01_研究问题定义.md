# 第 1 章：把“预测股票”改写成可检验问题

“用机器学习选涨得好的股票”还不是研究问题。它没有说明预测什么、什么时候知道信息、哪些股票可以进入样本、收益从哪一天算到哪一天，也没有说明什么结果算成功、什么结果会让我们停止研究。

本章的目标，是把一句想法写成一份可以交给数据代码执行、可以被别人复现、也可以被结果否定的研究规格。后续章节的特征、标签、模型和回测，都应该回到这份规格检查，而不是看到结果后再临时改口径。

## 1. 概念直觉：先写“实验合同”，再写模型

### 1.1 模型、信号和策略不是一回事

- **模型**：输入特征，输出一个预测值。例如用 `mom_20`、`vol_20` 等特征预测 `label_rank`。
- **信号**：把预测值做横截面排序、标准化或阈值处理。例如每天按 `prediction` 从高到低排序。
- **策略**：规定买什么、何时买、持有多久、权重、成本和卖出条件。例如每 5 个交易日选预测最高的 10 只股票等权持有。

模型的 RankIC 变好，不保证成本后组合变好；组合赚钱，也可能只是长期偏小市值或某个行业，而不是模型学到了稳定关系。研究时必须分别回答：模型排序是否有预测力，预测力能否在成交约束下变成组合收益，以及结果是否超过一个清楚定义的基准。

评价指标也按这两层区分。模型层的 `IC` 表示信号与未来收益的相关性；本教程关注横截面排序，因此使用按排名计算的 Spearman 版本 `RankIC`，并用 `ICIR` 衡量其跨期稳定性。策略层的 `IR` 则衡量相对基准的超额收益稳定性，不能与 `ICIR` 混写：

```text
IC_T     = corr(signal_T, future_return_T)
RankIC_T = SpearmanCorr(signal_T, future_return_T)
ICIR     = mean(RankIC_T) / std(RankIC_T)
IR       = mean(portfolio_return - benchmark_return)
           / std(portfolio_return - benchmark_return)
```

本项目代码中的 `rank_ic_ir` 表示预测层 ICIR；除非明确说明，ICIR 不额外年化。

### 1.2 三种监督学习定义

同一个研究想法可以有不同的标签形式，但每种形式回答的问题不同：

- **回归**：预测未来收益数值。保留的信息多，但金融收益噪声很大，绝对幅度通常很难稳定预测。
- **分类**：预测是否上涨，或是否进入当日收益前 20%。直观，但阈值会丢失股票之间的排序信息。
- **排序**：预测同一天股票的相对强弱。它不要求精确预测收益幅度，更贴合横截面选股。

本教程用回归器拟合连续的 `label_rank`，评价时关心同一交易日的横截面排序。若把任务改成分类，评价指标、标签定义和组合解释都应一起改写，不能只把模型名称换成分类器。

### 1.3 一条时间轴先解决大部分歧义

本教程主线使用下面的时间关系。`T` 是信号日，不是买入日。

| 时间 | 可用信息与动作 | 代码中的典型字段 |
|---|---|---|
| `T` 收盘后 | 使用截至 `T` 收盘可得的日频量价、市值和其他特征；生成预测 | `trade_date`、特征列、`prediction` |
| `T+1` 开盘 | 按预测排序后尝试买入 | `entry_date`、`entry_price`、`can_enter` |
| `T+1` 开盘至 `T+5` 收盘 | 计算计划持有期收益 | `scheduled_exit_date`、`scheduled_exit_price` |
| `T+5` 收盘 | 计划退出；若不能卖出，顺延到首个可卖日 | `actual_exit_date`、`actual_exit_price` |

因此，使用 `T` 日收盘价计算特征时，不能又假设能以同一个已经知道的收盘价成交。把决策放在收盘后、把成交放到 `T+1` 开盘，是本教程用于避免这种时点冲突的简化约定。

### 1.4 研究问题的九个必填字段

在训练前至少写清下面九项。它们不是报告目录，而是研究能否成立的最小条件。

1. **预测对象**：预测绝对收益、收益排名、上涨概率，还是别的量？
2. **时点**：特征何时可得，何时决策，何时成交，何时退出？
3. **股票池**：每个交易日哪些股票有资格被预测？哪些股票实际可以买入或卖出？
4. **标签**：收益的起点、终点、价格口径、是否复权、是否做横截面变换？
5. **基准**：标签相对哪个基准解释，组合相对哪个基准评价？
6. **成本**：佣金、印花税、滑点或教学版综合成本怎样计入？压力成本是多少？
7. **评价**：模型看什么指标，策略看什么指标，按哪些时间段报告？
8. **假设**：哪些关于数据可得性、成交、持仓和样本的假设必须暂时成立？
9. **失败标准**：什么结果会否定假设、停止加复杂度或回到数据检查？

还要补上特征、时间切分、模型、组合和已知局限。完整模板见本章第 4 节；也可以对照 `templates/research_question.md` 填写。

如果接入真实数据，教程原先的默认描述是：使用 2020 年后具有完整 `daily_basic` 的 A 股样本；T 日收盘后决策；T+1 复权开盘执行；未来 5 日横截面收益排名为标签；滚动训练；Ridge 为基线；Top-N 等权；RankIC 和成本后风险收益分别评价。本地 `src.run_demo` 使用合成数据验证这条流程，不把合成数据结果当作真实市场结论。

## 2. 公式与规则：把九项写成可执行口径

### 2.1 预测对象：不要直接说“预测价格”

价格水平受股票面值、拆分、复权方式和个股尺度影响。选股研究通常更适合预测收益或收益的相对次序。本教程的预测对象是：

> 对于股票 `i` 在信号日 `T` 的样本，预测它从 `T+1` 开盘到 `T+5` 收盘的未来收益在当日股票池中的相对排名。

模型训练目标是连续的 `label_rank`，不是价格，也不是“必然上涨”的判断。回归器可以输出任意连续数值；组合只使用预测值的排序，因此预测值不必严格落在 0 到 1 之间。

代码中的默认特征由 `src.dataset.FEATURES` 给出：

```python
FEATURES = [
    "mom_5", "mom_20", "reversal_3", "vol_20",
    "range_1d", "amount_chg_5", "log_mkt_cap",
]
```

这些特征只是教学基线，不代表它们一定有效。研究规格应该写“用哪些特征、窗口多长、何时可得”，而不是等模型跑完后从结果倒推解释。

### 2.2 时点：决策、成交和标签不能错位

设 `P_entry(i,T)` 为股票 `i` 在 `T+1` 开盘的价格，`P_exit(i,T)` 为它在 `T+5` 收盘的价格，则计划收益为：

\[
fwd\_return(i,T)=\frac{P_{exit}(i,T)}{P_{entry}(i,T)}-1
\]

在当前实现中，`src.dataset.build_features_and_labels(panel, horizon=5, min_history=...)` 通过交易日历生成：

- `entry_date`：`T` 后第 1 个交易日；
- `scheduled_exit_date`：`T` 后第 5 个交易日；
- `entry_price`：`entry_date` 的开盘价；
- `scheduled_exit_price`：`scheduled_exit_date` 的收盘价；
- `fwd_return`：计划收益；
- `realized_return`：若能买入，则用实际可卖的 `actual_exit_price` 计算的收益；
- `exit_delay_days`：实际退出相对计划退出的延迟天数。

这两个收益不能混用：`fwd_return` 是固定研究窗口的标签，`realized_return` 是考虑不可卖和延迟退出后的组合实现结果。标签用于评价预测，组合回测优先使用 `realized_return`。

### 2.3 股票池：信号资格和成交资格要分开

股票池不是“所有历史上出现过的代码”简单拼在一起。每个 `trade_date × code` 样本至少要明确：

- `signal_eligible`：是否允许进入当天的信号和标签横截面；
- `can_buy`：下一交易日是否有资格买入，合并后体现为 `can_enter`；
- `can_sell`：计划或之后的某个交易日是否可以卖出；
- `history_observations`：截至当天该股票已有多少条历史观测；
- 特征是否完整，是否因 `min_history` 或缺失特征被排除。

当前数据构造逻辑先按 `signal_eligible` 和 `fwd_return` 生成 `label_rank`，回测在选出 Top-N 前再过滤 `can_enter`。所以要区分“可以作为预测对象”和“可以实际成交”：一只股票可以有标签但因 `can_enter=False` 不能进入组合。不能为了让回测好看而把不可买股票无声地删除后再声称它仍代表原股票池。

接入真实 A 股时，股票池应使用当日可知的动态规则，例如历史交易状态、上市时长、风险标记、流动性条件和历史指数成分，而不是用今天的成分股回填过去。真实数据的最低字段和缺口见 `data/README.md`；本地默认演示则由 `src.synthetic_data.make_synthetic_panel` 生成合成股票面板。

### 2.4 标签：先定义收益，再决定是否排名

对每一个信号日 `T`，在当天有效股票集合 `U_T` 中计算未来收益：

\[
R_{i,T}=\frac{P_{i,T+5}^{close}}{P_{i,T+1}^{open}}-1,\quad i\in U_T
\]

本教程的标签是百分位排名：

\[
label\_rank(i,T)=rank\_pct\left(\{R_{j,T}:j\in U_T\}\right)
\]

实现上对应：

```python
eligible_returns.groupby("trade_date")["fwd_return"].rank(pct=True)
```

它是**同一交易日横截面收益排名**，不是市场中性标签，也不是行业中性标签。排名的好处是降低极端收益幅度对训练的影响，代价是丢失绝对收益的幅度信息。

当前配置中的 `label.benchmark` 为 `cross_sectional_median`。数据构造还会计算：

```python
excess_return = fwd_return - 当日有效股票的 fwd_return 中位数
```

但当前训练列仍是原始 `fwd_return` 的 `label_rank`，不是 `excess_return` 的排名。写研究报告时应明确说“横截面收益排名”，不要把这个字段描述成市场中性或行业中性。若未来要训练超额收益标签，应明确修改数据构造、配置和测试，不能只改文字。

### 2.5 基准：至少写清两种“相对谁”

“基准”在研究里可能指两个不同对象：

1. **标签基准**：用来解释未来收益的相对位置。本教程记录横截面中位数，并额外保存 `excess_return` 供检查；`label_rank` 仍直接按 `fwd_return` 排名。
2. **组合基准**：用来判断 Top-N 组合是否只是跟随股票池。当前 `src.backtest.top_n_backtest` 把当天可用于回测的 `day["fwd_return"]` 做等权均值，保存为 `benchmark_return`，并计算 `active_return = net_return - benchmark_return`。

因此，报告至少应同时展示：

- 模型的 `RankIC` 和分组收益；
- 组合的毛收益、成本后 `net_return`；
- 股票池基准收益 `benchmark_return`；
- 相对基准的主动收益和压力成本结果。

等权股票池基准不是无风险收益率，也不能回答所有风险调整问题；它只是当前教学回测的一个透明对照。

### 2.6 成本：先写单位，再写计算式

当前配置使用：

```yaml
model:
  cost_bps: 8
  stress_cost_bps: 20
```

`src.backtest.top_n_backtest` 的教学版成本规则是：

\[
cost=turnover\times\frac{cost\_bps}{10000}
\]

其中 `turnover` 是交易比例：首次建仓为 `1`；如果上一期的持仓全部替换，卖出和买入合计为 `2`。所以默认成本下：

- 首次建仓成本：`1 × 8 / 10000 = 0.08%`；
- 完全换仓成本：`2 × 8 / 10000 = 0.16%`；
- 压力成本下对应为 `0.20%` 和 `0.40%`。

这里的 `8 bps` 是每单位交易比例的简化综合成本，不是对整个调仓无条件只扣一次。当前教学代码没有逐笔模拟佣金、印花税和冲击成本，而是用基础成本和 `20 bps` 压力成本检查结论是否脆弱。真实研究应根据市场、标的和成交量进一步拆分并验证。

### 2.7 评价：模型指标和策略指标分开

**模型层**回答“排序有没有预测力”：

- 每日 RankIC：预测值与当日 `label_rank` 的 Spearman 相关；`src.metrics.rank_ic` 按 `trade_date` 计算；
- Mean RankIC、标准差、ICIR、正 IC 比例；
- 分年度 RankIC 和观测数；
- `src.metrics.grouped_returns` 的五组收益，检查从低预测组到高预测组是否大致单调。

上述口径在本节落实为具体输出：模型层报告每日 RankIC、均值、标准差、ICIR、正 IC 比例、分年度 RankIC 和五组收益；策略层另行报告主动收益、Sharpe、最大回撤、换手、成本和分年度结果。

**策略层**回答“排序能否变成可执行组合”：

- `top_n_backtest` 的 Top-N 等权组合；
- 成本前后收益、股票池基准收益和主动收益；
- Sharpe、主动 Sharpe、最大回撤、年化收益；
- 平均换手、平均成本、持仓数、延迟退出比例；
- 分年度结果和 `stress_cost_bps` 压力结果。

不要只报告一个全期收益，也不要用 `R²` 取代横截面排序评价。指标应该在研究开始前写下，测试期不能因为结果不好就换指标。

### 2.8 假设与失败标准：让研究真的可以被否定

一个可执行规格至少要列出以下假设：

- T 日使用的特征确实在 T 日收盘后可得，没有使用未来价格或未来发布的财务字段；
- 输入价格的复权口径一致，标签起点和终点使用同一口径；
- `can_enter`、`can_sell` 能反映最基本的不可成交情况；
- 组合按照 `top_n`、`holding_days` 和等权规则执行，不能在测试期临时改成更有利的规则；
- 标签为 5 日时，教学回测的 `holding_days` 也为 5；配置校验要求两者相等；
- 时间切分使用滚动样本外，`embargo_days` 至少不小于标签 horizon；当前默认 `train_days=504`、`validation_days=63`、`test_days=63`、`step_days=63`、`embargo_days=5`；
- 合成数据只能验证代码链路，不能作为真实市场有效性的证据。

失败标准应在看测试结果前写好。下面是一组**教学示例规则**，用于演示如何预注册，不是普适的收益或投资标准：

1. 若没有产生有效滚动测试预测，或标签、时点、成交字段无法审计，则研究无效，先修数据和口径；
2. 若全测试期 Mean RankIC 不大于 0，或正 IC 比例不超过一半，则不支持“模型有稳定排序预测力”；
3. 若至少三个独立测试年度中有两个年度 Mean RankIC 不大于 0，则不把全期均值解释为稳定关系；
4. 若基础成本后的组合主动总收益不大于 0，或压力成本下主动 Sharpe 不大于 0，则不支持“该预测能转成当前组合规则下的成本后优势”；
5. 若延迟退出、不可买入或持仓数量异常，导致组合假设与真实成交约束不一致，则先标记执行假设失败，不通过增加模型复杂度来掩盖。

达到失败标准时，结论应是“当前研究规格未被支持”或“需要先修正数据/执行假设”，而不是继续试很多模型直到找到一组漂亮数字。

## 3. 小例子：从一句想法到一次可计算实验

### 3.1 先写研究规格

假设想法是：“用过去的量价特征找未来表现较好的股票。”可以改写为：

| 字段 | 本例规格 |
|---|---|
| 预测对象 | 预测股票从 T+1 开盘到 T+5 收盘的未来收益在 T 日股票池中的百分位排名 `label_rank` |
| 决策与执行 | T 日收盘后计算特征并预测；T+1 开盘尝试买入；T+5 收盘计划退出，不能卖出则顺延 |
| 股票池 | 当日 `signal_eligible=True` 且有完整标签的股票；实际买入还要求 `can_enter=True` |
| 特征 | `mom_5`、`mom_20`、`reversal_3`、`vol_20`、`range_1d`、`amount_chg_5`、`log_mkt_cap`，均只用 T 日及以前信息 |
| 标签 | `fwd_return = scheduled_exit_price / entry_price - 1`；对同一 T 日有效股票做 `rank(pct=True)` 得 `label_rank` |
| 标签基准 | 当日横截面收益中位数；保存 `excess_return = fwd_return - 当日中位数`，但本例训练 `label_rank` 不使用该列 |
| 组合基准 | 当日可回测股票的 `fwd_return` 等权均值，即代码输出的 `benchmark_return` |
| 组合 | 每 5 个交易日选预测最高的 Top-2，等权；不重叠持有 |
| 成本 | 基础 `8 bps`、压力 `20 bps`，成本等于交易比例乘以 `bps/10000` |
| 评价 | 每日 RankIC、五组收益、Mean RankIC、正 IC 比例、成本后主动收益、Sharpe、最大回撤、换手、延迟退出和分年度结果 |
| 核心假设 | T 日收盘后信息可得；T+1 开盘可按 `can_enter` 过滤后成交；价格口径一致；5 日标签与 5 日持有一致 |
| 失败标准 | 按第 2.8 节的教学规则判断，不因测试期结果临时改动 |

这份规格已经可以指导数据构造、模型训练和回测；“找涨得好的股票”则不能。

### 3.2 手算四只股票的标签

假设在信号日 `T` 有四只股票，以下价格已经采用一致的研究价格口径：

| 股票 | T+1 开盘 `entry_price` | T+5 收盘 `scheduled_exit_price` | `fwd_return` |
|---|---:|---:|---:|
| A | 10.00 | 10.50 | 5.00% |
| B | 20.00 | 20.20 | 1.00% |
| C | 8.00 | 8.24 | 3.00% |
| D | 15.00 | 14.70 | -2.00% |

收益从低到高为 D、B、C、A，所以百分位标签为：

| 股票 | 收益次序 | `label_rank` |
|---|---:|---:|
| D | 1 | 0.25 |
| B | 2 | 0.50 |
| C | 3 | 0.75 |
| A | 4 | 1.00 |

当日收益中位数为 `(1% + 3%) / 2 = 2%`，因此 `excess_return` 分别为 A `3%`、B `-1%`、C `1%`、D `-4%`。注意：本实现的 `label_rank` 仍按原始收益从低到高排名；中位数超额列和排名标签是两个不同字段。

假设模型预测从高到低为 A、C、B、D，Top-2 持有 A、C：

\[
gross=\frac{5\%+3\%}{2}=4\%
\]

本次是首次建仓，`turnover=1`，基础成本为：

\[
cost=1\times\frac{8}{10000}=0.08\%
\]

所以：

\[
net=4\%-0.08\%=3.92\%
\]

等权股票池基准为：

\[
benchmark=\frac{-2\%+1\%+3\%+5\%}{4}=1.75\%
\]

本期主动收益为 `3.92% - 1.75% = 2.17%`。这只是一个四股票、一个持有期的演算，不能代替滚动样本外的统计结论。

## 5. 常见错误与自检规则

- **预测“价格”却没有收益起止点**：改写成明确的 `entry_price`、`scheduled_exit_price` 和收益公式。
- **用 T 日收盘特征又以 T 日收盘成交**：将决策放在收盘后、成交放到下一交易日，或把特征严格滞后；本教程采用前者。
- **把 `label_rank` 当成市场中性或行业中性**：当前它只是横截面收益排名；`excess_return` 减的是当日中位数，不等于行业中性。
- **标签基准和组合基准混在一起**：标签侧看横截面中位数与排名，回测侧看代码生成的等权股票池 `benchmark_return`，分别写清楚。
- **把计划收益和实现收益混在一起**：`fwd_return` 用于固定标签窗口，`realized_return` 反映不可成交和延迟退出后的组合结果。
- **忽略成交资格**：预测最高的股票不一定能买入；回测应保留 `can_enter`、`can_sell` 和延迟退出统计。
- **把测试期当调参集**：验证集用于每折选参；测试集只生成一次样本外预测。看到测试结果后改参数，后续结果不再是原测试。
- **只看总收益**：至少同时报告 RankIC、分组收益、基准、主动收益、换手、成本、最大回撤、分年度和压力成本。
- **看到好结果就增加模型复杂度**：先检查标签、时点、幸存者偏差、规模/行业暴露和成本；不能用复杂模型掩盖规格失败。
- **把合成数据结果当成投资证据**：`src.synthetic_data` 只用于验证数据到回测的代码链路。

提交研究前可以做一个五问自检：

1. 我能否用一句公式写出标签？
2. 每个特征在决策时是否已经可得？
3. 股票池、不可成交和退出延迟是否有字段记录？
4. 基准、成本和评价指标是否在看结果前已经固定？
5. 如果结果不好，我是否写过明确的停止条件？

任意一问答不上来，研究问题还没有定义完成。

## 7. 练习答案框架

答案不要求和示例完全相同，但每一项都必须能对应到字段、公式或代码行为。可以按下面顺序检查：

```text
研究问题一句话：
在 [信号时点]，对 [动态股票池] 中的股票，用 [可用特征] 预测
[入场价格] 到 [退出价格] 的 [收益/横截面排名]，并按 [组合规则]
与 [组合基准] 比较，在 [基础/压力成本] 下用 [样本外评价] 判断是否支持假设。

预测对象：应写清是未来收益还是收益排名；本课程参考为 label_rank。
时点：T 日收盘后决策，T+1 开盘入场，T+5 收盘计划退出；不能用 T 日以后信息造特征。
股票池：写 signal_eligible 的历史时点规则；另写 can_enter/can_sell 的成交规则。
标签：
  fwd_return = scheduled_exit_price / entry_price - 1
  label_rank = 当日有效股票的 fwd_return.rank(pct=True)
标签基准：横截面中位数及其 excess_return 诊断；不要写成行业中性。
组合基准：当日股票池 fwd_return 的等权均值 benchmark_return。
成本：
  cost = turnover * cost_bps / 10000
  基础 8 bps，压力 20 bps；首次建仓 turnover=1，完全换仓可接近 2。
评价：每日 RankIC/Mean RankIC/正 IC 比例/分组收益；
  组合净收益、主动收益、Sharpe、最大回撤、换手、延迟退出和分年度结果。
假设：特征点时可得、价格口径一致、成交资格可观测、持有期与标签一致、
  滚动样本外且 embargo 至少覆盖标签 horizon。
失败标准：预先写数值条件，例如 Mean RankIC <= 0、多个独立测试年度不稳定、
  基础成本后主动收益 <= 0 或压力成本下主动 Sharpe <= 0 时，不支持原假设。
跌停处理：标签仍按固定 T+1 到 T+5 的计划 fwd_return；
  组合不能假设按计划卖出，应顺延到首个 can_sell 日，用 actual_exit_price 计算 realized_return，
  并记录 exit_delay_days。
结论动作：若字段、时点或成交逻辑不可信，先数据审计；若规格可审计但结果满足失败标准，
  停止增加模型复杂度并记录“当前假设未被支持”。
```

完成本章后，你应该能从任一结果列反查到：它预测的对象、样本的信号日、标签的价格起止点、股票池资格、基准、成本公式和失败标准。只有这样，后续模型比较才是在比较模型，而不是在比较一组未声明的研究选择。
