# 第三卷 · 03｜行业轮动与历史分类版本

> **状态：教学正文 v1；人工分类版本、成员可得性门禁、行业排序和权重示意可复算。** 本章不使用真实行业历史成分或真实 A 股行业轮动收益。

## 本章核心问题：行业强弱比较的对象是什么？

行业轮动研究通常会根据历史行业表现形成排序，再把排序转化为候选配置。真正困难的部分不是排序函数，而是行业体系会调整、证券成分会进出、历史成员信息也可能迟到。**如果用今天的行业代码反推过去，研究对象本身就可能错。**

本章教你写出可审计的历史分类版本、成员身份、行业分数和评价协议。它不声称某个观察窗口或某种行业强弱分数必然具有预测能力。

## 1. 研究对象是历史时点的行业定义

真实行业研究必须明确：

1. 分类供应商及版本，而不是只写一个行业名称；
2. 分类版本的**生效日**、证券成员的进出有效区间；
3. 分类变动的公布时间与可使用时点；
4. 历史证券身份键与股票代码的有效区间；
5. 行业收益由行业指数还是成员股票组合构成，价格、公司行为与费用口径；
6. 历史成员不完整时的 UNKNOWN，以及分母和覆盖率如何计算。

本教材不是现实行业分类复现。它为教学设计了两个虚构分类版本：

| 人工分类阶段 | 分类版本 | 行业代码示例 |
|---|---|---|
| 前段 | TEACH_OLD | O_A、O_B 等 |
| 后段 | TEACH_NEW | N_A、N_B 等 |

分类切换时，代码并不天然代表同一个经济实体。若没有可信的历史映射，应保留版本差异，不能按代码后缀猜测映射关系。

## 2. 行业分数必须说明输入窗口和可得时间

将当期行业 \(g\) 的历史强弱分数记为 \(s_{g,t}\)。研究者必须说明：

- 分数由行业指数还是成员证券构成；
- 观察窗口和价格复权版本；
- 停牌、缺价、公司行动和行业成员变动如何处理；
- 计算结果何时完成、何时入库、何时可以进入决策；
- 并列值、极端值和缺失值如何处理。

本章数据字段 `strength_score` 是人工生成的行业分数，不对应固定真实观察窗口。其作用只是让读者练习排序、版本管理和未来信息隔离。

## 3. 从行业分数到候选排序

在当期有效行业集合 \(G_t\) 中，可按预先规定的方向排序：

\[
rank_{g,t}=\operatorname{rank}(s_{g,t}),\qquad g\in G_t.
\]

如果采用“分数越高越靠前”的约定，最高分行业可以成为候选；但候选不是订单，也不是成交。必须同时保存当期分类版本、行业代码、成员数量、未知成员数量和数据覆盖状态。

当分类版本切换时，研究者需要明确选择以下哪一种处理：

- 仅在各自版本内部比较；
- 使用有证据支持的历史映射；
- 无法建立映射时，将版本切换视为研究对象变化并重新开始比较。

不能静默把两个版本拼成一条连续历史序列。

## 4. 成员资格与标签可得性

行业成分数据至少需要两条时间轴：

- **有效时间**：证券在业务定义上属于该行业的区间；
- **可得时间**：研究者实际能够取得该成员记录的时刻。

决策时点 \(d_t\) 只能使用满足 \(available\_at_i\le d_t\) 的记录。若一条成员记录在决策后才到达，应标记为 UNKNOWN，而不是自动判定为不属于该行业。

同样，未来收益标签必须等到退出和数据发布完成后才能用于训练。使用固定行数切分不能替代按真实标签可得时刻进行 Purge。

## 5. 行业候选、目标权重和真实持仓

研究报告应分别保存：

1. 行业排序和候选名单；
2. 目标权重与现金；
3. 成员证券清单及其历史资格；
4. 订单、成交、费用和未成交原因；
5. 实际持仓和净值。

如果只计算行业分数乘以未来行业收益，得到的是**事后观察值**，不是可执行组合收益。真实组合还需要成员证券层面的价格、停牌、涨跌停、可卖数量、交易成本和容量证据。

## 6. 可运行实验与数据边界

数据集 [volume3-weekly-synthetic-v1](../../data/teaching/volume3_weekly_v1.json) 包含 16 个人工研究时点、每期四个虚构行业和八只虚构证券；其中一个时期切换分类版本，另一个时期有一条成员记录故意迟到。所有分类、价格和收益均为人工构造。

在仓库根目录运行：

~~~bash
python examples/volume3_strategy_lab.py --json
python -m unittest discover -s tests -p "test_volume3_strategy_lab.py" -v
~~~

查看行业排序、未知成员、训练标签可用性、目标权重和现金代理。测试会改变未来行业收益，要求此前的行业排序和目标权重不变；将行业特征可得时间改到决策之后时，程序必须拒绝。

本实验验证的是**规则与时间门禁的程序实现**，不是实际行业分类、历史成员覆盖或真实交易收益。

## 7. 习题与参考答案

**题 A：** 同一证券在两个教学分类版本中使用了不同代码，能否只按代码后缀判断它们属于同一行业？

答：不能。必须有明确、可追溯的历史映射证据；没有证据就保留版本差异。

**题 B：** 一条成员记录在决策后才可得，能否回填到当期行业成员集合？

答：不能。应保留 UNKNOWN，并单独报告可判定成员数和分母。

**题 C：** 行业候选在下一观察点因价格限制无法买入，能否直接使用行业后续收益作为账户盈利？

答：不能。目标信号不等于成交，必须另有证券清单、订单、成交数量、报价和现金账本。

**题 D：** 人工数据后段的行业排序效果优于前段，能称真实市场 OOS 吗？

答：不能。后段收益由教材人工生成，只用于验证程序时序逻辑；现实市场研究需要重新冻结并独立验收。
