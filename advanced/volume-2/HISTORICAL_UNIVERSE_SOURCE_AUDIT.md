# 第二卷 · 附录 C｜教材独立数据集与复现规范

> **状态：教材数据规范 v1 已建立，三类固定数据全部随仓库发布，可在没有个人量化数据库的环境下运行。** 本页保留旧文件路径以兼容阅读器书签，内容已改为教材自身的数据说明。

## 1. 数据为什么应由教材独立管理？

专业教材必须能被第三方克隆、阅读、复算，而不要求访问作者本人的策略研究项目或数据池。**本书的数据要服务于教学目标，不反过来让第二卷成为某个私人数据仓库的故障记录。**

因此我们把教材数据分为两类：**明确标注来源的真实历史教学行情**与**为验证算法/时间门禁刻意设计的合成数据**。两者不可互相冒充。

## 3. 怎么判断完整和不完整？

首次获得数据，不应直接把每行当成可训练的历史 PIT。必须先检查：

- **来源与版权**：数据供应商、允许的使用/再分发范围、取数时间、复权口径；
- **快照身份**：文件路径、固定版本、SHA-256、字段单位和序号；
- **证券身份**：上市/退市日期、历史代码有效区间，未知不等于不合格；
- **可得时刻**：财报或行情 `published_at`、`ingested_at`、`available_at` 不得晚于决策；
- **标签时刻**：退出成交价、公司行为、标签实际可得时间与研究折间 Purge；
- **研究边界**：挑选的四只明星股不构成全市场动态母体，人工数据更不是现实可交易收益。

这些是**独立教材数据合同**，不必为了讲清它们而引入作者个人策略研究库。

## 4. 一台新电脑如何直接复现？

~~~bash
git clone https://github.com/2514-nzk/quant-learning.git
cd quant-learning
python scripts/verify_teaching_datasets.py
python examples/advanced_pit_intake_lab.py --json
python examples/advanced_universe_coverage_lab.py --json
python examples/advanced_real_evidence_audit.py --json
~~~

如果仓库在构建中的分支，选择 `docs/three-volume-research-framework`。基础校验只依赖 Python 标准库，无需外部网络/私人数据库；真实行情采集是可选的独立维护操作，不属于 CI 的隐式步骤。

## 5. 若将来需要更大的真实 A 股教学样本

优先建立**教材自己可合法发布的公共快照**，而不是读取、复制或改写用户的研究库。新版本应明确：研究题目和证券范围、历史成员与退市规则、日历、单位、复权、源文件指纹、采集代码、失败记录与正确证据等级。

**仅有更大数据量并不等于具有严格 PIT 或独立 OOS**：没有历史首次披露/供应商接收证据，必须如实写明。发布真实股票数据还应审查第三方行情再分发许可；不因程序能够抓取就当然具备再分发权。

## 6. 本附录的完成标准

仓库中固定数据能由同一命令检查，合成事件由单独 JSON 提供，示例代码不会访问其他项目路径；读者不接入外部私有数据也能复算算法与教学结论。这就是数据层面的**可复现教学**。全市场 PIT/OOS 与真实策略业绩仍是另外需要证据的研究问题。
