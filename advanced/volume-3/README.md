# 第三卷｜A 股策略与交易系统

> **状态：第 01–05 章已完成可复算的教学正文 v1；第 08 章为真实价格入门案例；其余 7 章为待写框架。** 本卷尚无通过真实市场独立 OOS、完整 PIT 和真实成交验证的策略结论。

## 第 01–04 章：研究合同、状态、行业与因子方法

第一批章节构成一条通用研究路线：

- [第 01 章策略合同](01_strategy_contract.md)：信号、决策、入场、退出和标签可得性的时间关系；
- [第 02 章市场状态](02_market_regime.md)：冻结状态定义、同日条件/无条件基线和反事实检查；
- [第 03 章行业轮动](03_industry_rotation.md)：虚构分类版本、历史成员身份、行业评分与未知状态；
- [第 04 章反转与动量](04_reversal_momentum.md)：通用观察窗口、Spearman、条件分组和统计解释边界。

数据集 [volume3-weekly-synthetic-v1](../../data/teaching/volume3_weekly_v1.json) 完全属于教材：16 个人工研究时点、每期四个虚构行业和八只虚构证券，含分类版本变化、迟到成员和事后标签。日期不是交易所日历；所有评分、价格和收益均为人工数据，不代表真实行业分类、真实行情或独立市场 OOS。

运行：

~~~bash
python examples/volume3_strategy_lab.py --json
python -m unittest discover -s tests -p "test_volume3_strategy_lab.py" -v
python -m unittest discover -s tests -p "test_volume3_chapters.py" -v
~~~
