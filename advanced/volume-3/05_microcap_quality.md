# 第三卷 · 05｜微盘、价值、质量与持仓更新

> **状态：教学正文 v1；独立合成数据、选股规则演示与边界测试已建立。** 本章是方法教学，不复现任何真实投资组合或内部研究策略。

## 本章要解决的问题

微盘研究不能把一个因子排名直接等同于买入名单，更不能把目标权重直接当作真实持仓。研究者需要分别回答：

1. 决策时点有哪些证券符合历史股票池和数据可得条件？
2. 规模、价值与财务质量指标如何定义，方向和缺失值如何处理？
3. 主排序不足时，候补规则如何事前规定？
4. 停牌、价格限制和卖出受阻时，目标组合如何转化为受约束的持仓？
5. 结果是否依赖少数阈值、特定调仓日或幸存者样本？

本章用通用的主评分 \(Q\)、候补评分 \(B\) 和目标持仓数 \(K\) 演示规则设计。它们是教学占位符，不对应任何生产策略的因子、参数或选股条件。

## 1. 微盘首先是一个历史股票池定义

“微盘”不是跨时期不变的证券标签。研究合同至少需要冻结：

- **证券范围**：普通股、上市状态、风险警示状态、上市期限及退市证券的纳入规则。
- **规模字段**：总市值还是流通市值；使用哪个时点可得的价格、股本和公司行动版本。
- **排序母体**：全市场还是指定板块；分位数在哪个当期合格母体内计算。
- **流动性条件**：成交额、换手率或其他指标的观察窗口、单位、缺失语义和最低要求。
- **历史成员**：成分身份必须使用当时有效的版本，不能用今天的股票池回填历史。

教学数据中的 \`size_rank\`、\`listing_days\` 和 \`liquidity_ok\` 都是人工字段，只用于说明资格门禁，不代表真实证券的历史属性。

## 2. 应计与财务质量：定义不等于方向

应计是财务报表分析中的一个常见研究维度。一种常见的总应计近似写法是：

\[
Accruals_t = \frac{NI_t-CFO_t}{\overline{Assets}_t}
\]

其中 \(NI_t\) 表示期间净利润，\(CFO_t\) 表示经营活动现金流量净额，\(\overline{Assets}_t\) 表示平均总资产。不同研究可能采用资产负债表法、营运资本应计、平均资产或期末资产；口径不同，不能直接拼接。

**不能仅凭指标名称预设排序方向。** 需要先明确会计定义、行业适用性、极端值处理、报告期和修订版本，再检验它与研究目标之间的关系。应计指标也不能替代对现金流、盈利能力、负债、一次性损益和公司生命周期的综合检查。

财务数据应至少保留报告期、公告时间、供应商接收时间、修订版本和策略可用时间。对决策时点 \(d_t\)，只有满足下式的数据才能进入当期特征：

\[
available\_at_i < d_t
\]

本书示例对边界相等的记录采取保守排除。报告期结束日不等于公告日，也不等于研究者实际取得该记录的时刻。缺失值应区分未披露、未采集、供应商缺失、无法映射和真实数值为零。

## 3. 价值、质量与综合评分

价值指标可能包括市盈率、市净率、企业价值倍数等；质量指标可能涉及盈利能力、现金流、资本结构和应计特征。指标之间可能高度相关，也可能共同暴露于行业、规模和周期风险。

为了让规则可审计，可以把预先定义的主评分记为 \(Q_{i,t}\)，候补评分记为 \(B_{i,t}\)。两者应有独立的数据字典：

| 字段 | 必须事先说明的内容 |
|---|---|
| \(Q_{i,t}\) | 原始财务字段、计算公式、方向、标准化母体、可得时间 |
| \(B_{i,t}\) | 候补用途、输入字段、方向、缺失处理、与主评分的重叠 |
| 行业与规模 | 是否中性化、分组方式、历史分类版本 |
| 缺失值 | 缺失原因、是否允许进入排序、是否影响分母 |

本章的合成实验只使用人工生成的 \(Q\) 和 \(B\) 数值，以演示排序与候补流程。它不提供真实因子定义，也不声称任何指标具有预测能力。

## 4. 主排序、候补和调仓规则

一个清晰的教学规则可以写成以下步骤：

1. 在每个决策时点重建合格证券集合，先通过历史成员、上市状态、规模、流动性和数据可得性检查。
2. 对具备主评分 \(Q\) 的证券排序，按事前冻结的方向选出最多 \(K\) 个候选。
3. 若主候选不足 \(K\)，再从剩余合格证券中按候补评分 \(B\) 排序补足；没有有效候补评分的证券不参与该步骤。
4. 目标组合、候补名单和实际可持有名单分别保存，不把候补入选直接记为成交。
5. 每次调仓时，未进入新目标名单的旧持仓形成退出意图；若退出受阻，应保留持仓并记录原因。
6. 目标权重可以从等权基线开始，但必须另外记录受约束后的示意权重和现金。

目标持仓数 \(K\) 和调仓间隔 \(H\) 都是研究设计参数，应通过研究协议预先规定，而不是看到收益结果后反复修改。

## 5. 目标权重与受约束持仓

目标权重 \(w^*_{i,t}\) 是研究者希望达到的配置；受约束持仓 \(w_{i,t}\) 则受到证券状态、资金和交易制度影响。二者通常并不相同。

至少要分别记录：

- 目标证券、目标权重和目标股数；
- 买卖方向、委托数量、价格约束和发单时刻；
- 停牌、价格限制、拒单、未成交和撤单原因；
- 成交数量、成交价格、费用和成交后现金；
- 可卖数量、持仓批次以及受约束后的实际权重。

本章程序只演示“可交易/受阻”状态下的权重与现金账，不模拟盘口队列、真实成交概率、整手取整、T+1 可卖数量、滑点或交易费用。因此，程序输出是**教学用受约束权重示意**，不是成交回放或净值回测。

## 6. 可运行实验：资格门禁、候补与现金核对

数据文件：\`data/teaching/volume3_microcap_synthetic_v1.json\`。证券标识、日期、财务评分、规模排序、流动性状态和交易受阻状态均为人工构造，证据等级为 \`SYNTHETIC_ONLY\`。

在仓库根目录运行：

~~~bash
python examples/volume3_microcap_lab.py --json
python -m unittest discover -s tests -p "test_volume3_microcap_lab.py" -v
~~~

实验输出每期合格证券、主候选、候补、目标权重、受阻事项、受约束权重和现金。边界测试覆盖财务数据迟到、候补与主选分离、停牌/价格限制阻断、旧仓退出受阻及权重核对。

## 7. 稳健性、容量与失败审计

真实研究还需要逐项核验：

- 不同规模定义、排序母体和历史成员版本；
- 财务字段、公告可得时间、修订记录与缺失原因；
- 价值、质量、行业和规模暴露之间的相关性与增量；
- 不同调仓间隔下的换手、成本、容量和风格漂移；
- 停牌、价格限制、退市、公司行动、整手和 T+1 的历史状态；
- 候补、现金替代、旧仓保留和退出受阻等基线；
- 时间区块置信区间、多重检验登记和独立确认样本。

如果结果只在某一组阈值、某一段时期或某个幸存者样本中成立，应将其视为证据不足，而不是继续调参直到曲线变好。

## 8. 习题与参考答案

**题 A：** 财报报告期早于决策日，但公告或数据接收时间晚于决策日，能否使用？

答：不能。应按决策时点真实可得的版本判断，而不是按报告期结束日判断。

**题 B：** 主候选不足 \(K\)，候补评分排名靠前，是否意味着它已经买入？

答：不是。候补只决定研究名单中的补充顺序，仍需经过证券状态、资金、订单和成交检查。

**题 C：** 旧持仓未进入新目标名单，但当天无法卖出，能否立即从组合净值中删除？

答：不能。目标退出不等于卖出成交，应保留持仓并记录受阻原因。

**题 D：** 合成实验中现金和权重能够对账，是否证明策略有效？

答：不能。它只说明程序按教学规则执行，不能证明真实市场 PIT、样本外收益或成交能力。

## 9. 本章交付边界

已交付：微盘历史股票池的定义框架、应计与财务质量的测量边界、通用主评分与候补评分、目标/受约束权重区分、现金核对、独立合成数据和自动化测试。

尚未交付：真实全市场历史成员与财务 PIT、真实证券状态回放、实际成交与容量证据、独立样本外策略结论。这些内容需要合法、独立且可审计的数据来源，不能由教学合成数据代替。
