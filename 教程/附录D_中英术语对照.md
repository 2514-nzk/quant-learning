# 附录 D：中英术语对照

读原书、论文或库文档时，同一个概念常有不同译法。下表以本书的用法为准，英文列用于对照，不要求背诵。

| 中文 | English | 一句话解释 |
|---|---|---|
| 收益率 | return | 卖出价除以买入价再减 1；不同本金可以比较。 |
| 毛收益 | gross return | 未扣交易成本的收益。 |
| 净收益 | net return | 扣除费用、滑点等成本后的收益。 |
| 基准 | benchmark | 事先规定的对照组合，用来判断选择是否更好。 |
| 超额收益 | excess return | 组合收益减去基准收益，通常用百分点表示。 |
| 组合 | portfolio | 一篮子持仓及其权重。 |
| 权重 | weight | 某只股票或某类资产占组合资金的比例。 |
| 等权 | equal weight | 每只入选股票分配相同资金。 |
| 交易日 | trading day | 交易所开市的日子；周末和休市日不算。 |
| 决策时点 | decision time | 做决定并承诺交易的时点；只能用此时可得的信息。 |
| 回测 | backtest | 把规则放回历史，在每个决策时点只用当时信息重放。 |
| 研究规格 | research specification | 别人照着做能得到同一张表的规则说明。 |
| 策略 | strategy | 把选择、买卖时点、费用和受限处理写清的规则。 |
| 前视偏差 | lookahead bias | 使用了决策时点尚不可得的信息。 |
| 探索 | exploratory | 用来提出想法、修改规则的数据和结果。 |
| 确认 | confirmatory | 用没参与规则选择的数据做最终检查。 |
| 证据边界 | evidence boundary | 隔开探索与确认的那条线。 |
| 试验日志 | trial log | 每次规则版本、看过的数据和结果的记录。 |
| 时点一致 | point-in-time (PIT) | 只使用决策时点已经可见的数据版本。 |
| 主键 | primary key | 能唯一定位一行记录的字段组合，如日期加股票。 |
| 横截面 | cross-section | 同一天把多只股票放在一起比较。 |
| 时间序列 | time series | 沿着同一只股票的日期向前读。 |
| 特征 | feature | 决策时点已知、用来打分的输入。 |
| 因子 | factor | 正在检验是否具有排序能力的候选特征。 |
| 标签 | label | 事后才能知道的答案，用于学习和评价。 |
| 信号 | signal | 由特征或模型产生的排序、分数或方向。 |
| 缺失值 | missing value | 没有观测到的值；“不知道”不等于零。 |
| 幸存者偏差 | survivorship bias | 历史样本只剩活到今天的公司，收益被高估。 |
| 数据泄漏 | data leakage | 未来信息以预处理、切分或标签形式进入训练。 |
| 训练集 | training set | 用来估计模型参数的数据。 |
| 验证集 | validation set | 用来比较候选设置的数据。 |
| 测试集 | test set | 设置确定后，最后评价一次的数据。 |
| 样本外 | out-of-sample | 没参与模型拟合或选择的数据。 |
| 标准化 | standardization | 减均值、除以标准差，把不同尺度放到同一量级。 |
| 正则化 | regularization | 限制模型权重过大，降低过拟合。 |
| RankIC | rank information coefficient | 预测排名与未来收益排名的横截面相关系数。 |
| 分组收益 | grouped returns | 按分数分组后，各组未来收益的对比。 |
| 换手 | turnover | 一个持有期内被替换掉的持仓比例。 |
| 覆盖率 | coverage | 有有效分数、可以参与排序的股票比例。 |
| 因子冗余 | factor redundancy | 两个因子提供的信息高度重叠。 |
| 消融 | ablation | 去掉一个输入或模块，观察成绩变化。 |
| 增量检验 | incremental test | 在已有基线上增加信息，成绩是否稳定改善。 |
| 买卖价差 | bid-ask spread | 买价与卖价之间的差额。 |
| 滑点 | slippage | 计划价格与实际成交价格之间的差。 |
| 市场冲击 | market impact | 大额订单本身推动价格造成的不利影响。 |
| 盈亏平衡成本 | breakeven cost | 使策略超额收益归零的成本水平。 |
| 现金约束 | cash constraint | 买不到或未成交时，剩余资金不能凭空使用。 |
| 延迟退出 | delayed exit | 计划卖出未完成，持仓和资金继续被占用。 |
| 最大回撤 | maximum drawdown | 从历史高点到之后低点的最大跌幅。 |
| 夏普比率 | Sharpe ratio | 相对无风险收益的超额，除以收益波动。 |
| 线性回归 | linear regression | 用输入的加权和预测目标。 |
| 决策树 | decision tree | 按条件层层切分样本，在叶子里给出预测。 |
| 随机森林 | random forest | 多棵树的预测汇总，降低单棵树的方差。 |
| 梯度提升 | gradient boosting | 逐棵树修正前面留下的误差。 |
| 学习率 | learning rate | 每棵树对最终预测的贡献缩放。 |
| 早停 | early stopping | 验证成绩不再改善时停止训练。 |
| 过拟合 | overfitting | 在训练数据上很好，换到新数据就变差。 |
| 模型容量 | model capacity | 模型能拟合多复杂关系的自由度。 |
| 特征重要性 | feature importance | 某个输入对预测贡献的相对大小。 |
| 置换检验 | permutation test | 打乱分数后重算，估计“碰巧这么好”的概率。 |
| oracle | oracle | 用真实未来收益打分的事后上界，只用于诊断，不能交易。 |
| 自助法 | bootstrap | 有放回重抽样，估计统计量的波动区间。 |
| p 值 | p-value | 在原假设下，观察到当前或更极端结果的概率。 |
| 运行日志 | run log | 每次运行的配置、数据切分、指标和输出记录。 |
| 文件指纹 | file fingerprint | 由文件内容计算的识别值，用于确认版本一致。 |
| 漂移 | drift | 输入分布或特征与目标关系随时间变化。 |
| 复现 | reproducibility | 用保存的输入、配置和环境得到同一结果。 |

## 容易混淆的词

| 两个词 | 区别 |
|---|---|
| 特征 vs 因子 | 特征是一个输入；因子是正在被检验有没有排序能力的候选特征。 |
| 标签 vs 未来收益 | 标签是模型学习的目标；它可以由未来收益构造，也可以是排名或分类。 |
| 基准 vs 对照 | 基准是事先规定的比较组合；对照可以是任何用来排除其他解释的组。 |
| 泄漏 vs 前视偏差 | 泄漏是更宽的概念；前视偏差是其中最常见的一种。 |
| 参数 vs 超参数 | 参数从训练数据估计；超参数由验证数据选择。 |
| 回测 vs 模拟盘 | 回测重放历史；模拟盘用实时行情向前跑，不参与历史拟合。 |
| 因子有效 vs 策略赚钱 | 因子有排序能力，不等于扣费、成交和风险约束后仍能赚钱。 |
