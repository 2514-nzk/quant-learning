# 第 10 章｜多因子合成与增量检验

三列都准备好了，你把它们相加，满心期待名单变得更聪明。程序仍然给出 A、C。

这不是程序卡住。先看它究竟怎样投票。

## 1. 因子方向、尺度与等权合成

直接相加原始 EP、ROE 和涨幅，会让取值范围较大的一列更有影响。你们先用最容易核对的方法：每列在同一候选范围内排名，再把名次除以股票数。

| R01 股票 | EP 名次占比 | ROE 名次占比 | 动量名次占比 | 三列平均 |
|---|---:|---:|---:|---:|
| A | 1.00 | 1.00 | 1.00 | 1.0000 |
| B | 0.75 | 0.50 | 0.25 | 0.5000 |
| C | 0.50 | 0.75 | 0.75 | 0.6667 |
| D | 0.25 | 0.25 | 0.50 | 0.3333 |

A、C 仍是前两只。本期相对只看动量没有换仓，因而不可能仅凭“多用了两列”就获得不同的本期持仓收益。

## 2. 排名合成的代码实现

```python
import pandas as pd  # 导入表格工具。

all_rows = pd.read_csv("data/story/rounds.csv")  # 固定练习册，含输入和事后答案。
day = all_rows.loc[all_rows["round_id"] == 1].set_index("code")  # 只取第一期。
factors = ["ep", "roe", "mom_5"]  # 打分只读这三个已知输入，不读未来收益。
positions = day[factors].rank(method="average", pct=True)  # 每列分别排名。
score = positions.sum(axis=1, min_count=3) / 3  # 三列齐全才产生平均分。
print(score.round(4))  # 与上面的手算表核对。
```

`min_count=3` 很重要。若某只股票只剩一个有效因子，不能让默认跳过缺失的平均，悄悄把这一票当成全部依据。

缺失处理改变有效股票范围时，还要在共同样本上重算对照，记录少了谁。

## 3. 消融实验与增量信息

小林建议先做一件比增加第四列更有用的事：去掉动量，只平均 EP 和 ROE。

B、C 都得到 0.625，按事先规定的名字顺序，B 排在 C 前。于是本期入选 A、B，未扣费收益为 3%，而原来的 A、C 是 4%。

这说明在这一个截面里，动量参与了 B、C 的区分。它仍不是动量长期有价值的证明。

**删除一类输入后重做比较**，后面会叫消融实验。先用这次投票差异记住它的意思。

## 4. 多期组合对照与探索边界

回到前四期，三列合成在 R01–R03 都选 A、C；到 R04，A、B 合成分数并列为 0.75，按固定规则选中两只。两只未来收益平均为 0%。

| 同样从 8,000 元起步，四期未扣费复乘 | R04 期末金额 |
|---|---:|
| 只看动量 M0 | 7,970.96 元 |
| 三列排名平均 | 8,133.63 元 |

三列版本在这四期题目里少受了一次损失。它是在我们已经看过这些题以后被讨论的，因此属于探索。要把它加入候选，再按第 4 章留下的验证与测试职责比较，不能拿这一小表立即宣布胜出。

## 5. 因子冗余与类别权重

如果你加入“过去五日涨幅”和它的两倍，两列名次完全相同。平均以后虽然多了一列，信息没有增加。

EP 和 ROE 也可能受相似公司特征影响。我们需要查看名次是否常相似，选中的股票是否常重叠，以及错误是否一起出现；不能只数自己拥有几个指标。
