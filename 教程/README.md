# A 股量化研究入门：从问题到样本外证据

这本书沿着一项研究从提出问题到复核结论的完整过程展开：先明确假设、数据时点和验证方法，再构造因子、评价信号、形成组合，最后比较模型并整理可复现的研究。全书主线分为五编、十六章；请按这里的顺序阅读，文件名中的旧编号仅用于仓库内部管理。

## 阅读导览

- [实践准备：量化研究中的 Python 数据处理](00d_量化Python实战.md)
- [实践准备：量化研究够用的数学与统计](00e_量化数学与统计.md)

这两篇准备材料用来熟悉面板、信息时点、统计评价和不确定性。完成后，从第一编开始顺序阅读。普通 pandas 语法、市场术语和机器学习概念放在参考资料中，遇到需要时再查。

## 第一编：研究问题与证据设计

先定义要检验的关系和研究边界，再说明每个数据字段何时可得、未来结果如何计算，以及怎样避免验证过程泄漏。

1. [把研究想法写成可检验的问题](01_研究问题定义.md)：明确对象、时点、股票池、标签、基准、成本和失败条件。
2. [从假设到研报复现](01a_研究假设与研报复现.md)：区分事实、解释和假设，记录复现差异。
3. [数据、标签与信息时点](02_数据与标签.md)：构造面板，按交易日历对齐标签，并审计 PIT 与成交状态。
4. [时间顺序与泄漏](04_时间切分与泄漏.md)：先固定滚动验证和隔离规则，建立可信的样本外评价边界。

## 第二编：构造并检验因子

从基础量价输入出发，写清因子的计算，再用覆盖、排序和稳定性检验它提供了什么证据。

5. [特征工程：从稳定输入开始](03_特征工程.md)：理解基础量价特征、处理规则和特征审计。
6. [用算子准确表达因子](03a_因子表达式与算子.md)：定义时间序列与横截面操作，并核对窗口、缺失和并列值。
7. [定义传统因子并做好预处理](03b_传统因子与预处理.md)：为 EP、ROE、MOM_120_20 写出时点、单位和处理规则。
8. [单因子研究与评价](08a_单因子研究与评价.md)：用覆盖率、IC、分组、衰减和稳定性判断证据强弱。

## 第三编：从信号到组合

9. [从分数到可交易组合](09_预测到组合.md)：把排序变成目标持仓，处理买卖限制、成本、基准和换手。
10. [多因子合成与综合实训](09a_多因子合成与综合实训.md)：手算合成分数，设计增量比较和月度项目。

## 第四编：检验模型是否增加信息

因子证据和组合基线建立后，再增加模型复杂度。比较模型时沿用前面确定的数据、时间切分和交易口径。

11. [线性基线](05_线性基线.md)：用 Ridge 等简单方法建立可比较的标尺。
12. [决策树与随机森林](06_决策树与随机森林.md)：理解非线性、模型复杂度与稳定性。
13. [Boosting 与 LightGBM](07_GBDT与LightGBM.md)：理解逐步拟合、早停和调参纪律。
14. [模型评价与解释](08_模型评价与解释.md)：分别评价排序预测、组合表现和特征解释。

## 第五编：复现与完整实训

15. [把研究整理成可复现项目](10_研究框架与结课项目.md)：固定规格、保存证据、组织报告并检查实现边界。

## 本书中的两种练习案例

两类案例练习同一套研究方法，但服务于不同的研究规格，不能直接比较回测收益。

| 案例 | 用来练什么 | 当前实现边界 |
|---|---|---|
| 五日模型案例 | T 日收盘产生信号，T+1 开盘执行，T+5 收盘计算标签；使用合成数据或量价快照练习时间切分、模型比较和简化回测。 | `src.run_demo` 与 `src.run_duckdb_demo` 可以运行；教学回测不包含逐笔交易和完整风格归因。 |
| 月度三因子案例 | 定义、检验并合成 PIT EP、ROE、MOM_120_20；从四只股票手算走向月度 Top-50 项目规格。 | 讲义提供定义卡、小样本演算和验收要求；真实财务接入、历史行业和完整月度持仓账本仍需实现。 |

阅读时把注意力放在共通的研究流程和证据纪律上；频率、数据、持有期和实现范围则分别核对。
