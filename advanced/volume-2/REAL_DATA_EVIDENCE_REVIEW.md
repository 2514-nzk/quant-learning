# 第二卷｜真实历史价格的研究证据审计

> **状态：真实 OHLC 算术与来源完整性可复算；严格 PIT、完整市场母体、独立 OOS 与真实执行均未验证。**

这份教学审计连接第二卷第 05–08 章。所有价格来自仓库已有的四只 A 股 2024 年历史数据，**不新增策略、不声称发现 Alpha**。

## 一、先说清楚数据到底是什么

仓库保存贵州茅台、寒武纪、宁德时代、比亚迪四只股票的 2024-01-02—2024-06-28 日 K 线，每只 117 行，均为不复权价格。采集来源见 [manifest](../../data/real_a_share/manifest.json)，快照采集时间为 **2026-11-11 UTC**。第一卷从这些数据构造了 18 个非重叠观察期。

必须区分三个概念：真实历史市场价格、当年历史决策可用的 PIT 数据、具有独立测试意义的研究数据。这份数据满足第一个基本身份，但**缺少**供应商在 2024 年逐笔发布/接收的证据，四只知名股票也是事后固定选择；此前所有观察期已在课程中公开。不能用它证明后两者。

## 二、证据门禁

| 门禁 | 当前可以验证的内容 | 结论 |
|---|---|---|
| L0 | 每只 CSV 的 SHA-256 与固定 manifest 匹配、行数/日期/OHLC 合理 | 原始文件完整性可复核 |
| L1 | 从原始 CSV 重新计算教材保存的 MOM5 与未来观察收益 | 派生算术可复核 |
| L2 | 信号日在入场前、退出在入场后、相邻观察期不重叠；未来退出价不能回流当前因子 | 日期级逻辑可复核 |
| L3 | 当年行情发布/接收/入库时刻 | **NOT_PROVEN** |
| L4 | 当年完整动态上市/退市和资格母体 | **FAIL_SELECTED_SURVIVORS** |
| L5 | 历史分红、复权与总收益 | **NOT_PROVEN** |
| L6 | 没被看过的独立 OOS | **FAIL_PREVIOUSLY_EXPLORED** |
| L7 | 真实委托、排队、拒单、成本和现金账本 | **NOT_PROVEN** |

L0–L2 通过不意味着其它门禁自动通过。特别是 `manifest.captured_utc` 只说明采集时间，不能回填成 `feature_available_at`。

## 三、计算公式与固定描述性结果

信号日收盘后用过去五个交易日动量，下一交易日开盘与退出日收盘构成观察收益：

\[
MOM5_{i,t}=C_{i,t}/C_{i,t-5}-1,\qquad
y_{i,t}=C_{i,exit(t)}/O_{i,entry(t)}-1.
\]

每期四股 Spearman RankIC 记为 `IC_t`。选得分前两股的理论毛平均收益与四股等权之差：

\[
d_t=R^{gross}_{Top2,t}-R^{gross}_{Equal4,t}.
\]

| 指标 | 本地固定历史数据 |
|---|---:|
| 横截面证券数 | 4 只 |
| 非重叠观察期 | 18 期 |
| 平均 RankIC | **−0.1222** |
| 正 RankIC 期数 | **7 / 18** |
| 平均单期 Top2−Equal4 毛收益差 | **+0.1239 个百分点** |
| Top2 跑赢等权期数 | **10 / 18** |

这些数值不互相矛盾：RankIC 是完整四股排序相关，Top2 差只比较两种固定组合的**收益幅度**。这也不是“四股×18 期=72 个独立样本”。

脚本进一步给出 HAC(2)、循环移动区块 Bootstrap（区块 2、3、4）、逐期剔除影响与已公开的前10/中4/后4小段。**这些只是对该教学样本的描述性不确定性测量**，不能通过置信区间或后四期表现消除样本选择、数据来源及确认集重复使用问题。

## 四、怎样复算和反驳

~~~bash
python examples/advanced_real_evidence_audit.py
python examples/advanced_real_evidence_audit.py --json
python -m unittest discover -s tests -p "test_advanced_real_evidence_audit.py" -v
python examples/advanced_real_evidence_audit.py --output outputs/real_four_stock_audit_v1.json
~~~

脚本只读取仓库内固定原始文件，输出命令默认拒绝覆盖已有报告。测试主动更改 CSV 字节以触发 SHA 错误、篡改缓存观察收益以触发比对错误、移动时间边界以触发重叠错误，还验证未来退出价格的变动**不会**改变当期 MOM5 和选股排名。

## 五、由此推导的下一步研究需求

要从真实价格练习升级到真正的 A 股专业研究，最先需要补历史动态证券池、历史行业/财报及修订版本、源发布/接收时间证据、公司行为、标签可用时间和真实执行约束。之后才能冻结参数、完整登记实验，在新的未触碰验证期检验统计增量及成本后表现。若这些来源不具备，应明确报告“证据不足”，而不是把已知的四股小样本当作全市场 PIT。
