## 接入真实 A 股的最低数据

每行是一个 `trade_date × code` 样本，建议至少覆盖 5 年日频数据（含训练、验证、测试和足够的滚动窗口）。必须有：

| 字段 | 含义 | 时点要求 |
|---|---|---|
| `trade_date` | 交易日 | 交易所日历 |
| `code` | 证券代码 | 保留历史代码映射 |
| `open`, `high`, `low`, `close` | 价格 | 明确前复权/后复权口径 |
| `volume`, `amount` | 成交量、成交额 | T 日收盘后可得 |
| `adj_factor` | 复权因子（若自行复权） | 不能把未来信息错误回填到历史决策 |
| `is_suspended` | 停牌标记 | 用于过滤不可交易样本 |
| `is_limit_up`, `is_limit_down` | 涨跌停标记 | 用于成交约束 |
| `is_st`, `listed_days` | 风险和上市时长 | 按当日可知状态 |
| `sector` | 行业分类 | 最好保留历史行业版本 |
| `universe_flag` | 当日股票池 | 不能用当前成分股回填历史 |

如果加入财务因子，还需要 `announcement_date`（公告日）和报告期，不能只用 `report_period` 对齐。

## 真实数据的最低质量检查

- 日历连续性、重复键、价格非正、成交额异常。
- 复权口径和收益起止价格一致。
- 新股、退市、ST、停牌、涨跌停和一字板有明确处理。
- 股票池是历史时点可得的动态股票池。
- `config/research_config.yaml` 的 `data.min_history` 会按证券逐只限制最少历史观测数，避免新上市或历史过短的样本直接进入特征和标签。
- 每个特征都有公式、窗口、滞后、缺失率和可用时点。
- 下载后保存原始快照和版本号，避免数据源变化导致无法复现。

## 可选数据源

课程代码不绑定供应商。你可以用已有的本地数据、券商导出、AKShare、Tushare 或专业数据终端；只要转换为上述字段契约即可。先用合成数据跑通，再接真实数据，能显著减少“数据问题”和“模型问题”混在一起的排查成本。
