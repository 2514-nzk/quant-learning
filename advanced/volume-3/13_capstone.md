# 第三卷 · 13｜综合项目：策略立项、反证与退出

**先看一个实际问题：回测曲线好看、测试全部通过，就可以把 100 万元交给程序了吗？**

不能。测试通过说明某些代码行为符合约定，并不说明股票池覆盖完整、因子有真实市场优势、订单可以成交，或生产系统足够安全。本章把前三卷的知识整理成一份能够被复核、被否定的研究报告。

## 1. 从研究想法写出一份明确的协议

继续使用第二卷 40 只人工股票、5 个行业、24 期观察的固定面板，第三卷第 11 章在最后六期比较反转与动量固定配置、风险配置和现金。第 12 章单独演练纸面订单系统。

| 必须冻结 | 本项目 |
|---|---|
| 数据与版本 | 固定种子人工面板和输入指纹 |
| 候选 | REV20、MOM5、固定与风险配置 |
| 时间 | 每五个时段决策，次期开盘模拟成交 |
| 对照 | 固定配置、风险配置、现金 |
| 执行 | 整手、人工费用、滑点和成交限制 |
| 失败条件 | 对账失败或故障演练失败则停止修复 |

策略配置不因最后六期收益重新选择。已公开的六期只用于教学演示，不能称为独立确认；纸面故障账本不是同一回测的真实订单回报。

## 2. 研究报告从哪里开始看？

先检查数据和时点，然后看实际收益，不要先挑曲线最好看的模型。数据和政策分别计算 SHA-256 指纹，报告还计算自身内容的指纹（不含自身哈希字段）。

~~~formula
输入和版本 → 信号 → 目标权重 → 模拟订单 → 实际模拟持仓
→ 现金及每日净值 → 金额归因 → 反证 → 结论
~~~

指纹可以发现内容变动，不能证明真实、合法或没有泄漏。报告应保留失败和未成交，不允许只保存成功的订单。

## 3. 六道门槛：程序正确不等于市场有效

| 门槛 | 本实验检查什么 |
|---|---|
| ledger_reconciled | 各账户每日金额归因残差及累计账本 |
| fault_drill | 重启重试、重复成交、对账差异、T+1 |
| real_pit | 真实历史信息可得性，当前未证明 |
| independent_oos | 独立真实市场样本外，当前未证明 |
| real_execution | 实际市场成交、费用和容量，当前未证明 |
| production_approval | 生产测试与人工审批，当前未获得 |

故障或账本检查失败，结论 STOP_AND_REPAIR；两项通过但真实市场和生产门槛未满足，结论 RESEARCH_ONLY。全部门槛都有证据时也仅是 ELIGIBLE_FOR_HUMAN_REVIEW，不表示自动交易。

## 4. 什么时候应停止或重新研究？

策略异常不等于立即认定因子失效。先排查数据版本、股票池变化、市场与行业暴露、成本、成交率、模型输入和标签定义。如果是数据或订单异常，优先停止新意图并对账，而不是借故障重新调参。

如果独立证据反复表明净超额不满足事前标准，可以降级或关闭研究。不能在回撤中途临时挑选一个最有利的退出点，然后回填为历史规则。真实停机时还需要管理存量持仓与可卖数量；停止交易程序不等于已卖掉所有证券。

重新启用需要新研究版本、明确变更原因、独立确认样本和人工审批。没有新证据则继续研究或维持关闭。

## 5. 完整项目怎么复算？

运行 [综合项目程序](../../examples/volume3_capstone_lab.py)：

~~~bash
python examples/volume3_capstone_lab.py --chapter 13
python examples/volume3_capstone_lab.py --json
python -m unittest discover -s tests -p "test_volume3_chapters.py" -v
~~~

网页末尾也可运行，无需个人数据库、券商连接或真实账户。JSON 输出包含：

| 对象 | 用途 |
|---|---|
| input_sha256 / policy_sha256 | 固定数据与规则 |
| allocation | 多策略目标、模拟订单和归因 |
| paper | 独立故障演练与恢复日志 |
| gates / decision | 证据检查与研究决策 |
| report_sha256 | 报告完整性指纹 |

复算时应检查相同输入得到相同报告，改变未来价格不改变历史目标，持仓和现金对账一致，错误门槛会阻止报告声称可上线。即使人工模拟净值盈利，仍然不能越过真实市场证据门槛。

## 6. 毕业练习与参考答案

**练习：** 假设风险账户净值比固定配置高，但缺少真实 PIT 和成交证明；纸面实验又发现重复回报会重复扣款。应该上线、继续研究，还是停止修复？

答：先停止修复，修正账本后重新跑全部故障测试。即使修好也只能继续研究，不能将人工收益当成实盘证据。

**练习：** 未来希望改用中证 1000 历史成分，第一步是什么？

答：确认历史成员版本、上市退市与状态、复权公司行为、公告时间、交易日历、授权与数据缺口。先做数据审计，不是直接替换股票代码表。

## 7. 三卷学完后还需要什么？

第一卷训练四只真实股票的手算直觉；第二卷训练时点、统计、机器学习、组合与执行；第三卷将这些方法用于不同策略问题、风险配置和纸面故障演练。
