# 起步第二课｜读懂第一段量化代码

这一课把刚才四只股票的手算翻译成 Python。先顺着文字看懂代码在做什么，再运行。完整脚本是[first_quant_experiment.py](../examples/first_quant_experiment.py)，只使用 Python 自带功能。

代码里 `#` 后的中文是注释，帮助你理解这一行，不参与计算。遇到不熟悉的写法，可以先看旁边的注释，再对照运行结果。

## 1. 用名字保存一个数

```python
buy_price = 10.00  # 用变量保存每股买入价，单位为元。
sell_price = 10.50  # 保存以后卖出时的每股价格。
future_return = sell_price / buy_price - 1  # 价格相除再减 1，算出小数形式的收益率。
print(f"收益率：{future_return:.2%}")  # 把变量填入花括号；.2% 表示按百分数保留两位小数。
```

输出是 `收益率：5.00%`。

`=` 表示把右边的计算结果存到左边的名字里。`/` 表示除法，`-` 表示减法。`future_return` 保存的是小数 `0.05`。

`print` 把结果显示出来。最后一行里的 `f"..."` 可以在花括号中放变量；`.2%` 表示按百分数显示，并保留两位小数。

变量名可以自己取，但最好能看出含义。这里的英文是代码中的名字，不是需要背诵的新金融概念。

## 2. 用一条记录表示一只股票

```python
stock = {"code": "A", "past_return": 0.08}  # 一个字典保存一条股票记录，0.08 就是 8%。
print(stock["code"])  # 用字段名 code 取出股票名字。
print(stock["past_return"])  # 取出过去涨幅，显示为小数 0.08。
```

输出分别是 `A` 和 `0.08`。

花括号里的这种记录叫**字典**：每个字段都有一个名字，冒号右侧是它的值。`stock["past_return"]` 就是取出这条记录的过去涨幅。

四条记录放在方括号组成的**列表**里，就像把表格的四行收在一起：

```python
# 方括号把四条股票记录收进同一个列表。
known_stocks = [
    {"code": "A", "past_return": 0.08},
    {"code": "B", "past_return": -0.01},
    {"code": "C", "past_return": 0.04},
    {"code": "D", "past_return": 0.02},
]
```

`"A"` 带引号，表示文字；`0.08` 是数值。代码中的缩进和括号要一起保留。

## 3. 告诉电脑按哪一列排序

下面片段接在前面的列表之后：

```python
# 定义一个函数，接收一条股票记录。
def read_score(stock):
    return stock["past_return"]  # 取出过去涨幅，作为这只股票的分数。

ranked = sorted(known_stocks, key=read_score, reverse=True)  # key 指定评分函数，reverse=True 表示分数从高到低。
selected = ranked[:2]  # [:2] 取排序后的前两条记录。

# 逐只取出入选股票，执行下面缩进的语句。
for stock in selected:
    print(stock["code"])  # 取出当前股票的名字并显示。
```

它会依次输出 `A`、`C`。

逐行读：

1. `def` 定义一个小工具，名字叫 `read_score`；它接收一条股票记录。
2. `return` 把这条记录的过去涨幅交回去。
3. `sorted` 按这个分数排序，`reverse=True` 表示从高到低。
4. `[:2]` 取排序后的前两条记录。
5. `for` 表示逐条重复执行缩进中的动作，这里是打印股票名字。

选股的小工具只读取 `past_return`。它完全没有查看未来价格。

## 4. 选完以后，再取未来价格算收益

在另一张表里保存事后才能知道的答案：

```python
# 按股票名字保存价格；entry 是买入价，exit 是卖出价。
future_prices = {
    "A": {"entry": 10.00, "exit": 10.50},
    "B": {"entry": 20.00, "exit": 20.20},
    "C": {"entry": 8.00, "exit": 8.24},
    "D": {"entry": 15.00, "exit": 14.70},
}

# 输入股票名字，计算它的未来收益。
def calculate_return(code):
    prices = future_prices[code]  # 用股票名字查到对应的价格字典。
    return prices["exit"] / prices["entry"] - 1  # 卖出价 / 买入价 - 1，得到小数形式的收益率。

total_return = 0.0  # 先把收益合计设为零，后面逐只累加。
# 这次只遍历入选的两只股票。
for stock in selected:
    total_return = total_return + calculate_return(stock["code"])  # 把当前股票的收益加到合计中。

portfolio_return = total_return / len(selected)  # len 数入选股票的个数；等权组合使用简单平均。
print(f"组合毛收益：{portfolio_return:.2%}")  # 按百分数显示，保留两位小数。
```

`len(selected)` 是入选股票的数量，本例为 2。循环把 A、C 的收益加在一起，再除以 2，结果是 `4.00%`。

这个平均只适用于当前“各分一半资金”的规则。若一只占 80%、另一只占 20%，应按权重计算，不能继续简单平均。

## 5. 运行完整脚本

前面各段需要按顺序放在同一个 Python 文件里。配套脚本已经把它们接好，并加上了四只股票的等权基准。

在项目根目录打开 PowerShell，先检查 Python：

```powershell
python --version
```

如果尚未安装，可以从[Python 官网](https://www.python.org/downloads/)安装 Python 3.11 或 3.12，Windows 安装时启用将 Python 加入 PATH 的选项，再重新打开终端。本课无需安装额外依赖。

然后运行：

```powershell
python examples/first_quant_experiment.py
```

预期输出：

```text
入选股票：A、C
组合毛收益：4.00%
候选股票等权平均：1.75%
比基准多：2.25 个百分点
8000 元期末变为：8320.00 元（未扣费用）
```

完整脚本中的 `append` 把股票名字逐个加入名单，`"、".join(...)` 用顿号连接这些名字；另一段循环用同样的方法计算全部候选股票的平均收益。

这里的电脑只是替我们做了手算。运行一次成功说明这段计算和手算一致，接下来还要研究规则在其他日期是否站得住。

## 6. 只改一个数，先猜结果

在配套脚本里把 A 的未来卖出价从 `10.50` 改成 `9.00`，其他内容保持原值。

先回答：入选股票会改变吗？组合收益会是多少？

**答案：** 入选仍是 A、C；A 的未来收益变成 -10%，C 仍是 3%，所以组合收益为 `(-10% + 3%) / 2 = -3.50%`。选股依据只在已知数据表里，未来价格改变只影响事后成绩。

如果看完这段亏损才把 A 从当时的入选名单删掉，就混入了未来信息。第 4 章会进一步解释这类错误。
