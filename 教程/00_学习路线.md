# 阅读指南｜怎么读这本书

这本书从一笔 8,000 元开始，先让你做一次能复查的选股研究，再通过每章的进阶训练和独立实战路线，把入门计算接到研究级的数据、模型和执行流程。

研究搭档小林是虚构人物。他会递来新数据、提议换规则，也会和你一起看失败。你不需要先会 Python，也不需要先背金融名词。

股票、交易日编号和数据都为教学构造。它们让计算足够小、错误足够清楚；模型结果由配套程序实际运行产生。它们用来练习研究方法，不能证明真实市场里的收益。

## 1. 先别背名词，跟着这 8,000 元走

假设现在给你 **8,000 元教学用虚拟资金**。只有四只虚构股票 A、B、C、D，你还不知道哪只会涨。

第一步只看它们**过去五天**的表现：

| 股票 | 过去五日涨幅 | 排名 |
|---|---:|---:|
| A | 8% | 第 1 |
| B | -1% | 第 4 |
| C | 4% | 第 2 |
| D | 2% | 第 3 |

我们约定买排名前两名，也就是 A 和 C，各分 4,000 元。这是一个**选股规则**。等未来过了五个教学交易日，才打开答案：A 涨了 5%，C 涨了 3%。

```text
A：4,000 × (1 + 5%) = 4,200 元
C：4,000 × (1 + 3%) = 4,120 元
合计：4,200 + 4,120 = 8,320 元
```

你已经完成了第一次“量化”：**事先写规则 → 按规则选择 → 事后算结果**。这就是全书的起点。

本书以后出现的新名字，都可以先翻译回一个熟悉的问题：

| 新词 | 先用大白话理解 |
|---|---|
| 特征、因子 | 用来选股票的“线索”，比如过去涨幅 |
| 标签 | 过了几天才知道的“答案”，比如未来收益 |
| 基准 | 不使用你的选股规则，按约定买一篮子作对照 |
| 回测 | 把同一规则放到很多个过去的日期重做 |
| 数据泄漏 | 做决定时偷看了本不该知道的答案 |
| 模型 | 从过去的练习题里学出一套打分办法 |
| 样本外 | 用没参与挑选规则的数据再考一次 |
| 净收益 | 从毛收益里按实际规定扣除成本后的结果 |

**第一次读只做两件事：** 看懂每个表里哪些是“当时已知”，哪些是“事后答案”；每章能自己复算一个小数字。遇到代码看不懂，可以先跳过代码，看表和展开答案。

起步第一课只用加减乘除，第二课才把相同的动作翻译成 Python。**接着就能在目录的「基础准备」里找到 Python 数据分析、数学和金融基础，不需要翻到最底部。它们按需选读，不是第 1 章的入门门槛。****先把 8,320 元这笔账弄懂。** 16 道综合练习放在第 16 章后面：其中前四道可以现在试试，后面的题等学到相应章节再做。等你能解释为什么最终是 8,320 元，再继续第 1 章。

### 炒股经验怎么带进这本书？

你可能习惯这样做：看 K 线发现一只股票很强，翻财报看看估值，买入后观察盈亏。量化不是否定这些经验，而是**把“我觉得强”写成别人能重复执行的规则**。

- “最近走势很强” → 写清是过去 **5 个交易日涨幅**，还是 5 日均线。
- “估值较低” → 写清是 PE 低、EP 高，财报数据**哪天公布**。
- “开盘买入” → 写清是次日开盘**尝试委托**，并记下买不到的情况。
- “回测不错” → 写清对比谁、扣了哪些费用、有没有看未来才调参数。

这些步骤会在第 1–9 章学到。你不需要重新学习股票是什么；真正的新技能是**时间、表格、固定规则和代码**。

如果你更想先看真实交易软件里的 K 线，完成第一课后也可以直接打开[三只 A 股真实 K 线练习](真实A股K线_入门实例.md)；它使用真实历史价格，但不会替代四股票的手算主线。

## 2. 然后是四个循环

主线不是十六个并列主题，而是四个闭环。每个循环结束时，你应该能独立做一件事：

特别是第二循环，顺序已经改成 **第 3 章：认识数据和未来答案 → 第 4–6 章：学会算特征、均线和财务因子 → 第 7 章：公平切分时间，不能用测试选规则 → 第 8 章：检验因子好不好**。先掌握输入，再讨论怎样考试，避免学到一半才发现前面的名词还不会。

| 循环 | 章节 | 要回答的问题 | 读完你能 |
|---|---|---|---|
| 一 | 第 1–2 章 | 这笔收益算不算本事？ | 判断一次盈利是否值得继续，并写出可复查的规则 |
| 二 | 第 3–8 章 | 数据和因子可不可信？ | 做出一张时点正确、能被单因子评价的表 |
| 三 | 第 9–10 章 | 信号能不能变成钱？ | 算清成交限制、费用和现金，得到可执行组合 |
| 四 | 第 11–14 章 | 模型有没有增加信息？ | 在同一口径下比较单因子、线性和树模型 |
| 收尾 | 第 15–16 章 | 结论能不能重做？ | 保存输入、配置、输出和失败版本 |

每一章开头会说明“你已经会什么”和“这一章只解决什么”。如果前面的某一步没做，先回去补那一步，不要在这里同时补两个概念。

## 3. 一个新概念怎样出现

正文尽量按同一个顺序处理概念：

```text
一个具体问题 → 你先猜或先算 → 看到差异 → 再给名字
```

所以有些段落会让你先填一个数、先选一个答案，再展开核对。答案放在“展开”框里，是为了让你先做决定。算错不是事故，是这本书的主要材料。

我们的目标是一次只增加一个新概念；如果一段里同时出现四个，说明这一段该拆开了。

## 4. 工具与参考怎么用：正文优先，手册后查

**第一次从头读，不必跳出去补完整本 Python、数学或机器学习手册。** 正文会在第一次需要用到知识时，给出最小例子、中文解释和一条能核对的计算。从起步第二课开始，再尝试运行代码。

你可能已经会看 K 线、均线、成交量、PE、ROE、涨跌停，但量化研究还要问：“这条规则怎么写给电脑？当时的数据可不可得？按约定能不能成交？怎样知道不是碰巧选对？”

| 炒股时熟悉的事 | 正文中学习什么 | 想深究才查 |
|---|---|---|
| 看涨跌、比较指数 | 起步第一课、第 1–2 章：收益、基准、复利 | [金融与 A 股参考](00c_金融市场基本概念.md) |
| 看财报、K 线、复权 | 第 3 章：先从 K 线到历史表，再理解答案和公告时点 | [数据与标签参考](参考_数据标签实现与审计.md) |
| 看均线、涨幅榜、成交额 | 第 4–6 章：把盘面印象变成固定计算 | [因子算子参考](参考_因子算子与边界.md) |
| 按排名选股、复盘胜率 | 第 8 章：排名是否有用 | [数学与统计参考](00e_量化数学与统计.md) |
| 涨跌停、停牌、交易费用 | 第 9 章：买不到怎么办、账户怎么算 | [A 股交易规则参考](附录B_A股规则与回测核对.md) |
| 看策略回测和净值图 | 第 11–14 章：模型能否胜过简单规则 | [机器学习参考](00b_机器学习基础.md) |

**操作办法：** 读正文 → 先动手算一道题 → 看答案 → 不会才点参考。参考手册保留详细代码、公式、边界条件，供第二遍和做项目时查，不是第一遍的必修预习。

## 5. 三种读法

- 顺序读：从起步第一课开始，按四个循环读完。第一次读可以跳过参考层和扩展代码。
- 按问题查：从目录找到对应章节，先看开头的“你已经会什么”，缺什么补什么。
- 重做实验：每读完一个循环，运行一次对应脚本，对照输出。数字对不上时，先查输入、日期和规则，再查代码。

## 6. 四级学习法：同时兼顾零基础与进阶研究

不要把进阶内容当作第一遍阅读的必做题。每章末尾的“选读”部分可以全部跳过；先按四个小阶段推进，每一级都保留能核对的成果：

| 学习层级 | 阅读方式 | 每一级的实际验收 |
|---|---|---|
| L0 入门 | 起步线与十六章正文，只做最简单手算 | 能解释信号、标签、组合与基准的每个数字 |
| L1 基础 | 第二遍读本章的“进阶训练”，独立运行代码 | 能复算时间切分、RankIC、费用和模型候选 |
| L2 进阶 | 整理独立的因子、回测和模型报告 | 能发现并定位 PIT 错误、标签越界和账本不平 |
| L3 研究级 | 沿[研究级实战路线](进阶实战_从教学数据到研究级流程.md)换用具有历史版本的真实数据 | 冻结研究协议并报告滚动 OOS、失败样本及执行限制 |

前三层可继续使用本书的固定人工练习数据；最后一层必须换成经审计的真实市场数据，并明确数据源、时间边界和未实现部分。研究级是方法与证据标准，**不表示你已经发现盈利策略，更不等于读完就“精通”**。

每读完一章，先用 30 秒回答：**这一章是在解决什么麻烦？故事里的哪一个数字变了？哪个数字不能提前知道？** 如果还答不上来，就看本章最前面的例子，不需要马上研究全部公式。

练习时每章分别问三个问题：**我会算吗？我能编码复现吗？我能指出至少一种让结果失效的情况吗？** 答得上，再进入下一关。

如果已经完成第 8 章，建议进入[深度专题 A：因子研究与稳健性](专题A_单因子到稳健性研究.md)，把 RankIC、ICIR、分组和成本做成完整报告。完成第 11–14 章后，进入[深度专题 B：机器学习验证](专题B_机器学习验证与增量检验.md)，重做 Ridge、森林与 LightGBM 的参数选择和测试隔离。两篇专题都提供可运行审计实验，但不把人工数据当成真实市场证据。

## 7. 卡住时，先找数字，不要先找定义

回到这一章开头的那张表、那笔钱、那个日期。问三个问题：

1. 这个动作解决什么问题？没有它会怎样？
2. 最小的具体例子是什么？能不能用 A、B、C、D 替换字母？
3. 我现在能不能不看书画出这一步的输入和输出？

如果三个问题都答不上来，先跳过这一节，把后面的例子读完，再回来。理解常常发生在第二次经过同一个概念时。
