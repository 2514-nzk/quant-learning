# 阅读指南｜和小林做一次纸面研究

假设你有 8,000 元虚拟资金，想从 A、B、C、D 四只股票里选两只。你先试了一条很朴素的规则：过去涨得多的排前面。第一笔赚了 320 元。

这本书从这里开始。研究搭档小林是一个虚构人物：他会递来新数据，提议换规则或用更复杂的模型，也会和你一起检查失败。你不需要先熟悉 Python，也不需要先背完金融名词。

股票、交易日编号和数据都由我们为教学构造。它们让计算足够小、错误足够清楚；书中模型表则由配套程序实际运行产生。它们用来练习研究方法，不能证明真实市场里的收益。

## 1. 先把第一笔算懂

按[教材目录](README.md)从两节起步课开始。第一课只用加减乘除，走完：

```text
看当时已知的四个数 → 挑两只 → 打开未来答案 → 算资金 → 和对照比较
```

第二课再让电脑重复同一件事。变量、列表、排序和循环都会对应到刚才用手做过的动作，代码中有简单中文注释。

先读懂输出，再看每一步怎样得到它。不用为了开始读书，先安装一套模型环境；第一份脚本只用 Python 自带功能。

## 2. 后面的章节为什么接在这里

读完第一笔盈利，接下来的问题会自然出现：

| 你遇到的事 | 接着需要弄清什么 |
|---|---|
| 第二次仍赚钱，却输给四股等权；后来又亏了 | 一次好结果能说明多少，什么结果会否定想法？ |
| 新表格里出现一列公司盈利信息 | 当时真的已经知道它了吗？ |
| 一段代码把 8% 算成了 6.93% | 有没有把不同股票和日期混起来？ |
| 三个分数看起来都很有道理 | 它们提供了不同信息，还是重复投票？ |
| 选中的 C 买不到，买卖还要付费 | 真实留下的现金和持仓是多少？ |
| 树模型训练几乎全对 | 换到没有参与训练的题目，还能做到吗？ |
| 一个月后想重新检查结论 | 还能找到那次数据、设置和输出吗？ |

五编、十六章都沿这次研究推进。第一笔、后续四期演算和模型阶段各有明确用途，章节会交代哪张表、哪段日期和哪种费用约定正在使用。模型阶段把固定练习扩展到 60 期，仍是相同四只虚构股票与三列已知分数。

## 3. 读到问题时，先停一小会儿

有些答案收在“展开核对”里。先猜入选名单、资金或哪一步有错，再点开。算错可以留下原答案，看看差异发生在排序、比例、时间，还是现金上。

例如，在看到第一笔赚 320 元后，先预测：“如果后来 A 跌了，当时的入选名单会变吗？”这种小问题会反复出现。你能解释一个动作，就已经在前进。

遇到新公式，先用表里的一只股票替换字母；遇到代码，先找到它读取哪列、产生哪个数。标为错误示范或接口片段的代码有特定用途，完整运行入口会另行给出。

## 4. 工具材料在卡住时再查

| 卡在哪里 | 去哪里找 |
|---|---|
| 变量、列表、循环 | 起步第二课 |
| pandas 表格、分组、滚动窗口 | Python 数据分析与量化数据处理参考 |
| 均值、波动、排名相关 | 数学与统计工具 |
| 复权、涨跌停、交易单位 | 金融市场参考与规则附录 |
| 回归、过拟合、模型参数 | 机器学习基础与模型扩展材料 |
| 真实数据接入、月度因子项目 | 因子研究、组合与工程参考 |

参考区保留了原有七特征工程案例和月度三因子 Top-50 项目。它们用于学会主线后继续扩展，输入、交易频率和代码入口另有约定。正文不会要求你中途换成这两种案例，再回来拼接收益。

## 5. 想亲手重做时

起步第二课先运行 `examples/first_quant_experiment.py`。之后，`examples/story_research.py` 会接着重做同一笔钱、后续四期、第一期的限制与费用；加 `--models` 才进入模型练习。完整命令与输出核对在第 15、16 章。

你可以先一路读完，也可以每读一章就重算一小段。随手记下输入、规则、结果和你现在的解释。最有用的阅读记录往往是：“刚才我以为会这样，实际却这样，原因在这里。”
