# 第 11 章｜把手工权重交给一把简单的尺

你把三个权重来回改了几次。小林看着越来越长的表，说：“如果要让历史决定权重，就把学习规则也写清楚。”

于是我们先请一个容易追踪的模型出场：线性模型。它仍然做乘法和加法，只是权重由训练样本估计。

## 1. 它在学什么

本故事每一期有四只股票。未来收益从低到高的百分位标签是 0.25、0.50、0.75、1.00；R01 对应 D、B、C、A。

模型想根据过去涨幅、EP、ROE，给出接近这些标签的分数。一个最简单的形式是：

```text
分数 = 截距 + w1×处理后的动量 + w2×处理后的 EP + w3×处理后的 ROE
```

这里的分数用于同一期排序，不是预测能赚百分之几，更不是盈利概率。

你提供的是训练期历史输入和历史答案。模型在最终测试时，只能读输入。

## 2. 先把量尺统一，再学权重

如果一列数值范围很大，它在加权时与其他列的尺度就不同。你们只用训练数据估计每列均值和标准差，再将同一套转换用于验证和测试。

```python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge

# 先处理数值尺度，再训练 Ridge；fit 时两步只接收训练数据。
model = make_pipeline(StandardScaler(), Ridge(alpha=0.1))
model.fit(train[features], train["label_rank"])  # 输入和答案按同一行对应。
validation_scores = model.predict(validation[features])  # 新样本只交输入，不交答案。
```

这是接口片段；完整数据切分和运行命令在后面。Ridge 在拟合误差之外限制过大的权重。限制强弱由 `alpha` 控制，仍要由验证集选。

## 4. 学到的 EP 权重，怎么成了负数

选好 alpha 后，用前 46 期重训的标准化系数约为：动量 0.0511，EP -0.0023，ROE 0.1022，截距 0.625。

你原本以为“便宜更好”，看到负号很不踏实。先不要把它翻回正数：模型是在其他输入同时存在、并已标准化的条件下估计关系。EP 与 ROE 相关时，权重分配也会变化。

这里不能把负系数直接解释为“便宜导致亏损”，也不能把原始的 8% 直接乘这个标准化权重。输入转换本身是模型的一部分。

删除一列再比较，会比猜一个系数的经济故事更有帮助。我们在第 14 章回来看这件事。
