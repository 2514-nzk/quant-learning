# 研究级章节写作与实验规范

**核心原则：口径先冻结，证据再进入，允许失败结论。**

## 逐章统一结构

1. 问题与假设：经济解释、适用边界、事前失败标准。
2. 概念与推导：公式、条件、反例，不只复述定义。
3. 数据合同：字段名、来源、证券口径、单位、历史版本、known_at 和缺失语义。
4. 实验协议：signal/decision/entry/exit/label_end、基准、训练验证 OOS、Purge。
5. Python 实现：可运行脚本、依赖、种子、单元测试和复现命令。
6. 分析：基线、分层、统计不确定性、多重检验、条件效应、成本与风险。
7. 反证与局限：泄漏、偏差、漂移、未成交、样本不足和无效结论。
8. 习题、参考答案与**实际核实的**资料来源。

## 不可妥协的边界

- 真实与模拟数据分离。模拟绩效只能用于教学，不能证明真实市场策略有效。
- 财务、行业、题材和历史股票池必须匹配当时的可用版本；不能用当前快照回填。
- 统计排序、组合超额、净收益和真实成交是不同证据等级。
- 多重试验、重叠标签和测试集使用历史必须记录；被反复查看的测试集不得声称未触碰。
- 交易制度需核对证券品种和历史日期；拒单、停牌、退市不能静默删除。
- 没有数据与运行记录时不提供数字结论，不编造论文引用或结果。

## 状态流转

**框架已建 → 草稿 → 可复算 → 已审校**。

“可复算”要求提供固定的输入版本、环境和测试命令；“已审校”额外要求跨章节口径一致、引用核实、失败案例与边界审计。

章节保存到 `advanced/volume-2/` 或 `advanced/volume-3/`，实验按职责进入 `examples/`、`src/`、`tests/`。新提交先经 PR 审核，不覆盖第一卷数据和实验入口。
