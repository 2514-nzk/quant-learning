## 传统多因子补充审计

每项填写证据路径；未实现写“未实现”，不适用写原因，不能只凭设计文字打勾。

- [ ] 财务报告期、公告/可用时间和修订版本已区分，TTM 累计报表与字段单位已核对。
- [ ] 横截面、时间序列、行业内算子维度正确；窗口、并列、缺失和退化分布有约定。
- [ ] MOM_120_20 的端点为 T-120 与 T-20，历史长度充分，未把 20 行当成 20 个市场交易日。
- [ ] 原始与预处理版本报告各自覆盖率，并在共同有效样本上对照。
- [ ] 中性化使用历史行业/市值；数据不足时明确未完成，没有当前行业回填。
- [ ] 因子方向、尺度、类别权重和缺失因子处理在看验证结果前固定。
- [ ] 单因子逐日评价没有提前按未来成交结果筛样本；无定义日期、退市/停牌标签缺失有记录。
- [ ] ICIR 与策略 IR 区分，收益重叠和自相关没有被当作独立观测处理。
- [ ] 历史 IC 加权只使用收益窗口已结束的历史结果。
- [ ] 月度调仓按交易日历生成，评价收益与实际执行起止一致，没有用固定 20/21 日代替月份。
- [ ] 目标与实际持仓区分；整手、未成交、现金、买卖方向成本及受限卖出有证据。
- [ ] 复权收益与原始成交价分开，公司行为未遗漏或重复计入。
- [ ] 参数邻域、子样本、删除因子、安慰剂、1.5 倍/2 倍成本与延迟执行有记录。
- [ ] 保存全部尝试和失败实验，结论区分事实、推断、假设和局限。
