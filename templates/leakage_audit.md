# 数据泄漏与回测审计

- [ ] 所有特征在 T 日决策时真实可得。
- [ ] 标签只使用 T 日之后的数据，起止价格与执行假设一致。
- [ ] 股票池是历史时点可得的，没有用当前成分回填。
- [ ] 财务数据按公告/可用日对齐，而不是只按报告期。
- [ ] 缺失值、标准化、去极值和特征选择只在训练集拟合。
- [ ] 时间切分没有随机打乱。
- [ ] 训练和测试之间按标签周期设置 Purge/Embargo。
- [ ] 参数只由验证集选择，测试集没有被反复查看。
- [ ] 停牌、涨跌停、新股、ST、退市和不可成交价格已处理。
- [ ] 成本、滑点、印花税和换手已计入。
- [ ] 已检查规模、行业和 Beta 暴露。
- [ ] 已报告分年度、不同随机种子和压力成本结果。
- [ ] 已保存配置、数据快照、预测明细、持仓和日志。
