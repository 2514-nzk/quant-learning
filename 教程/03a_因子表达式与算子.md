本章融入 PDF 第 10–13、24 页的 Operator 内容。Operator（算子）是一个定义清楚的数据操作，例如排名、滞后、滚动平均。下表是教材语义约定，不表示仓库已经提供同名函数库；实际可运行的小例子用 pandas 实现。

## 1. 先问计算方向，再写函数

同一张 `trade_date × code` 长表有两个方向：

| 操作 | 比较对象 | pandas 思路 |
|---|---|---|
| 横截面 `rank_pct(x)` | 同一天的不同股票 | `groupby('trade_date')` 后排名 |
| 时间序列 `ts_rank(x,n)` | 同一股票当前值与自己的过去 n 期 | `groupby('code')` 后滚动排名 |
| 分组 `group_rank_pct(x,industry)` | 同一天、同一行业的股票 | 按日期和历史行业共同分组 |

一只股票今天比自己的历史更强，不意味着它今天强于其他股票。这是 `ts_rank` 和 `rank_pct` 不能互换的原因。

每个算子都写清六件事：输入字段与单位、计算维度、窗口边界、最少有效数、缺失/并列处理、输出含义。最后检查依赖的最大信息时点是否晚于信号时点。

## 2. 核心算子字典

| 类别 | 表达式 | 本教材约定与易错点 |
|---|---|---|
| 数学 | `add/sub/mul/div` | 相加先统一单位；比率要解释分母 |
| 安全除法 | `safe_divide(a,b,eps)` | 分母非有限或绝对值不大于阈值时返回缺失；阈值须有业务单位 |
| 变换 | `log/log1p/signed_log` | 定义域分别为 x>0、x>-1；`signed_log=sign(x)*log1p(abs(x))` |
| 限幅 | `clip(x,lo,hi)` | 固定边界；缩尾边界则来自预定的统计规则 |
| 横截面排名 | `rank_pct(x)` | 有效样本中升序平均名次 / 有效数量，取值在 (0,1]；缺失保留 |
| 横截面标准化 | `zscore(x)` | 当日减均值除总体标准差，`ddof=0`；零方差返回缺失并记录 |
| 去中心 | `demean/median_demean` | 减当日均值/中位数，只去水平，不去行业或市值暴露 |
| 分组 | `quantile_group(x,k)` | 先定并列规则与最少样本数；组数不足时报告，不能硬凑 |
| 滞后 | `delay(x,n)` | 同一股票 n 个市场交易日前的值，n>=0 |
| 差值 | `delta(x,n)` | `x(T)-x(T-n)`，保留原单位 |
| 变化率 | `pct_change(x,n)` | `x(T)/x(T-n)-1`；不隐式填充缺失 |
| 滚动 | `ts_mean/ts_sum/ts_min/ts_max` | 窗口含当前时点 T；本章例子要求完整窗口 |
| 波动 | `ts_std(x,n)` | 窗口样本标准差，`ddof=1`；最少有效数另记 |
| 历史排名 | `ts_rank(x,n)` | 当前值在含 T 的窗口内的平均名次 / 有效数量；不是整窗排名均值 |
| 历史分位值 | `ts_quantile(x,n,q)` | 本教材明确为窗口的 q 分位**数值**；位置用 `ts_rank` 表达 |
| 关系 | `ts_corr/ts_cov` | 同一股票两列的配对有效观测；常数序列相关系数无定义 |
| 分组处理 | `group_rank_pct/group_zscore` | 日期与历史行业双重分组；单股票行业排名可算但没有组内区分力 |
| 中性化 | `neutralize(x,exposures)` | 每日横截面回归残差；定义控制变量、权重与缺失处理 |
| 条件与缺失 | `where/mask/isna/notna` | 条件本身也必须在 T 时点可得 |
| 填充与计数 | `ffill/count_valid` | 财务只在单股票、公告后、预设有效期限内前向延续；统计窗口有效数 |

不同框架对 `percentile`、`ts_quantile`、`normalize` 的命名可能不同。PDF 用“历史分位位置”描述 `ts_quantile`；本教材将“位置”和“分位数值”显式分开，避免把 pandas `rolling.quantile()` 的输出误当百分位排名。迁移框架时先读函数定义。

`normalize` 若用于权重，还要约定除以代数和、绝对值和还是其他量；它们对负值的处理不同。

## 3. 一个能独立运行的小样本

下面代码可整体复制到 Python 中运行，依赖已在项目 `requirements.txt` 中。数据是完整、共同的三个教学交易日，不包含停牌缺行，所以 `shift(1)` 此处恰好等于一个市场交易日。

```python
import numpy as np
import pandas as pd

dates = pd.to_datetime(['2024-01-02', '2024-01-03', '2024-01-04'])
panel = pd.DataFrame({
    'trade_date': np.tile(dates, 3),
    'code': np.repeat(['A', 'B', 'C'], 3),
    'x': [1., 3., 2., 4., 2., 2., 2., 1., 4.],
}).sort_values(['code', 'trade_date']).reset_index(drop=True)

panel['rank_pct'] = panel.groupby('trade_date')['x'].rank(
    method='average', pct=True
)
panel['delay_1'] = panel.groupby('code')['x'].shift(1)
panel['ts_mean_3'] = panel.groupby('code')['x'].transform(
    lambda s: s.rolling(3, min_periods=3).mean()
)
panel['ts_rank_3'] = panel.groupby('code')['x'].transform(
    lambda s: s.rolling(3, min_periods=3).apply(
        lambda w: pd.Series(w).rank(method='average', pct=True).iloc[-1],
        raw=True,
    )
)
last = panel[panel['trade_date'].eq(dates[-1])].set_index('code')
print(last[['x', 'rank_pct', 'ts_rank_3', 'delay_1', 'ts_mean_3']].round(4))

assert np.allclose(last['rank_pct'], [0.5, 0.5, 1.0])
assert np.allclose(last['ts_rank_3'], [2/3, 0.5, 1.0])
assert panel.groupby('code')['delay_1'].head(1).isna().all()
assert panel.groupby('code')['ts_mean_3'].head(2).isna().all()
assert np.allclose(last['delay_1'], [3., 2., 1.])

ties = pd.Series([10., 20., 20., np.nan])
assert np.allclose(ties.rank(pct=True).dropna(), [1/3, 5/6, 5/6])
assert pd.isna(ties.rank(pct=True).iloc[-1])
```

最后一天手算结果：

| 股票 | x | 当日 rank_pct | 自身 ts_rank_3 | delay_1 | ts_mean_3 |
|---|---:|---:|---:|---:|---:|
| A | 2 | 0.5 | 0.6667 | 3 | 2 |
| B | 2 | 0.5 | 0.5 | 2 | 2.6667 |
| C | 4 | 1 | 1 | 1 | 2.3333 |

A、B 在当日并列，占第 1、2 名，平均名次 1.5，除以 3 后均为 0.5。B 自身历史是 `[4,2,2]`，当前 2 也取得平均名次 1.5。

## 4. 交易日、缺失与窗口边界

在真实数据里，`shift(20)` 仅表示上 20 行。必须先按市场交易日历把每只股票排成完整时间网格，或显式连接 `T-20` 日期，才能声称它是过去 20 个交易日。网格中的停牌行情可保留缺失；是否沿用估值价格必须另立规则，不能偷偷把缺失成交量当作零或把填充价当作可成交价。

比较两个窗口：

```text
ts_mean(close, 20)：close(T-19) 到 close(T)，共 20 个值
pct_change(close, 20)：close(T) / close(T-20) - 1，需要两个端点，跨度 20 日
```

要从连续行情直接计算后一项，通常需要 21 行价格。`min_periods` 控制滚动窗口有效值数量，不会保证数据在真实历史中已经公开。

无穷值先变缺失。财务字段缺失可能表示尚未公告、不适用、报表缺项或接口异常，要记录原因。不能跨股票填充，也不能用后一天数据反向填回今天。

## 5. 把五个表达式翻译成人话

| 表达式（伪代码） | 解释 | 前提 |
|---|---|---|
| `rank_pct(roe)` | 今天谁的已知 ROE 更高 | ROE 已完成 PIT 对齐 |
| `group_rank_pct(ep,industry)` | 同行业内谁更便宜 | 历史行业可得，行业样本充足 |
| `-rank_pct(ts_std(return_1d,20))` | 波动较低取得较高分数 | 负号统一方向；减号并不意味着能做空 |
| `pct_change(delay(close,20),100)` | `close(T-20)/close(T-120)-1` | 复权与市场日历一致，跳过最近 20 日 |
| `volume/ts_mean(volume,20)` | 今日成交量相对含今日的 20 日均量 | 分母有效；若改用过去 20 日不含今天，公式应显式延迟均量 |

动量表达式必须由内向外读。把它错写成 `close(T)/close(T-120)-1`，就丢掉了“跳过近期窗口”这项研究假设。

## 6. 拓展算子只要求能解释

`ema`、`decay_linear`、`weighted_mean` 用不同权重平滑历史；必须固定近期权重是否更高、缺失值是否重归一。`ts_argmax/min` 必须固定返回“从窗口左侧数的位置”还是“距今天多少期”。`slope` 依赖时间单位，`rolling_beta` 和 `rolling_residual` 依赖回归窗口、截距和基准。偏度、峰度与条件计数则描述分布形状和事件频率。

先掌握第 2 节的核心算子，再逐个加入拓展。函数数量不作为考核标准。

## 7. 练习与答案框架

1. 把 `[10,20,20,缺失]` 做 `rank_pct`，说明分母。答案：`[1/3,5/6,5/6,缺失]`，分母是三个有效样本。
2. 把 A 的最后一个数从 2 改成 100。第一天的滞后和滚动结果应该改变吗？答案：不应改变；用“改未来、查过去是否不变”检测前视错误。
3. 一只股票在 `T-20` 没有行情，能否自动拿第 20 条历史记录代替？答案：不能；按预注册规则返回缺失或使用明确的估值规则，并报告覆盖变化。
4. 行业内只有一只股票时，排名为 1 能否说明它很优秀？答案：没有相对比较证据；组内标准差为零，标准化无定义，应报告样本不足。
