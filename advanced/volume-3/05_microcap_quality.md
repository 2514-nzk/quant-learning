# 第三卷 · 05｜微盘、价值、质量与持仓更新

> **状态：教学正文 v1；固定合成股票池、选股与持仓更新实验及边界测试已建立。** 本章不声称复现真实 A 股微盘收益、真实 RESI5 因子效果或可成交策略绩效。

## 本章核心问题

微盘股策略不能把“低市值 + 一个质量指标”直接写成买入名单，再用收盘价计算净值。真实研究至少要回答：决策时点哪些股票属于历史股票池；低应计和质量指标何时可得；主选不足时如何补位；目标权重经过停牌、跌停、整手、现金和交易成本后，实际持仓是什么？

本章建立一套**教学用微盘组合规则**，目的是让读者审计这四个环节，而不是宣称找到了有效因子。

## 1. 微盘不是一个无需定义的标签

“微盘”必须先指定横截面、规模字段和时点。研究合同至少应冻结：

- 股票池：当时已上市、未退市且满足证券类型要求的普通股；ST、风险警示、停牌及上市期限不足的处理需单独定义。
- 规模：使用决策时点已知的总市值或流通市值，不能把今天的市值倒灌到历史。
- 排序母体：明确全市场还是剔除特定板块后的股票池；分位数必须在当期合格母体内计算。
- 流动性：使用过去窗口成交额/换手率，并定义最低门槛；不能用未来成交量筛选历史信号。
- 交易约束：涨跌停、停牌、退市整理、最小交易单位和资金约束必须进入订单层。

本章固定合成数据中的 `size_rank` 仅代表事先给定的规模排序，不能解释成真实历史市值分位。

## 2. 低应计与财务质量：先定义分子、分母和可得时刻

一种常见应计指标为：

\[
Accruals_t = \frac{NI_t-CFO_t}{\overline{Assets}_t}
\]

其中 (NI) 为期间净利润，(CFO) 为经营活动现金流量净额，分母为期初期末平均总资产。不同研究也会使用资产负债表法、营运资本应计或期末资产；口径不同，不能直接拼接。

教学排序约定：**应计越低越优先**。它只是待检验的质量代理，不等于低应计必然带来超额收益。至少需要检查行业、规模、盈利能力、现金流、一次性项目和财报修订。

财务字段应保留报告期、公告时间、供应商接收时间、修订版本和可用时间。决策时点 (d_t) 的合法条件是：

\[
available\_at_i < d_t
\]

边界相等时按本书保守规则排除。报告期结束日不等于公告日，更不等于策略可取得该数据的时刻。缺失值必须带原因；未知、未采集、尚未披露和真实零值不能互相替代。

## 3. 质量、价值和 RESI5：角色不能混为一谈

质量可由 ROE、经营现金流/资产、负债约束等组成；价值可由估值指标表达。但这些变量可能高度相关，也可能带来行业和规模暴露。本实验不把它们简单加权成“神奇总分”，而是把低应计作为主排序、RESI5 作为候补排序示例。

本章把 RESI5 明确定义为**过去五个交易日个股收益减去同一时点基准收益的简化残差收益**：

\[
RESI5_{i,t}=R_{i,t-5:t}-R_{b,t-5:t}
\]

真实项目若使用不同基准、回归残差、风险模型或复权口径，必须另立定义，不能仅凭名字假定相同。本例只用于展示候补排序，不声称 RESI5 有预测力。

## 4. 主选、候补与持仓更新

教学规则冻结如下：

1. 先执行时点与资格检查：财务数据必须已知，股票必须满足上市期限、流动性及状态约束。
2. 在合格股票中按低应计排序，形成最多五只主选。
3. 主选不足五只时，按 RESI5 从高到低补位；RESI5 缺失者不参与候补排序。
4. 跌停、停牌等无法买入的股票不产生新买单；它们不能被当作“已成交”。
5. 每个调仓日重新计算目标名单。未进入新名单的旧仓形成卖出意图；卖不掉时保留实际持仓并记录原因。
6. 新名单等权分配目标资金作为基线；实际下单按整手和现金约束换算。未成交现金留在账户，不虚构补足。

五日调仓是教学频率，不代表最优频率。真实研究必须比较不同调仓间隔、换手、费用、容量与风格漂移，并使用独立确认期。

## 5. 目标权重不等于实际仓位

若目标权重为 (w_i^*)，但股票停牌、跌停无法买入、卖单未成交或现金不足，则实际权重 (w_i) 会偏离目标。必须分别保存目标名单、目标权重、订单方向与数量、拒单/未成交原因、实际成交股数和费用，以及成交后的现金、可卖持仓和实际权重。

本章教学账本使用确定性的“状态可成交/不可成交”规则，不模拟真实盘口队列或成交概率。T+1 意味着当日买入股份不能当日卖出；跨调仓日持仓必须保留买入批次或可卖数量。

数据文件：`data/teaching/volume3_microcap_synthetic_v1.json`。所有股票、财务公告时点、规模、流动性、收益、跌停和停牌状态均为人工构造，证据等级为 `SYNTHETIC_ONLY`。

~~~bash
python examples/volume3_microcap_lab.py --json
python -m unittest discover -s tests -p "test_volume3_microcap_lab.py" -v
~~~

实验输出每期合格股票、主选、RESI5 候补、目标权重、无法买入股票、实际持仓与现金。它验证规则是否按约定执行，不用于比较真实策略收益。

## 7. 必须做的稳健性与失败审计

真实研究至少需要：低应计口径、财务字段和公告可得时间审计；市值分位、流动性门槛、上市期限和 ST 处理敏感性；行业/规模中性化与风格暴露分解；五日、十日、月度调仓频率比较；退市、停牌、涨跌停、公司行为、整手、T+1 和费用回放；候补、不补位、现金替代、旧仓保留等基线对照；时间区块置信区间、多重试验登记和独立 OOS。

如果结果只在某一组阈值、某一调仓日或某个幸存股票池中成立，应视为研究风险，而不是继续调参直到曲线变好。

## 8. 习题与参考答案

**题 A：** 财报期末早于决策日，但公告在决策日之后，能否使用该指标？

答：不能。期末日期不是可得时间，必须依据当时已公开且已接收的数据版本。

**题 B：** 主选只有三只，能否把两只 RESI5 候补直接视为已买入？

答：不能。候补只是排序名单；仍需经过资格、价格状态、资金、整手和订单成交检查。

**题 C：** 某旧持仓今天跌停，目标名单已将它剔除。净值里能否立即删除该持仓？

答：不能。目标卖出意图不等于成交。应保留实际持仓及不可成交状态，并按可验证价格估值。

**题 D：** 合成实验中组合收益较好，能否说明微盘策略有效？

答：不能。合成数据只能验证程序与教学规则，不能证明真实市场收益、PIT 或执行能力。
