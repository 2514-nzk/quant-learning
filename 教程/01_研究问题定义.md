# 第 1 章｜研究问题与研究规格

你把起步课的结果记在本子上：8,000 元变成 8,320 元。选股规则只有一句话——过去五日涨得最多的两只，各买一半。

这很容易让人兴奋。你准备把“收益 4%”圈起来，小林却先问了一句：“如果我四只都买，结果会怎样？”

先别往下翻。你觉得本次盈利，已经足够说明这条规则有用了吗？

## 1. 基准与超额收益

第一期的未来收益是：A 5%，B 1%，C 3%，D -2%。你选中了 A、C，所以赚了 4%。

如果按相同资金比例买四只，收益会是：

```text
(5% + 1% + 3% - 2%) / 4 = 1.75%
8,000 × 1.75% = 140 元
```

你这次比这个简单对照多赚了 180 元。相对于 8,000 元，差额是 2.25 个百分点。

我们把事先规定的对照叫**基准**。这不是替收益换个名字：它让问题从“有没有赚钱”往前走了一步，变成“这次选择有没有比简单对照更好”。

这一次，答案是更好。现在还不知道下一次怎样。

## 2. 研究规格的最小约定

你把规则发给小林：“买最近涨得最好的两只。”他回了一张表，里面看的却是过去二十日，而你看的是五日。

“最近”这个词给两个人留下了不同理解。另一个差别更隐蔽：你在收盘以后看完数据，他却把买入价记成同一个收盘价。

你们先放下收益高低，重新把动作写具体：

| 这次究竟做什么 | 第一版约定 |
|---|---|
| 候选范围 | 四只虚构股票 A、B、C、D |
| 打分 | 决策时已知的过去五个市场交易日涨幅 |
| 选股 | 分数从高到低，选前两只；同分按股票名字排 |
| 时点 | T 收盘后决定，T+1 开盘尝试买入，T+5 收盘计划卖出 |
| 分配 | 每只分一半资金 |
| 对照 | 同期四只候选股票等权平均 |
| 暂时的简化 | 假设都能成交，先算未扣费收益 |

这张短表就是一份**研究规格**。先写下来，后面的改动才有参照。

## 3. 规则版本与事后修改

看过结果后，你发现只买 A 能赚 5%，比买 A、C 更高。只买 A 会不会更好？当然可以提出这个新问题。

但眼前这段答案已经帮你想到“只买一只”。不能用同一个 5% 再证明新想法已经可靠。

<details>
<summary>先做选择：下一页报告里能把规则改成“只买 A”吗？</summary>

可以另建一版研究，明确说明它是在看完这一期后提出的。原来的记录仍应保留“A、C，各半，4%”。新版本要到未参与这个想法形成的数据上检查。

</details>

你给本子起了第一条记录：`M0：过去五日涨幅，Top-2，等权，未扣费`。没有删掉这次成功，也没有让成功替自己改写规则。

## 4. 特征、信号、标签与策略

回看刚才的动作，这些术语都能落到具体东西上：

| 名字 | 在你这次实验里是什么 |
|---|---|
| 特征 | T 日已经知道的过去五日涨幅 |
| 信号 | 用这个涨幅给股票排出的次序 |
| 标签 | 后来才能看到的 T+1 到 T+5 收益或其名次 |
| 组合 | A、C 各一半的实际或计划持仓 |
| 策略 | 把选择、买卖时点、费用和受限处理一起写清的规则 |

机器学习还没有出场，这次研究已经可以继续。以后让模型打分时，仍要沿用同样的日期、对照和交易约定。

## 5. 研究结论与证据边界

你最初想写“发现了有效策略”。现在改成：

> 在第一期教学数据中，M0 的未扣费收益为 4%，高于候选股票等权对照的 1.75%。目前只核对了这一期，尚未检查重复性、费用和成交限制。

这句话稍长，却清楚地留下了下一步工作。下一章我们不忙着增加模型，先让同一条规则再接受几张成绩单。
