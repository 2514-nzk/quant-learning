# 阅读指南｜从看懂一次选股开始

起步课按初次接触股票、量化和 Python 的读者来写。先用四只虚构股票做一次能手算的实验，理解每个动作，再逐步加入数据、统计和模型。

全书只有一条阅读顺序，见[教材目录](README.md)。前面两节起步课接着五编、十六章；详细工具和实现资料放在末尾，遇到问题时再查。

## 1. 第一件事是算懂一次选择

先读[起步第一课](00f_从一次选股认识量化.md)，它只用加减乘除，带你走完：

```text
看当时已知的数据 → 按规则选两只 → 计算后来的收益 → 和一个对照比较
```

这一课结束时，先确认自己能回答：

- 收益率怎样从两个价格算出来？
- 哪个数在做选择时已经知道，哪个数是后来才知道的答案？
- 组合赚钱以后，为什么还要和其他选择比较？

然后读[起步第二课](00g_读懂第一段量化代码.md)。它逐行解释保存数值、记录股票、排序和计算平均值，并提供一份只依赖 Python 自带功能的脚本。

## 2. 正文会逐步增加哪些东西

| 读到哪里 | 接在起步实验上增加什么 | 留下一件能解释的东西 |
|---|---|---|
| 第一编 | 把想法写清，分开已知数据与未来答案，安排评价时间 | 一份短研究说明和一条时间线 |
| 第二编 | 计算不同的打分依据，检查它们是否有帮助 | 一个手算因子和一份评价记录 |
| 第三编 | 把分数转成持仓，加入费用和买卖限制 | 一次从目标到实际持仓的核对 |
| 第四编 | 从手工权重进入模型学习，比较复杂度的作用 | 同条件下的模型比较 |
| 第五编 | 保存完整过程，核对一次项目运行 | 能被他人复查的实验材料 |

第一章先完成几句话的研究说明。字段契约、完整指标公式和实现接口，在相应章节或参考资料中逐步出现。

## 3. 碰到代码和数学时怎么停下来

每次读完一个小节，先合上页面，用自己的话讲出它想解决的问题，再重算例子。遇到新符号，把它替换成例子里的一个实际数字。

代码可以先阅读输出、对照手算，再逐行查看输入从哪里来。某段代码依赖上文变量时，要一起运行；标成实现片段的内容供查接口，完整运行入口另有说明。

需要补工具时，按下面的问题查阅：

| 卡在哪里 | 查什么 |
|---|---|
| 变量、列表、循环和函数 | 回到起步第二课的小片段 |
| pandas 表格、分组、滚动窗口 | Python 数据分析参考；完成算子章后可练量化数据处理工具 |
| 均值、标准差、排名相关 | 数学与统计工具中的对应小节 |
| 复权、涨跌停、交易单位 | 金融市场与 A 股规则参考 |
| 回归、过拟合、模型参数 | 机器学习基础参考 |

这些工具在用到时补齐。每次能解释一个新动作，比同时记住一整页术语更有用。

## 4. 书里的两种案例怎样相连

起步课先使用五日案例的一组简化数字；后面继续练习同样的“已知信息、决定、未来结果”的时间关系。完整实训会加入不能成交、延迟卖出等情况，并换用专门构造的数据。

另一个月度三因子案例在学习价值、质量和动量时进入，用来练习定义和合成。它与五日模型案例的频率、数据和实现范围不同；章节会注明使用哪个规格。

当前五日教学代码能运行；月度案例提供手算、定义卡和项目要求，真实财务接入与完整月度持仓账本仍需实现。研究过程可以互相借鉴，收益结果需要分别解释。

## 5. 每次实验保留什么

做小练习时，先记住输入、规则、结果和自己的解释。进入项目以后，再把日期范围、数据版本、费用、代码配置和输出文件一起保存。

改规则之前先写下理由，每次只改一个主要条件，亏损和失败的结果也保留。最终希望你能沿着报告中的一个数字，找到它来自哪张表、哪个时间和哪条规则。
