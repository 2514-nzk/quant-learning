# 第二卷 · 06｜标签、时间切分、Purge 与 Embargo

> **状态：教学版 v1 方法与例题内部校审完成；合成标签和切分实验可复算。** 未进行真实 A 股多期 OOS 验证。示例证券、行情与收益均是人工构造，不代表市场策略效果。

## 本章核心问题：一行训练记录何时真正“知道答案”？

第 05 章解决特征是否当时可得；本章解决**收益标签什么时候形成、什么时候可用于训练**。例如周五形成信号，下一交易日开盘计划买入，到下一个指定时刻开盘退出；即使训练信号发生在验证之前，训练标签也可能穿过验证首个信号。按日期切分不等于时间上独立。

本章应交付：标签合同、逐样本时间校验、前向滚动 Purge、训练与确认 OOS 的隔离说明。

## 1. 信号、标签和真实订单是三种对象

计划在未来 entry 和 exit 时观察价格，简单毛收益为：

\[
y_{i,t}=\frac{P^{exit}_{i,t}}{P^{entry}_{i,t}}-1.
\]

这是观察性标签，**不是已成交的净收益**。至少需要保存：

| 字段 | 含义 | 使用边界 |
|---|---|---|
| `signal_at` | 信号横截面锚点 | 只用此时已知输入 |
| `feature_available_at` | 特征最后可得时刻 | 不晚于约定的特征截止 |
| `decision_at` | 模型与组合选择完成 | 不晚于计划交易 |
| `entry_at` | 计划入场报价的观察时刻 | 不自动等于实际成交 |
| `exit_at` | 计划退出观察时刻 | 不自动等于卖单成交 |
| `label_end_at` | 标签最后一个必要价格/事件形成时刻 | 不早于退出观察 |
| `label_available_at` | 标签真正到达并可供训练的时刻 | 不早于标签结束 |

标签常见形式是绝对收益、相对基准收益、逐期横截面收益排名、事件分类。它们都依赖预先定义的评价母体。不要根据未来成交状况过滤股票之后再称之为当时已知的评价母体。停牌、涨跌停及公司行为，应以状态和缺失/删失规则单独处理。

## 2. 为什么 Purge 依据事件时间而非固定删五行？

设历史训练候选样本 j 的信号为 s_j，标签最后观测为 e_j，完成校验并可用于训练为 a_j。验证折首信号为 v_k。针对**只使用验证开始之前训练样本**的前向方案：

\[
T_k=\{j:s_j<v_k,\ a_j<v_k\},\qquad
P_k=\{j:s_j<v_k,\ a_j\ge v_k\}.
\]

在本书的严格约定里，a_j 与 v_k 相等也要清除，避免同一瞬间的数据先后顺序无法确定。若只有 e_j 而不知道 a_j，需要明确保守可用时刻的假设。退出价格形成不代表系统立刻完成数据接收或标签校验。

为什么不是“固定删除五行”？因为五个**交易日**不等于五个**自然日**，更不等于 DataFrame 上五条**证券行**。同一日有数千只股票，停牌、节假日和事件窗口也会让样本的标签终点不同。按 `label_available_at` 逐行判定，才能明确哪些样本跨越验证时点。

### 2.1 Purge 不等于 Embargo

Purge 针对因标签窗口重叠或答案未形成而不能纳入训练的记录。Embargo 常见于训练样本可以分布在验证窗两侧的交叉验证，为减少邻近信息依赖再设缓冲。两者的具体时间判据必须由研究设计给出。

本章代码只实现**纯前向训练的 Purge**，可选 `safety_gap_minutes` 在标签已可用之后追加一段保守安全距离。它**不是**适用于任意双向交叉验证的通用 Embargo。不要把代码名称理解为所有时序切分问题已解决。

## 3. 正确的滚动训练需要冻结什么？

一份可审计的折叠报告至少有：训练候选区间、验证首信号、每行的 `signal_at` / `label_end_at` / `label_available_at`、保留/清除样本数、参数选择时间、是否接触了最终 OOS。

还要区分两个预处理问题：当日所有股票的特征值已在决策之前形成时，使用**当日横截面**均值做 z-score，并不自动构成未来泄漏；但提前在全部训练/验证/测试日期上 `fit` 一套全局标准化器，再去切分训练集，可能引入验证/测试分布的信息。行业成员和证券资格仍应遵守 PIT。

Purge 只能解决标签时间穿越的一部分风险，不能修复静态当前股票池、供应商财务修订、测试期调参、多重检验或理想报价不能成交等问题。

## 4. 实验：逐条检查标签何时可供训练

[Python 实验源码](../../examples/advanced_factor_research_lab.py) 生成 12 个合成周度信号期、每期 12 只人工证券，不需要外部数据或第三方库。运行：

~~~bash
python examples/advanced_factor_research_lab.py --json
python -m unittest discover -s tests -p "test_advanced_factor_research_lab.py" -v
~~~

函数 `purge_forward(train, valid, safety_gap_minutes=0)` 找到最早验证信号，并按

~~~text
label_available_at + safety_gap < valid_first_signal_at
~~~

保留训练样本。实验把**独立复制出来的一条**训练记录的标签时刻故意推至验证之后，以证明这一条必须被清除。因子统计使用原始未修改的合成数据，不会把这个专门制造的标签异常混进收益检验。

测试包括无时区、重复日期/证券、未来特征、晚到标签、边界相等、非法倒序和额外安全间隔。注意：实验只验证**给定 timestamp 字段的语义一致性**，并不验证真实供应商的时间来源和交易所日历。

### 4.1 真实价格下的时序隔离测试

[四股 18 期审计](REAL_DATA_EVIDENCE_REVIEW.md) 逐期检查信号早于入场、退出晚于入场、观察期之间不重叠，并构造反事实：改变最后一期某股未来退出日收盘价，**不应改变**当期已形成的 MOM5 或选择排名。

这里的价格来源没有 2024 年逐笔供应商接收/入库时间，也缺 `label_available_at`。这只能算**日期级门禁**，不等于完整的真实 PIT 或训练/Purge/OOS 合格证明。早已在第一卷公开的后四期，不再具有“未触碰 OOS”的证据身份。

### 4.2 按标签真正可用时间做 Purge

新增 [PIT 事件与标签输入合同](../../examples/advanced_pit_intake_lab.py) 把“标签在哪天退出”和“模型何时**能得到这个标签**”分开：

\[
signal\le decision<entry\le exit\le label\_available.
\]

若下一验证段的首个信号时刻是 \(v\)，严格的前向训练标签门禁为：

\[
label\_available\_at < v.
\]

**相等也不通过**，因为这份课程采用保守的“必须严格早于验证开始”的冻结标准。一个未来退出尚未发生、或虽退出但尚未完成收集/校验的标签，不能提前作为训练答案。这和根据日历简单“固定删去五行”完全不同。

默认合成例子两条标签：一条 3 月已可用，可以进入 4 月初验证之前的训练集；另一条直到验证开始当天稍后才可得，必须标记 `PURGED_LABEL_NOT_READY`。测试另涵盖边界相等、未来特征、倒序退出、无时区、晚到修订与来源元数据矛盾。

请注意两点：**一**、本实验读取的是人为给出的事件时间，即使逻辑验证通过，也不证明这些时间是真实供应商日志；**二**、这里只实现单向前推训练的标签门禁，不意味着复杂双向交叉验证的 Embargo、行情停牌与所有重叠特征问题已经解决。

运行：

~~~bash
python examples/advanced_pit_intake_lab.py --json
python -m unittest discover -s tests -p "test_advanced_pit_intake_lab.py" -v
~~~

### 4.3 样本准入不是标签 Purge 的同义词

[教材数据与参考股票池审计](HISTORICAL_UNIVERSE_SOURCE_AUDIT.md) 将“证券当时是否在有效研究母体内”与“该证券标签在训练截止是否已经可用”分开：两者都是必要条件，任何一项未知都不能自动跳过审计。即便某条标签 `label_available_at < validation_first_signal_at`，如果其当时证券成员身份为 UNKNOWN，也**不能仅凭标签时间合格而将它认定为历史全市场有效训练样本**。

本轮程序给出覆盖维度的证据门禁，尚未实现真实 A 股全市场样本准入与模型训练联动；该环节仍是未来数据和研发任务。

### 4.4 教材里的标签失败案例：未知不等于零收益

使用 [教材合成 PIT 事件](../../data/teaching/pit_events_v1.json) 与 [历史母体覆盖实验](../../examples/advanced_universe_coverage_lab.py) 分别练习：

1. A 的旧财务值在决策时可得，4 月才出现的修订值不能回填到 3 月；
2. B 的成员身份直到决策之后才披露，必须标为 **UNKNOWN**，不能推断为“未上市”或“退市”；
3. 标签虽可能已有退出价，但如果 `label_available_at >= validation_first_signal_at`，仍不能进入训练集；
4. 缺价、真实停牌、代码变更、摘牌日期是不同事件，不可全部填 0，更不能当作真实可成交标签。

这四个是**专门设计的教学反例**，不是个人策略数据的历史结论。在真实市场里，必须用交易所交易状态、独立来源时点和明确的出入场报价分别检验。

## 5. 可复核练习

**练习 A**：周五 14:50 已形成退出报价，系统 15:10 才验证并写入标签；验证信号是 15:00，能把这条标签拿来训练验证首个模型吗？

答：不能。`label_available_at` 是 15:10，晚于验证信号。

**练习 B**：一个五日收益标签对应 31 个行业，每周一组横截面。删除最后五条行业记录能防泄漏吗？

答：不能，记录数量不是交易日跨度。必须逐行核对标签终点和信息可用时刻。

**练习 C**：研究者不断用“2026 年最终 OOS”的结果选择窗口，还能说该期从未被用于开发吗？

答：不能。该期已进入研究选择过程，不能继续宣称完全独立。
