# 第 9 章｜从信号到组合：成交约束与成本

你已经会：因子分数、组合和基准。这一章只问：选中的股票买不到怎么办？费用和现金怎样改变最终收益？

名单已经在 D006 决定。到了 D007 开盘，小林把成交回报推过来：A 买到了，C 没买到。

你盯着纸面：A、C 各 4,000 元，未来收益 5% 和 3%，账户本应变成 8,320 元。现在 C 那一份还躺在现金里。

这一笔到底剩多少？

## 1. 目标持仓、未成交与现金

你面前有三种办法：留现金、全部给 A、顺着分数买下一只。哪种一定正确？

<details>
<summary>先选择，再展开看研究约定</summary>

三种都可以成为一套明确的规则，但会改变持仓与风险，必须在看未来成绩之前规定。本故事固定“计划买不到的那一份留现金，不临时加仓或替补”。不能看到 D 后来亏了才决定不补它。

</details>

所以实际账面变成 A 4,000 元、现金 4,000 元。A 后来涨 5%，现金收益在本例设为零：

```text
4,000 × 1.05 + 4,000 = 8,200 元
```

纸面 320 元盈利变成了 200 元。打分没变，未来价格也没变，变的是实际拿到了什么持仓。

## 2. 买入费用与资金预算

我们给故事统一加上每侧成交金额 0.1% 的教学费率，也就是 10 bps。买入和卖出分别付费；它不是实际 A 股收费表。

你想用 4,000 元买 A，再付 4 元买入费。小林问：“这一份预算只有 4,000 元，多出来的 4 元从哪来？”

<details>
<summary>先想：如果直接买 4,000 元再付 4 元，现金账会差多少？</summary>

会多出 4 元没有来源。买入费必须从同一份预算里出，所以真正用于买股票的金额要小于 4,000 元。

</details>

把买入费也包含在预算里，才能使现金账闭合：

```text
实际买入金额 = 4,000 / 1.001 ≈ 3,996.004 元
买入费 ≈ 3.996 元
两者相加 = 4,000 元
```

按 A 的 10 元买入价，得到约 399.6004 个虚拟份额。为了看清算术，这里允许碎份额；整手、最低佣金与真实税费还未加入。

## 3. 卖出费用与现金核对

A 后来按 10.50 元退出：

| 现金步骤 | A 这一份的金额 |
|---|---:|
| 买入前预算 | 4,000.000 元 |
| 实际买入金额 | 3,996.004 元 |
| 买入费 | 3.996 元 |
| 卖出成交金额 | 4,195.804 元 |
| 卖出费 | 4.196 元 |
| 卖出后现金 | 4,191.608 元 |

再加上 C 没买成留下的 4,000 元，期末约为 **8,191.61 元**，盈利约 191.61 元。

现在把四个独立版本摆在一起：

| 第一期开局均为 8,000 元 | 期末金额 |
|---|---:|
| 都能成交，不扣费 | 8,320.00 元 |
| C 买不到，不扣费 | 8,200.00 元 |
| 都能成交，买卖各扣费 | 8,303.38 元 |
| C 买不到，买卖各扣费 | 8,191.61 元 |

它们是回到原点重做的对照，不是四笔顺次发生的收益。源数据、名单和费用都能由 `python examples/story_research.py` 重放。

## 4. 成本不只有佣金

前面的 0.1% 是教学用的“双边费率”，它把几类成本压成了一个数。真实交易里，成本至少分成几层：

| 成本 | 什么时候发生 | 这一期的例子 |
|---|---|---|
| 佣金与规费 | 每笔成交 | 教学假设每边 0.1%；真实费率按券商、市场、日期核对 |
| 税费 | 卖出时（A 股印花税等） | 教学先并入费率；真实规则要单独查日期和板块 |
| 买卖价差与滑点 | 下单到成交 | 买入价高于中间价、卖出价低于中间价 |
| 市场冲击 | 订单越大越明显 | 4,000 元很小，故事忽略；大资金必须估 |
| 融资、借券、换月 | 持有或展期 | 本故事不涉及 |
| 机会成本 | 买不到、延迟退出 | C 买不到，4,000 元留现金 |

前几层通常按成交金额收，市场冲击随规模上升。所以“费率 0.1%”只在小资金、流动性好的时候近似成立；资金变大，冲击成本会把这条线抬高。

### 盈亏平衡成本

成本高到什么程度，这笔交易的超额收益就没了？

第一期毛收益 4%，基准 1.75%，毛超额 2.25 个百分点。买卖各付 c，组合收益大约减少 2c。令净超额为零：

```text
2.25% - 2c ≈ 0
c ≈ 1.125%
```

也就是每边约 1.1%。故事用的 0.1% 远低于这个数，所以第一期扣费后仍有约 2.04 个百分点的超额；但这是四只股票、一个区间，不能外推。

更精确地按本章的预算公式算，盈亏平衡约在每边 1.09%。差别来自费用按买卖金额分别计算，而不是简单加减。这里沿用书里的口径，基准未扣费；如果基准也按同样费率交易，盈亏平衡点会变。

这里只需要记住：**先算盈亏平衡成本，再看费率表**。如果策略的毛超额只有 0.2 个百分点，而每边成本 0.1%，它很可能经不起真实摩擦。

### 成本随规模变化

同样是 0.1%，对 4,000 元和 4,000 万元不是一回事。小资金可以假设按报价成交；大资金要估计自己的订单占当日成交量的比例，否则回测里的收益会在实盘里被冲击成本吃掉。

本故事不建立冲击模型，只保留一条检查：**每次报收益，都写清用了什么成本假设、资金规模多大、哪些成本没有算。**

## 5. 延迟退出与资金占用

再往后看一个执行设计题。R04 信号在 D024，计划 D025 入场、D029 退出。假如 D 的旧持仓直到 D031 收盘才卖出，R05 原计划却在 D031 开盘入场。

先猜：旧篮子还没卖完，D031 开盘的新篮子能买吗？

<details>
<summary>展开核对</summary>

不能。开盘时还没收回的钱，不能拿来买新篮子。本故事采用保守的一篮子约定：旧篮子没有完全退出，就跳过冲突的新入场，等下一次预定机会。

</details>

```text
D029 计划卖出失败 → D030 仍持有 → D031 开盘：新篮子原计划入场
                                          D031 收盘：旧篮子才卖完
```

不能在更早的决定中提前使用后来才知道的卖出日。

这个时间图是执行设计练习。故事脚本当前精确重放 R01 的买入、现金与双边费用，尚未实现上述逐日订单和延迟退出账本。需要接入工程时查[组合实现参考](参考_组合与项目实现.md)。

## 6. 组合执行的核对要点

把这一章的执行差异收成一张表：

| 检查 | 问题 | 这一期的答案 |
|---|---|---|
| 目标 vs 成交 | 计划买的两只都买到了吗？ | C 没买到 |
| 未用现金 | 没买成的钱去了哪？ | 留在现金，收益设为零 |
| 买入费 | 预算包含费用吗？ | 用 4,000/1.001 买入 |
| 卖出费 | 卖出金额再扣一次吗？ | 4,195.804 → 4,191.608 |
| 资金回来时间 | 旧持仓卖完前能买新篮子吗？ | 不能 |

现在你不再把一个排序相关系数直接叫策略收益。下一章再回到评分本身：EP、ROE、动量三列都在了，把它们加起来，是否真的做了更好的选择？
