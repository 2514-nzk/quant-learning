# 第 6 章｜用算子准确表达因子

上一章把“过去涨了多少”写成一个特征。现在把这种计算拆成几个可以重复使用的小动作。

**算子**就是一个定义清楚的数据操作，例如取前一天的值、求平均、排序。本章先练四个动作，之后再组合；完整名称字典放在参考资料。

## 1. 先用三个价格手算

A 股票在三个连续教学交易日的收盘价是 `10、11、12`。站在最后一天：

| 想知道什么 | 手算 | 对应操作 |
|---|---|---|
| 前一天的价格 | 11 | 滞后：往回取值 |
| 相对两天前涨多少 | `12/10-1=20%` | 变化率 |
| 最近三天平均价 | `(10+11+12)/3=11` | 滚动均值 |

“滚动”表示日期向前走时，计算窗口也跟着向前移。今天用最近三个值，明天就换成明天时点最近的三个值。

再把 A 和其他股票放在同一天比较，就需要第四个动作：横截面排名。

## 2. 先决定沿哪个方向算

| 日期 | A 收盘价 | B 收盘价 | C 收盘价 |
|---|---:|---:|---:|
| 第一天 | 10 | 20 | 5 |
| 第二天 | 11 | 20 | 5 |
| 第三天 | 12 | 18 | 6 |

沿着 A 的三天看，是时间序列；在第三天横着比较 A、B、C，是横截面。

第三天各自相对前一天的涨幅为：A 约 9.09%，B 为 -10%，C 为 20%。从低到高是 B、A、C，名次为 1、2、3。

把名次除以有效股票数 3，得到 B 为 1/3、A 为 2/3、C 为 1。这个数表达当天的相对位置。

## 3. 给四个动作写上明确约定

| 动作 | 本课怎样理解 | 必须说明的边界 |
|---|---|---|
| 滞后 | 取同一只股票过去某日的值 | 按市场交易日定位；没有目标值就保留缺失 |
| 变化率 | 当前值除以过去值，再减 1 | 两个端点、跨度和单位明确，分母有效 |
| 滚动均值 | 最近若干个值的平均 | 是否包括今天、需要几个有效值 |
| 当日排名 | 同一天不同股票按数值排序 | 方向、并列值、有效股票数 |

例如本课三日均值包括今天，要求三个值都齐全，所以前两天算不出三日均值。

“过去两日变化率”横跨两段时间，需要三个连续日期来定位首尾；“最近三日均值”则使用三个值。名称相似，也应把输入写清。

## 4. 把同一张表交给 pandas

pandas 是用 Python 处理表格的工具。`DataFrame` 是它的表格对象：每列有名字，每行是一条记录，和第 3 章的数据表相对应。

下面是一段完整例子。项目环境装好 `requirements.txt` 后，可以整体复制到 Python 文件运行。

```python
import pandas as pd  # 导入表格工具，后面用 pd 这个短名字调用它。

# 把各列数据组成一张表，每个列表对应一列。
panel = pd.DataFrame({
    # 先把日期文字转成日期类型；这组三天会重复三次。
    "trade_date": pd.to_datetime([
        "2024-01-02", "2024-01-03", "2024-01-04"
    ] * 3),
    "code": ["A"] * 3 + ["B"] * 3 + ["C"] * 3,  # ["A"] * 3 表示连续三条 A 记录，B、C 同理。
    "close": [10.0, 11.0, 12.0, 20.0, 20.0, 18.0, 5.0, 5.0, 6.0],
})
panel = panel.sort_values(["code", "trade_date"])  # 先按股票、再按日期排好，避免前后价格取错。

# 先按股票分堆，再取各自前一行的价格。
panel["prev_close"] = panel.groupby("code")["close"].shift(1)
panel["ret_1d"] = panel["close"] / panel["prev_close"] - 1  # 每一行的当前价除以前一行价格，再减 1。

# 先按日期分堆，再给当日收益排名。
panel["rank_pct"] = panel.groupby("trade_date")["ret_1d"].rank(
    method="average", pct=True  # 并列时取平均名次；pct=True 再除以有效股票数。
)

last_day = panel[panel["trade_date"] == pd.Timestamp("2024-01-04")]  # == 是比较；保留日期等于 1 月 4 日的行。
# 选出四列；round(4) 保留四位小数，index=False 隐藏行号。
print(last_day[["code", "prev_close", "ret_1d", "rank_pct"]].round(4).to_string(index=False))

a_prices = panel.loc[panel["code"] == "A", "close"]  # loc[行条件, 列名]：只取 A 的收盘价这一列。
# rolling 取最近三个值求均值；iloc[-1] 取最后一个结果。
print("A 最后三日均价：", a_prices.rolling(3, min_periods=3).mean().iloc[-1])
```

先把代码和动作对上：

- `panel["close"]` 取出收盘价这一列。
- `groupby("code")` 先把同一只股票放在一组。
- `shift(1)` 取组内前一行；本例三个日期完整连续，所以恰好是前一个市场交易日。
- `groupby("trade_date")` 让同一天的股票一起排名。
- `.loc[条件, 列名]` 按条件取行和列。
- `rolling(3).mean()` 算最近三个值的均值；`.iloc[-1]` 取最后一个结果。

预期数值：

| 股票 | 前一天收盘价 | 第三天收益 | 当日百分位排名 |
|---|---:|---:|---:|
| A | 11 | 约 9.09% | 约 0.6667 |
| B | 20 | -10% | 约 0.3333 |
| C | 5 | 20% | 1.0000 |

A 的最后三日均价为 11。程序打印收益时 `0.0909` 约等于 `9.09%`。

## 5. 缺失和并列要提前说清

每只股票的第一天没有前一行，所以前日价格和单日收益是缺失。这种“历史不够”不能自动写成 0。

如果中间少一个市场交易日，`shift(1)` 就只保证回到前一条记录，未必回到前一个交易日。真实研究要先对齐市场日历，或者按目标日期显式连接。

如果两只股票分数并列，本书排名用它们所占名次的平均。例如 `[10,20,20]` 的升序名次是 `[1,2.5,2.5]`，百分位为 `[1/3,5/6,5/6]`。

## 6. 现在试着解释一个表达式

```text
close(T) / close(T-5) - 1
```

从里面的日期开始读：找到今天和五个市场交易日前的收盘价，再相除并减 1。这就是前面用过的五日涨幅。

以后遇到较长表达式，也可以先拆成这些小动作。需要查历史排名、行业分组、标准化或中性化时，再打开[完整算子与边界参考](参考_因子算子与边界.md)。

## 7. 小练习与答案

**题一：** A 的未来第四天价格被改了，前三天已经算出的特征应该改变吗？

**答案：** 不应该。前三天的计算只依赖当时及以前的数据。

**题二：** `10、11、12` 的三日均价和两日变化率分别是多少？

**答案：** 均价为 11，变化率为 20%。一个是价格水平的平均，一个是两个端点间的比例变化。

**题三：** 为什么排名前先按日期分组？

**答案：** 本例要比较同一天不同股票。把不同日期混在一起，会改变要回答的问题。
