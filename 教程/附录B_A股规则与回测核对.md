# 附录 B：A 股规则与回测核对

本附录落实 PDF 第 6–7、18、21、24 页的“规则独立维护”要求。它是研究核对表，不是截至某一天已完成核验的交易所规则汇编。数值规则应按交易所、板块、品种、日期、风险状态和新上市阶段保存版本；教材正文只使用明确标注的教学假设。

## 1. 规则如何进入实验

| 规则 | 需要保存的事实 | 回测处理 | 常见错误 |
|---|---|---|---|
| 交易日与交易时段 | 交易所日历、竞价与连续竞价时段 | 在可执行时点生成订单 | 把自然月末当交易日 |
| T+1 可卖限制 | 买入批次、数量、可卖日期 | 新买普通股票不能同日卖出 | 把开盘到收盘标签直接当可交易往返 |
| 涨跌幅与无涨跌幅阶段 | 逐证券逐日限价和适用状态 | 判断订单价格及成交可能性 | 全部证券固定套同一涨跌幅 |
| 涨停/跌停成交 | 当时可用的盘口或日线保守假设 | 保留未成交订单与原因 | 日线触板就断言全天都不能成交 |
| 停复牌 | 起止时间、历史状态 | 不能交易；旧持仓和资金占用保留 | 删除停牌股票并退回本金 |
| ST、新股、历史成分 | 生效日、退出日、上市日 | 按信号时点筛选股票池 | 用今天的股票状态回填过去 |
| 申报数量和价位 | 最低数量、递增单位、最小价差、零股规则 | 订单取整后重新检查现金 | 把 100 股和 0.01 元用于所有品种 |
| 费用与税费 | 生效期、买卖方向、最低费用、计费基数 | 逐笔按方向计算并扣现金 | 只按组合收益扣一个固定比例 |
| 除权除息与公司行为 | 除权日期、现金红利、送转及持仓变化 | 收益口径和账户处理相互核对 | 用复权价下单，或复权收益又重复加红利 |
| 退市与样本结束 | 退出路径、可成交记录、残余持仓 | 保留损失和未了结状态，明确估值规则 | 没有后续行情就删掉亏损样本 |

费用公式示意：

```text
单笔佣金 = max(适用最低佣金, 成交金额 × 适用佣金率)
单笔总费用 = 佣金 + 按方向适用的税费/过户费 + 其他明确费用
成交现金流 = 原始成交价 × 股数，再按买卖方向计入费用
```

是否有最低佣金、费率及生效日，应来自所研究时期和账户的实际约定。现有 `cost_bps` 是教学综合成本，不能据此声称实现了逐笔历史税费。

## 2. 可维护的规则登记格式

每条规则保存以下字段，缺值不等于默认适用：

| 字段 | 填写内容 |
|---|---|
| rule_id / version | 规则名称与版本 |
| exchange / board / security_type | 适用交易所、板块与品种 |
| effective_from / effective_to | 生效和终止日期 |
| applicable_state | ST、新上市、退市整理等适用条件 |
| parameter / unit | 数值及单位、单边/双边、最低金额等 |
| source_title / source_url | 具体规则文件名称、发布机构与链接 |
| verified_at / reviewer | 核对时间与核对人 |
| implementation / evidence | 代码位置、配置版本、对应成交核对记录 |

查验入口可从 [上海证券交易所](https://www.sse.com.cn/)、[深圳证券交易所](https://www.szse.cn/)、[北京证券交易所](https://www.bse.cn/) 和 [中国结算](https://www.chinaclear.cn/) 开始。入口链接不等于已经核实某条最新制度；真实研究要记录具体规则文件及其历史生效范围。

## 3. 当前代码能支持到哪里

| 能力 | 当前教材/代码状态 |
|---|---|
| T 信号、T+1 开盘、T+5 收盘标签 | 现有日频教学流程 |
| 未来可买状态与退出延迟 | 有简化字段与非重叠篮子处理，需审计日线假设 |
| 交易比例 × bps 成本 | 已有教学近似 |
| 月度信号与持续持仓现金账本 | 月度三因子项目的待实现项 |
| 部分成交、逐笔订单、最低佣金、整手、现金分红账本 | 不属于现有简化回测的完整实现 |
| 多年行业中性化 | 历史行业数据缺口见数据说明，不能默认完成 |

一次回测能够运行，并不代表表中全部能力都具备。报告应该按实际实现与输出证据填写。

## 4. 课堂核对题

信号日计划卖出一只停牌股，并把全部资金换入新股。停牌股卖出失败，应该怎样处理？

答案框架：保留原持仓和估值、占用资金、记录卖出失败；新买入数量受剩余可用现金限制；下次可卖时按原定规则继续处理。不能因为目标权重为零就删除旧持仓。
