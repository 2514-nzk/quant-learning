## 学习建议

### 完全新手（零基础）
1. 先完整学习三个前置章节（00a → 00b → 00c）
2. 完成每章末尾的练习，确保理解
3. 再进入正式课程第1章

### 有基础的学习者
直接从第1章"学习路线"开始，遇到以下问题时查阅前置章节：
- pandas操作不熟悉 → 00a章
- 过拟合/交叉验证概念模糊 → 00b章
- 复权/涨跌停/成本不理解 → 00c章

### 学习节奏
推荐按顺序学习。每章最后的练习应登记到 `templates/experiment_log.csv`，而不是只在 Notebook 中临时修改。
