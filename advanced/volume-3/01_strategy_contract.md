# 第三卷 · 01｜策略立项与交易时点合同

> **状态：教学正文 v1；教材独立合成策略数据与时间门禁实验可复算。** 本章没有真实 A 股策略收益、历史全市场 PIT 或实盘成交证据。全部证券、行业和收益均为人工数据。

## 本章核心问题：怎样把策略想法变成可被否定的交易研究？

第一卷解释收益、因子和模型，第二卷建立数据时点、样本外和统计审计。第三卷把这些方法组合成完整研究：**什么时候知道什么信息、决定买什么、计划如何成交、用什么标准宣布失败**。一个“每周选择最强行业”的想法若没有明确定义以上问题，就不是可审核的策略。

完成本章后，应能够写出策略规格卡，区分预测、目标仓位、实际成交和成本后结果；正确限制训练标签的时间，并在发现不可信数据时停止计算而不是补齐虚假结果。

## 1. 八个必须事先冻结的研究问题

| 项目 | 必需内容 | 常见错误 |
|---|---|---|
| 研究对象 | 证券类别、历史母体、行业体系版本、基准 | 用今天股票池代替过去 |
| 待证伪假设 | 方向、增量对象、失败标准、研究自由度 | 先看盈利才设计解释 |
| 数据版本 | dataset_id、来源、缺失、哈希、可用时刻 | 合成收益当作真实行情 |
| 时间轴 | signal、feature cutoff、decision、entry、exit、label available | 周五读取下周入场价 |
| 预测规则 | 因子方向、并列值、缺失、行业和股票映射 | 多次调参只公布赢家 |
| 仓位与现金 | 长仓、风险预算、可用现金、成交条件 | 目标仓位自动视为成交 |
| 验证协议 | 基线、开发期、后续期、Purge、重训 | 在最终期调参后仍称未触碰 |
| 停止与归档 | 数据不合格、统计失效、成本失败、拒单 | 覆盖旧报告和失败交易 |

研究合同先于结果。一项策略可以因为数据不合格而停止，也可以有统计排序证据却不具备长仓超额，更可以出现净收益改善但成交不可验证。这些结果都应明确记录。

## 2. 同一周涉及六个不同时间

第三卷使用 [16 周课程专用数据](../../data/teaching/volume3_weekly_v1.json)，对应的**交易日历完全人工设置**，并非交易所实际开市日历。以第一期为例：

| 时间事件 | 人工北京时间 | 意义 |
|---|---|---|
| market known at | 2024-07-05 14:45 | 市场状态特征已准备 |
| industry known at | 2024-07-05 14:50 | 行业历史强弱信息可用 |
| signal / feature cutoff | 2024-07-05 15:00 | 当前截面可使用的最晚信息 |
| decision | 2024-07-05 18:00 | 策略与目标持仓已确定 |
| planned entry | 2024-07-08 09:30 | 未来入场观察时刻，不等于成交 |
| planned exit | 2024-07-15 09:30 | 未来退出观察时刻 |
| label available | 2024-07-15 09:45 | 退出后的模拟标签可用于训练 |

统一的时间约束为：

\[
t_{\mathrm{feature}}\le t_{\mathrm{signal}}
\le t_{\mathrm{decision}}<t_{\mathrm{entry}}
<t_{\mathrm{exit}}\le t_{\mathrm{label\ available}}.
\]

绝不能因为今天已经把全部未来收益存在一个 JSON 文件里，就让历史决策函数读取下一期的 following_week_return。它在本书中是**事后评价标签**，不是预测特征。真实 A 股的周五休市、节假日、停牌、IPO 与退市规则另需交易所历史日历和身份表支持。

### 2.1 标签已经形成，不代表训练当时知道

设第 t 期信号为 \(s_t\)，训练候选 j 的标签实际可用时刻为 \(a_j\)。本书保守的前向训练集合：

\[
\mathcal T_t=\{j:s_j<s_t,\ a_j<s_t\}.
\]

这里相等也拒绝。教材第 2 期周五信号出现时，第 1 期标签仍要到下周一才完成，**因此第 2 期没有任何可用历史标签**；第 3 期才可以看到第 1 期的标签。删去“最后五条证券行”或把周五收盘视作自动可训练都不正确。

这一约定与 [第二卷第 06 章 Purge](../volume-2/06_labels_splits.md) 和 [第二卷第 11 章 Prequential](../volume-2/11_oos_drift.md) 一致。

## 3. 从排名到权重：三个对象不能混写

决策选择出行业 \(g\) 后，需要得到**目标权重** \(w_{g,t}\)。本书仅做目标权重的算术比较：

\[
w_{g,t}\ge0,\qquad \sum_g w_{g,t}\le1.
\]

现金权重为 \(1-\sum_g w_{g,t}\)。预先冻结的行业毛观察收益与成本*代理*为：

\[
R_t^{\mathrm{gross}}=\sum_gw_{g,t}y_{g,t},\qquad
L_t=\sum_g|w_{g,t}-w_{g,t-1}|,
\]
\[
R_t^{\mathrm{proxy}}=R_t^{\mathrm{gross}}-cL_t.
\]

本课程人为设 \(c=0.001\)。从现金到某行业满仓，L1 目标变动 \(L=1\)；某行业 100% 换成另一行业 100%，\(L=2\)。**这不是实际成交金额、真实佣金或真实净收益**；没有委托价格、撮合队列、卖出限制或资金账本。目标权重可以完全不同于实际持仓。

## 4. 四个预注册的策略和对照

| 名称 | 决策规则 | 对应检验 |
|---|---|---|
| cash | 全部现金，模拟不计息 | 空仓对照 |
| equal_four | 同版本四个人工行业各 25% | 简单分散对照 |
| always_top | 每周过去四周收益最高行业目标 100% | 无条件行业强弱 |
| regime_gated_top | 只有 RISK_ON 才持有 Top1，否则现金 | 市场门禁的人工增量 |

四条规则必须使用**同一个日期、相同合成行业数据和相同费用代理**。若只在正收益日期报告门禁结果，或为某条分支事后修改成本，就无法公平比较。

本书的两类行业分类码 TEACH_OLD 与 TEACH_NEW 纯属教学，不能当成真实申万行业；分类切换时所有行业码均改变，因此当前程序保守地把代码改变视为不同目标资产，可能产生较大的 L1 代理换手。**这只是方法示范，不是历史行业映射。**

## 5. 教材独立的数据与可运行程序

数据清单中的 **volume3-weekly-synthetic-v1** 包含 16 个人工周度时点、每期四行业、八只虚构股票；其中第 9 期切换行业版本，第 7 期的 S03 成员时间故意晚到。这让读者能重现实验的**失败边界**，而不必接入个人量化数据库。

从仓库根目录运行：

~~~bash
python examples/volume3_strategy_lab.py --json
python -m unittest discover -s tests -p "test_volume3_strategy_lab.py" -v
python scripts/verify_teaching_datasets.py --json
~~~

在输出中查看 market_regime_counts、unknown_members、eligible_training_week_ids_at_week_3 和 strategies。每条分支保存逐期目标行业、市场状态、毛观察收益、L1 换手、人工费用和净收益代理；前八期标为人工开发，后八期标为**人工后段演示**，不是独立真实市场 OOS。

程序测试主动改变未来的全部行业收益，要求此前排名、状态和目标仓位完全不变；无时区、未来才知道的行业特征、重复证券和错误分类版本会被拒绝。它验证的是我们写出的*算法时间边界*，不能验证供应商历史披露真实性。

## 6. 本章的反证和停止规则

- **迟到信息**：如果市场特征在信号以后才可得，拒绝计算，而不是回填。
- **成员身份未知**：保留 UNKNOWN；不能自动写成不合格或被退市。
- **重复看后段结果**：若修改阈值或窗口，该后段不再是未触碰验证。
- **成本后为正**：合成目标权重代理为正，仍不能宣称真实市场可盈利。
- **缺真实执行**：停止所有“已成交”“可交易净收益”的表述。

## 7. 练习与答案

**题 A：** 第 2 期人工周五信号能否用第 1 期未来一周收益训练？

答：不能；第 1 期标签直到其计划退出后的下周一才可用。第 3 期才可以使用第 1 期。

**题 B：** 从行业 A 100% 转到行业 B 100%，人工 \(c=0.001\)，费用代理为多少？

答：\(L=|0-1|+|1-0|=2\)，\(cL=0.002\)，即 **0.2 个百分点**。不是市场真实成本。

**题 C：** 把未来收益全部改掉，是否允许此前行业排名或 RISK_ON 状态改变？

答：不允许。只有事后评价收益会改变。实验有反事实单元测试。

**题 D：** 在 16 个人工周里门禁策略胜出，可以写“A 股择时通过 OOS”吗？

答：不可以。数据由教材编写，后段不是实际不可提前知道的市场数据，费用也只是代理。
