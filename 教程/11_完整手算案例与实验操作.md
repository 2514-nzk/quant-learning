# 第 11 章：从四只股票手算到一次完整实验

本章把前十章连接成一个可核对的小案例。目标不是证明策略赚钱，而是让你能回答每个数字来自哪个时点、哪条公式和哪个输出文件。

## 1. 固定研究规格

假设在交易日 T 收盘后产生信号：

- 股票池：T 日收盘时满足上市、历史长度和过去 60 日流动性条件的股票。
- 特征：全部只使用 T 日及以前数据。
- 入场：T+1 复权开盘。
- 计划退出：T+5 复权收盘。
- 标签：T+1 开盘到 T+5 收盘收益的当日百分位排名。
- 组合：可买股票中预测最高的 2 只，等权。
- 成本：每侧成交金额 10 bps。

先写规格再看结果。否则看到某只股票在 T+1 涨停后，临时把成交价改成 T 日收盘，就已经发生了研究污染。

## 2. 四只股票的标签

假设价格和成交状态如下：

| 股票 | T+1 开盘 | T+5 收盘 | T+1 可买 | T+5 可卖 | T+6 收盘 |
|---|---:|---:|---|---|---:|
| A | 10.00 | 10.50 | 是 | 是 | 10.45 |
| B | 20.00 | 19.60 | 是 | 是 | 19.70 |
| C | 8.00 | 8.80 | 否，涨停 | 是 | 8.70 |
| D | 15.00 | 15.45 | 是 | 否，跌停 | 15.30 |

计划收益为：

```text
A: 10.50 / 10.00 - 1 =  5.0%
B: 19.60 / 20.00 - 1 = -2.0%
C:  8.80 /  8.00 - 1 = 10.0%
D: 15.45 / 15.00 - 1 =  3.0%
```

从低到高排序为 B、D、A、C，百分位 Rank 为 `0.25, 0.50, 0.75, 1.00`。C 虽然 T+1 买不到，仍可保留在预测评价中；模型在 T 日并不知道次日一定涨停。组合执行时才用 `can_enter=False` 排除 C。

D 在 T+5 跌停卖不出。预测标签仍是固定研究问题的 T+5 收益 `3.0%`，但组合实际收益必须使用首个可卖日。如果 T+6 可以卖出，则：

```text
realized_return(D) = 15.30 / 15.00 - 1 = 2.0%
exit_delay_days(D) = T+6 - T+5
```

这解释了为什么 `predictions.csv` 同时保存 `fwd_return` 和 `realized_return`。

## 3. 手算一次 RankIC

假设模型给出的预测从低到高顺序为 B、A、C、D，对应预测名次 `1,2,3,4`。真实收益名次为 B、D、A、C，对每只股票计算名次差：

| 股票 | 预测名次 | 真实名次 | d | d² |
|---|---:|---:|---:|---:|
| A | 2 | 3 | -1 | 1 |
| B | 1 | 1 | 0 | 0 |
| C | 3 | 4 | -1 | 1 |
| D | 4 | 2 | 2 | 4 |

`sum(d²)=6, n=4`：

```text
RankIC = 1 - 6*6 / (4*(4^2-1)) = 1 - 36/60 = 0.40
```

一个正的 RankIC 只说明当日排序有一定一致性。需要观察数百个样本外交易日的均值、离散程度、正 IC 比例和分年度稳定性。

## 4. 手算 Top-2 组合与成本

预测最高的是 D、C、A、B。C 不可买，因此实际持仓为 D 和 A，各 50%。实际毛收益为：

```text
gross_return = 0.5 * 2.0% + 0.5 * 5.0% = 3.5%
```

首次建仓只有买入侧，交易比例为 1。成本 10 bps：

```text
cost = 1 * 10 / 10000 = 0.10%
net_return = 3.50% - 0.10% = 3.40%
```

若下一期两只股票全部替换，卖出比例 1、买入比例 1，总交易比例为 2，成本为 `0.20%`。若只替换一只，交易比例为 `1/2 + 1/2 = 1`。

D 延迟到 T+6 才退出。如果下一篮子原定 T+5 收盘后、T+6 开盘进入，资金和旧持仓发生冲突。教学回测采取保守做法：旧篮子未完全退出时跳过冲突调仓。更完整的系统需要逐日现金和仓位账本。

## 5. 手算切分边界

假设标签期限是 5 日，日期位置如下：

```text
Train 最后信号日 = 第 100 日
其标签计划退出 = 第 105 日
Validation 首日必须晚于第 105 日
Validation 最后信号的退出也必须早于 Test 首日
```

因此本项目在两个边界各放 5 个交易日空档：

```text
[Train][5 日隔离][Validation][5 日隔离][Test]
```

标准化器只能在 Train 拟合。候选参数在 Validation 比较。选定参数后允许用 Train+Validation 重训，但不能根据 Test 结果回头换参数。

## 6. 运行合成实验

```powershell
$env:QUANT_RUN_ID='baseline_001'
python -m src.run_demo
```

终端会打印样本行数、滚动折数和各模型摘要。先打开：

1. `outputs/demo/latest.txt`：确认最近 run_id。
2. `<run_id>/config_used.json`：确认实际配置，不要只看当前 YAML。
3. `<run_id>/run_manifest.json`：确认 Python、库版本和样本区间。
4. `<run_id>/data_source.json`：确认合成参数或真实 DuckDB 快照路径。
5. `<run_id>/metrics.json`：查看每折验证选择和总体/年度指标。
6. `<run_id>/predictions.csv`：抽查单日单股的日期、标签和成交字段。
7. `<run_id>/backtest_<model>.csv`：检查换手、成本、延迟退出和净值。

合成数据没有经济含义。若模型结果为负，不需要“修到赚钱”；先验证流程是否严格、结果是否可复现。

## 7. 运行真实数据实验

```powershell
$env:QUANT_RUN_ID='pit_universe_001'
python -m src.run_duckdb_demo
```

真实数据运行前后至少做四项审计：

- 任一 `trade_date` 的 `signal_eligible` 股票数不超过 `max_stocks`。
- 过去日期的股票池排名只由该日及以前的成交额决定。
- `entry_date` 晚于 `trade_date`，`scheduled_exit_date` 对应统一市场日历。
- 报告明确写出历史行业 PIT 数据不足，不能声称行业中性。

真实回测出现较高收益时，先检查市值暴露、幸存者偏差、复权口径、涨跌停状态和成本，而不是先讨论实盘。

## 8. 做一次合格的单变量实验

例如比较 Ridge alpha：

1. 保留基准运行目录 `baseline_001`。
2. 只修改 `ridge_alphas`，其他配置不变。
3. 使用新编号 `ridge_grid_001` 运行。
4. 比较每折选择、Mean RankIC、正 IC 比例、年度 IC 和成本后组合结果。
5. 在 `templates/experiment_log.csv` 写下假设、变更、结果和结论。

不能只摘取最好的模型或年份。若平均改善但多数年份退化，结论应写“证据不稳定”。

## 9. 常见错误与定位顺序

### 没有滚动折

样本交易日不足以覆盖 `train + embargo + validation + embargo + test`。缩短窗口仅用于调试，正式实验应恢复研究规格。

### LightGBM 没有输出

检查 `requirements.txt` 是否安装成功。当前代码会在每折选择记录中明确写 `skipped`，不再静默假装三模型都运行。

### RankIC 有值但回测很差

检查 Top-N 是否过窄、换手和成本是否过高、预测优势是否只存在于中间分组，以及不可成交股票是否集中在高预测端。

### 收益很好但最大回撤很大

总收益不能替代路径风险。检查分年度收益、最差阶段、规模或行业暴露和压力成本；不要只用全期终值下结论。

### 两次结果不同

比较 `config_used.json`、`run_manifest.json`、随机种子和 DuckDB 快照。不要凭记忆判断“代码没改”。

## 10. 练习与答案框架

练习一：把四股票案例中的 D 改为 T+7 才可卖，重新计算实际收益和下一次允许调仓时间。

答案框架：标签仍使用 T+5 计划收益；`actual_exit_date=T+7`；实际组合使用 T+7 价格；所有入场日在 T+7 及以前的冲突篮子跳过。

练习二：预测名次改为 C、A、D、B，手算 RankIC。

答案框架：先统一“1 是最低还是最高”的方向，逐股计算 `d²`，代入 Spearman 公式。方向定义不一致会把好模型算成负 IC。

练习三：解释为什么不能在构建测试预测前删除 `can_exit_on_schedule=False` 的股票。

答案框架：该字段来自未来计划退出日；提前删除等价于事先知道哪些股票未来会跌停或停牌，属于前视筛选。应先按 T 日信息预测和选股，再在事件发生时处理退出。

完成本章后，你应能从任一报告数字反查到预测行、成交字段、公式和配置。如果做不到，研究仍不可审计。
