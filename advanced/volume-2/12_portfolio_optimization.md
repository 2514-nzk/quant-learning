# 第二卷 · 12｜风险模型、组合优化与约束

> **状态：教学正文初稿；合成组合优化实验可复算。** 尚未开展真实 A 股历史风险模型、严格样本外或容量验证。实验中的信号、行情和板块均为人工构造。

## 核心问题：预测排序为什么不能直接决定仓位？

前面已学会构建因子和检验 RankIC。但“谁排第一”不等于“该买多少钱”。真实组合还受到证券风险、行业集中、当前持仓、资金、整手、交易成本及不可成交的共同约束。

**因子分数、预期收益、目标权重、实际持仓是四个不同对象。** 第 12 章聚焦目标组合，第 13 章再将它转换成交易状态。

## 1. 一个明确但有限的优化问题

在每次决策时刻，令 w 为非负目标权重、mu 为预先定义的人工收益代理、Sigma 为仅基于已知历史估计的风险矩阵。考虑：

\[
\max_{w}\quad \mu^\top w-\lambda w^\top\Sigma w
                 -c\sum_i|w_i-w_i^{old}|.
\]

其中三项依次是代理收益、代理方差风险及目标仓位调整惩罚。约束：

\[
w_i\ge0,\quad \sum_iw_i\le1,\quad
w_i\le w_{\max},\quad \sum_{i\in g}w_i\le W_g,\quad
\|w-w^{old}\|_1\le T.
\]

这是**教学目标函数**，并非专业量化中的唯一标准。使用现金权重 1−sum(w)，不允许卖空。L1 权重差并不自动等于实际成交金额：股价、现金、费用及成交失败都会让两者不同。

### RankIC 不带有收益量纲

RankIC 衡量的是排序相关，不是 5% 收益之类的预测。实验采用人工映射 `mu_i = 0.015 × score_i`，只为了说明优化程序如何工作。这**不是**已校准的 A 股收益预测。真实组合应审计预期收益误差、风险暴露、成交费用及估计不稳定性。

## 2. 协方差必须只使用当时已知的价格

经典历史协方差：

\[
\hat\Sigma_{ij}=\frac{1}{N-1}\sum_t(r_{i,t}-\bar r_i)(r_{j,t}-\bar r_j).
\]

少量历史样本会让矩阵估计不可靠。本书实验从截止决策日的人工收盘价求对数收益，最多使用最近 5 个历史收益观察，非对角元素乘以 1−alpha，示意对角收缩；历史不足两条时，使用**公开标注的占位对角矩阵**，而不是伪称已经从数据估计了稳定协方差。

返回结果含 `risk_data.latest_used_date`、历史收益条数与回退类型，允许独立检查是否使用了未来日期。单元测试故意修改下一交易日的价格、信号，当前目标权重必须保持一致。

完整风险系统还可能需要因子协方差、行业残差、时间衰减、收缩强度验证及压力测试。这里并未实现它们。

## 3. 什么叫可复算的有约束最优化？

[合成组合实验](../../examples/advanced_portfolio_execution_lab.py) 为每只人工股票枚举 0%、10%、20%、30%、40% 五种权重，对每个候选检查：

- 全部股票目标仓位总和 ≤100%，允许现金；
- 单只上限 40%，每个人工行业上限 60%；
- 相对当前持仓的权重 L1 改变量 ≤1.6；
- 计算上述目标函数，取**可行离散网格**中的最高分。

这里的“最优”严格限定在已声明的粗网格，**不是连续权重空间的精确最优解**。改变网格大小、风险参数或评分映射，会改变目标持仓。工业级实现应另做数值求解、稳定性、容量和不可行问题处理。

教学中使用有限枚举，是为了看到每条约束如何具体影响组合选择，而不是隐藏在一个黑盒求解器中。

## 4. 优化的是目标，实际成交可能让仓位偏离

如果计划卖出某行业股票，但次日订单因限制没有成交，持仓就可能继续集中；如果计划买入但资金不足或买单被挡住，现金比例会高于目标。因此：

**target_weights 不等于 realized_weights。**

每次执行后需要根据最新现金、实际股票数量、市场价格重新计算资产占比与行业风险；不应假定“优化器已约束，所以账户天然受控”。

## 5. 公平的基线必须使用同一执行规则

合成项目含三条预先规定的分支：

| 分支 | 目标规则 | 目的 |
|---|---|---|
| cash | 维持 100% 现金 | 检验无交易账本 |
| equal_weight | 六只人工证券等目标权重 | 简单被动比较 |
| optimized | 离散权重网格、风险与行业约束 | 展示条件优化 |

三组使用完全相同的人工市场、简化 T+1、现金与费用模型。比较时应观察净值、拒单、现金占用、集中度和费用，而不只看目标函数。即使某组得到较高净值，也**不是实际市场策略超额**。

## 6. 动手实验

在仓库根目录执行：

~~~bash
python examples/advanced_portfolio_execution_lab.py
python examples/advanced_portfolio_execution_lab.py --json
python -m unittest discover -s tests -p "test_advanced_portfolio_execution_lab.py" -v
~~~

重点阅读 `covariance_at_decision()`、`optimize_weights()`、`current_weights()`。确认优化器使用的风险历史截止于当日决策、每条权重约束满足声明值、现金允许非零，以及未来价格变化不会回头影响前一次权重。

**所有参数和数据是人工教学约定**，不是 A 股真实交易规则、真实预测校准或真实容量。

## 7. 习题与核对

**题 A：** RankIC 提高可以直接推出更高仓位吗？

答：不能。RankIC 没有收益金额尺度，需要收益预测校准、风险目标、成本与执行约束。

**题 B：** 目标行业权重不超过 60%，但卖单被拒，实际组合仍一定满足 60% 吗？

答：不一定。执行后必须重算实际组合，必要时触发风控。

**题 C：** 历史只有一条收益记录，程序用对角占位矩阵，能称其为可靠的历史协方差吗？

答：不能。这是显式回退假设，应保留记录并限制结论。
