# 阅读指南：按一条研究主线读完本书

这篇是前言，说明本书怎么读、练习案例怎么理解。**唯一的章节顺序见[教材目录](README.md)**；正文按一条连续主线组织，参考资料放在主线之后。

## 本书要带你完成什么

从一句模糊的想法出发，最后交出一份可核对的研究：

> 我想检验什么关系？决策时能看到什么数据？信号怎样形成？它能否在样本外重复，并在交易成本和执行限制下留下证据？

阅读顺序从研究问题、信息时点和标签开始，再进入特征与因子、单因子评价、组合构建、模型比较，最后做完整实训与报告。时间切分放在特征研究之前，是为了先固定“怎样才算真正的样本外证据”。

## 阅读前的准备

建议先读[量化 Python 实战](00d_量化Python实战.md)和[量化数学与统计](00e_量化数学与统计.md)，并完成各自的内置数据练习：

```powershell
python examples/quant_python_workshop.py
python examples/quant_math_workshop.py
```

如果 pandas/NumPy 语法还不熟，查阅[数据分析参考](00a_Python数据分析基础.md)；如果 A 股交易、复权或 PIT 概念不熟，查阅[市场基础](00c_金融市场基本概念.md)。机器学习概念放在参考资料中，需要时再看；进入模型篇前并不要求先读完一大本机器学习讲义。

## 两种练习规格

书里保留了两类案例，它们用来练习同一套研究方法：

| 案例 | 用来练什么 | 当前实现边界 |
|---|---|---|
| 五日模型案例 | T 日收盘产生信号，T+1 开盘执行，T+5 收盘计算标签；用合成数据或量价快照练习时间切分、模型比较和简化回测 | `src.run_demo` 与 `src.run_duckdb_demo` 可以运行；教学回测不包含逐笔交易和完整风格归因 |
| 月度三因子案例 | 用 PIT EP、ROE、MOM_120_20 定义、检验并合成传统因子；从四只股票手算走向月度 Top-50 项目规格 | 讲义提供定义卡、小样本演算和验收要求；真实财务接入、历史行业和完整月度持仓账本仍需实现 |

两种案例的信号频率、数据、持有期和实现范围不同。它们可以比较研究流程，不能把回测收益直接放在一起排名。章节中的标签、PIT、滚动验证、成本和证据边界都服务于这两类练习。

## 每章怎么读

1. 先读概念和时点约定，画出一条时间线。
2. 完成手算或章节练习；章节提供可运行的小例子时，再用代码核对。
3. 把公式、数据可用日和未解决的假设记入研究模板。
4. 每次实验只改一个预先写明的条件；保留失败结果和原始输出。

从项目根目录运行模型教学案例：

```powershell
python -m src.run_demo
```

如需检查本地 DuckDB 快照，再运行 `python -m src.run_duckdb_demo`。真实数据示例同样需要先核对数据覆盖、PIT 字段、历史股票池和交易状态，不能把“代码跑完”当成策略验证。

## 完成时应能回答

- 特征在决策时点是否已经可得，标签的日期与价格端点是什么？
- 滚动验证怎样避免相邻标签窗口泄漏，测试结果是否被用于调参？
- 单因子证据、模型排序能力和成本后组合表现分别说明什么？
- 结果是否对成本、市场状态、行业/规模暴露和成交限制敏感？
- 其他人能否用保存的规格、数据来源、配置和输出复核结论？

如果其中任何一题只能凭印象回答，就回到目录中相应章节补证据。本书的完成标准是研究过程能被解释和复核，不是得到最高收益。
